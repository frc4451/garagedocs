**Topic:** first compile and run, `System.out.println`, comments.
**Cites:** [Java Setup](/java/fundamentals/java-setup), [Printing](/java/fundamentals/java-printing).
**Difficulty:** beginner. **Estimated time:** 20 minutes.

**Repository checkpoint:** Work in `assignments/a01-hello-team/` inside the repository from [A00](/java/assignments/a00-practice-repository-setup). Keep every source and input file for
this assignment there. After completing the checks and rubric, update the root
`README.md`, commit with `Complete A01: Hello, Team`, and push to GitHub.

## Scenario

Write and run a Java program that introduces you to a reviewer. This checks the local tools and the repository workflow before you add calculations or input.

## What To Build

A single file named `HelloTeam.java` with a class `HelloTeam` containing a `main` method.

Use [Create And Find A File](/tools/vscode-tour#create-save-and-find-a-file) if you need help creating and saving the named file. If you work locally, open the `assignments/a01-hello-team/` folder in VS Code and create
`HelloTeam.java` inside it. Do not name the file `Main.java`: a public class and its source
filename must match exactly. Start with this structure, then put the four print statements
where the comment appears:

```java
// Author: your name
// Date: the date
// What this program does: one sentence

public class HelloTeam {
    public static void main(String[] args) {
        // Put exactly four println statements here.
    }
}
```

Running it prints **exactly** four lines, in this order:

```text
Name: <your name here>
Team: <your team number and name here>
Role: <programming / mechanical / electrical / strategy / etc.>
Ready to build.
```

Replace the angle-bracketed placeholders with your real information. The final line,
`Ready to build.`, is fixed.

## Requirements

- A header comment at the top of the file: your name, the date, and one sentence on what
  the program does
- A `class` declaration whose name matches the filename
- Exactly one `main` method
- Exactly four `println` calls in `main`

compiled the local copy and pushed it to your repository.

## Stretch Goals

Finish, check, and save the required four-line version before trying these. The fifth line
fails the fixed output shape. The one-`println` version can print matching text, but it
fails the four-call assignment requirement that automated checks cannot inspect. Keep
stretch work in a separate copy such as `HelloTeamStretch.java` with a matching
`HelloTeamStretch` class.

- In the stretch copy, add a fifth line built with string concatenation: `Today is ` + the
  year, for example `Today is 2026.` Hard-code the year; you have not met `java.time` yet.
- In another stretch copy, re-implement the four lines using exactly **one** `println` and
  the `\n` escape sequence. Decide which version you would rather maintain when "Role"
  becomes "Subsystem".

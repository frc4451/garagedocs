**Topic:** `if` / `else if` / `else`, the `switch` expression, boolean operators.
**Cites:** [Conditional Logic](/java/java-conditionals), [Control Flow](/java/java-control).
**Difficulty:** easy. **Estimated time:** 45 minutes.

### Scenario

A match is 150 seconds long: 15 seconds of autonomous, then teleop, with the final 30
seconds of teleop counted as **endgame**. Your driver coach wants a utility that, given a
time in seconds since the match started, says which phase the robot is in.

You will write the logic twice — once with an `if / else if / else` chain, once with a
`switch` expression — so you can compare the two styles on the same problem.

### Requirements

- Both phase methods return the same value for every input. That is the point of printing
  them side by side
- No bare numbers scattered through the branches; name the boundaries
- The `switch` version uses the arrow form, not fall-through `case` labels with `break`

### Stretch goals

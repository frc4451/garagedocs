### Scenario

For this exercise, use a fictional 150-second timeline: 15 seconds of autonomous followed by teleop, with the final 30 seconds labeled endgame. These are exercise constants, not current-season rules.

Implement the same phase decision with an if/else chain and a switch expression. Compare both results at every boundary.

### Requirements

- Both phase methods return the same value for every input. That is the point of printing
  them side by side
- No bare numbers scattered through the branches; name the boundaries
- The `switch` version uses the arrow form, not fall-through `case` labels with `break`

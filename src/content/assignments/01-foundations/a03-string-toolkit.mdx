## Scenario

Clean and compare text from a scouting form. Each helper handles one operation so you can test spaces, capitalization, and missing text separately.

## What To Build

A single file `StringToolkit.java` with five `public static` helpers:

<ContentTable
  headers={["Method", "Behaviour"]}
  rows={[
    ["<code>String normaliseName(String raw)</code>", "Trim the ends, collapse runs of internal whitespace to one space, convert to title case. Returns an empty string for <code>null</code> or a whitespace-only input."],
    ["<code>String eventCodeKey(String raw)</code>", "Strip whitespace, remove any <code>-</code> or <code>_</code>, return the result uppercased."],
    ["<code>boolean namesMatch(String a, String b)</code>", "True when <code>normaliseName(a)</code> equals <code>normaliseName(b)</code>. Use <code>.equals()</code>."],
    ["<code>int countVowels(String s)</code>", "Count a, e, i, o and u in either case. <code>null</code> counts as 0."],
    ["<code>String[] firstAndLast(String fullName)</code>", "Return first and last name as a two-element array, or the name and an empty string when only one name is given. Trim and title-case each."]
  ]}
/>

Worked examples: `normaliseName("  jane   DOE ")` gives `Jane Doe`,
`eventCodeKey(" sc-ROCK-2026 ")` gives `SCROCK2026`, `countVowels("hello world")` gives `3`,
and `firstAndLast(" Avery ")` gives `Avery` with an empty last name.

## Read The Starter

A **method** is a named block of code. In a declaration such as
`public static int countVowels(String s)`, `String s` is the input parameter and `int` is
the type that must be returned. `main` calls each helper for you. Do not move the helper
declarations inside `main`; methods belong directly inside the `StringToolkit` class.

`String[]` means “array of String values.” An array keeps several values in numbered slots
starting at 0. For `firstAndLast`, return a newly created two-slot array. The caller reads
slot 0 as the first name and slot 1 as the last name. A one-name input still returns two
slots, with `""` in slot 1. If the normalized input is empty, return two empty strings so
the caller can safely read both slots. This task does not ask you to sort anything; the
word “first” means the first name position in the normalized text.

Here, “title case” means capitalizing the first character of **each name piece** and
lowercasing the remaining characters in that piece. It is not the editorial title-case
rule used for book or article titles. Because `normaliseName(null)` returns `""`, calling
`namesMatch(null, null)` returns `true`: both normalized results are the same empty string.

The starter's fixed `main` is also a test driver. For example, it stores one returned array
and then prints its two slots:

```java norun
String[] pair = firstAndLast("Casey  Lee ");
System.out.println(pair[0] + "|" + pair[1]);
```

This is a partial example from the supplied `main`, not a complete program and not the
implementation of `firstAndLast`.

## Requirements

- All five helpers are `public static` on the `StringToolkit` class
- Compare `String` content with `.equals()` or `.equalsIgnoreCase()`, never `==`
- Reach into characters with `charAt(i)` or `toCharArray()`; `s[0]` is not valid Java
- Do not change the input. Each helper returns the type listed in its signature.

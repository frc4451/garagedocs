## Scenario

A deadband ignores small joystick readings near zero. A curve with an exponent above 1 reduces the magnitude of inputs between -1 and 1, while a clamp keeps the final output in range.

Build and test each transformation as a separate method. The calculated value is a requested output, not a measured robot speed.

This assignment uses an **unscaled deadband**. Only values strictly inside the deadband
change to zero. A value outside it is returned unchanged before the curve is applied. For
example, `deadband(0.50, 0.05)` returns `0.50`; it does not shift or rescale the remaining
range. Some robot libraries offer rescaled deadbands, but that is a different calculation
and would fail this assignment's expected values.

Trace one negative value through the required order: `-0.50` survives the deadband,
`Math.abs(-0.50)` is `0.50`, and `Math.pow(0.50, 2)` is `0.25`. Restoring the original
negative sign gives `-0.25`; the clamp leaves it there because it is already between
`-1.0` and `1.0`. Use `double` values throughout. This is ordinary decimal arithmetic,
not integer division.

## Requirements

- Each method does exactly one thing and returns a value. None of them print
- `applyCurve` calls the other three rather than repeating their logic
- Use `Math.abs` and `Math.pow` rather than hand-rolling either

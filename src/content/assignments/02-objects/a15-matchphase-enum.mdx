## Scenario

Replace A05's String phases with an enum that stores each phase's time range, label, and example drive scaling. A call to phaseAt(75) returns the TELEOP constant.

Keep the fictional timeline from A05. The scaling values are exercise data, not safe output limits for a physical drivetrain.

## What To Build

An enum is a type with a fixed set of objects. Here, those objects are `AUTO`,
`TELEOP`, `ENDGAME`, and `OVER`. Unlike the small enum in [Enums and
Records](/java/fundamentals/java-enums-and-records), each object also stores fields
and supplies its own version of one method. The constructor calls beside the
constants fill the four fields that are already in the starter.

`MatchPhase` with four constants, each carrying `startSeconds`,
`endSecondsExclusive`, `maxDriveScaling` and `label`. The constants and constructor are
written for you. You add three things:

## Build Locally

Create `MatchPhase.java` and `MatchPhaseTester.java` in the assignment folder.
Move the enum into `MatchPhase.java` and declare it `public`. Move the supplied
tester, including its unchanged `main`, into `MatchPhaseTester.java` and keep that
class `public` too. The browser starter keeps both types together, where only
`MatchPhaseTester` can be a public top-level type.

Declare the local enum constructor `private`. Only the constants inside
`MatchPhase` call it; assignment code should not construct additional phases.

## Read The Unfamiliar Syntax

Start with one constant. `AUTO(0, 15, 1.0, "Autonomous")` calls the enum
constructor once and stores those four arguments in the `AUTO` object. Its brace
block then implements `shortStatus`. Repeat that same shape for the other three
constants, changing only the required status expression. After the last constant
body, keep the semicolon that separates the constants from the enum's fields and
methods.

`public abstract String shortStatus(int currentSeconds);` has no method body. Java then
requires every constant to provide one. Keep each implementation `public` because
an overriding method cannot be less visible than the method it replaces.

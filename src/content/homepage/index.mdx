## Our mission

GarageDocs builds Students that want to join the FRC 4451 Automation Team by building software skills
from academic lessons in Java to FRC applications on competition-ready robots.

Lessons focus on results students can observe: run the code, test locally in simulation, inspect data, then understand the resulting behavior. 
Prerequisites and sources are listed so students can start with the appropriate background to complete lessons.

## Where to Get Started

If you are a prospective member of the FRC 4451 Automation Team, you should start with the [Badge](/badges) curriculum.

Otherwise, you can use this glossary to help navigate sections of the site.
1. [Tools](/tools) helps showcase the command line, Git, VS Code, networking, and documentation habits.
2. [Hardware](/hardware) for references on wiring electronics, then return to its vendor pages while bringing up devices.
3. [Java](/java) will help you complete the matching [Practice assignments](/java/assignments) as you learn.
4. [FRC 2026 Kit Bot](/kit-bot) to write robot code and test in simulation.
5. [FRC](/frc) for more comprehensive thoughts on various FRC software topics.

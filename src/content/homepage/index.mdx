## Our mission

GarageDocs helps students build programming skills they can carry from their first Java program to a competition robot. The curriculum is written for students with different levels of experience and keeps FRC 4451's programming knowledge available from one season to the next.

Lessons focus on results you can observe: run the code, test the robot in simulation, inspect its data, and understand why it behaved that way. Prerequisites and sources are listed so students can enter at the right place and mentors can update the material as software and hardware change.

## How to navigate

If you're new to programming, follow this learning path:

1. Start with [Java](/java) and complete the matching [Practice assignments](/assignments) as you learn.
2. Work through [Kit Bot](/kit-bot) to write robot code and test it in simulation. Start after completing Java and at least Track 2 of Practice.
3. Continue to [FRC](/frc) for more advanced topics using FRC 4451's competition robot code.

Use [Tools](/tools) when you need help with the command line, Git, your editor, networking, or AdvantageScope. If you already know what you need, choose a section below and use its sidebar to find a lesson.

## About the project

GarageDocs is maintained by FRC 4451 ROBOTZ Garage. It grew from the open-source [Mantik](https://github.com/itkan-robotics/mantik) project and now combines FRC 4451's lessons, team code, simulation workflow, and selected material from other FIRST contributors. The [References](/references) page records the full authorship and project history.

Java lessons and Practice assignments run in the browser. Kit Bot and FRC lessons use the WPILib development tools and teach students to test robot code in simulation before moving to hardware. Each FRC lesson includes a Sources list with the documentation, API references, and team code used to write it.

FRC 4451's mentors use [Claude](https://claude.com/) (Anthropic) to draft lessons from FRC 4451's code and cited documentation, then review and edit the drafts. The project checks internal links, heading links, and runnable Java examples separately.

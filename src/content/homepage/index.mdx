### How to navigate

Start with Java if you are new to programming, and use Tools for the command line, editor, and Git skills you need along the way. Complete the corresponding Practice assignments as you learn.

For FRC, work through Kit Bot after learning Java. The FRC section assumes you can apply those skills and builds on them with FRC 4451's competition code.

Use the sidebar to find pages within a section. Tools pages are references you can return to for a specific task.

### References

These sources support the curriculum and site. Every FRC lesson ends with a **Sources** list naming the documentation pages, Javadoc entries and team-repository files it was written against, with the library version each was checked at; the [Resources](/resources) catalog provides links grouped by section and topic. New sources are added to both as the curriculum grows.

#### Source repositories

- **[itkan-robotics/mantik](https://github.com/itkan-robotics/mantik)**: the project this site is forked from; the site framework, the original FRC lessons, the [PID practice project](https://github.com/itkan-robotics/mantik-pid-practice) and its tutorial videos, and the base of the Resources catalog. Mantik's FTC lessons and browser PID simulator were part of this fork until September 2026 and were removed as out of scope.
- **[FRC3476/mantik-orange](https://github.com/FRC3476/mantik-orange)**: the in-browser Java playground the Java lessons and Practice assignments run on.
- **[FSC Open Docs](https://github.com/firstsouthcarolina/FSCOpenDocs)** (FIRST South Carolina): the source of the two FRC Networking pages, written by FSC contributors including FRC 4451's mentors and used under CC BY-SA 4.0; see [NOTICE](https://github.com/frc4451/mantik-garage/blob/main/NOTICE).
- **[Cobra2026Private](https://github.com/frc4451/Cobra2026Private)**: FRC 4451's 2026 competition robot code. It provides the ROBOTZ Garage library (`org.robotzgarage.frc2026`; ROBOTZ Garage is the team's name) and reference implementations for FRC lessons. Lesson examples may be simplified or use illustrative configuration values.
- **[Riptide2025](https://github.com/frc4451/Riptide2025)**: the 2025 robot; the [Choreo](/frc/choreo) and [QuestNav](/frc/questnav) lessons draw on its autonomous and headset code.

#### Technical documentation

- **WPILib**: [docs.wpilib.org](https://docs.wpilib.org/) and the [Java API](https://github.wpilib.org/allwpilib/docs/release/java/): command-based, simulation, unit testing, telemetry, coordinate systems.
- **CTRE Phoenix 6**: [v6.docs.ctr-electronics.com](https://v6.docs.ctr-electronics.com/): control requests, Motion Magic, CANcoder, simulation, unit testing, and the [manual PID tuning](https://v6.docs.ctr-electronics.com/en/latest/docs/api-reference/device-specific/talonfx/manual-pid-tuning.html) application note used in the [Manual Tuning](/frc/manual-pid-tuning) group.
- **REV**: [docs.revrobotics.com](https://docs.revrobotics.com/) and [REVLib](https://codedocs.revrobotics.com/java/).
- **AdvantageKit**: [docs.advantagekit.org](https://docs.advantagekit.org/): the IO layer, logging and replay.
- **AdvantageScope**: [docs.advantagescope.org](https://docs.advantagescope.org/): the data sources and tabs covered in [Tools](/tools/advantagescope-tour).
- **PhotonVision**: [docs.photonvision.org](https://docs.photonvision.org/).
- **PathPlanner**: [pathplanner.dev](https://pathplanner.dev/), **Choreo**: [choreo.autos](https://choreo.autos/), **BLine**: [bline-docs](https://bline-docs.pages.dev/).
- **QuestNav**: [questnav.gg](https://questnav.gg/).
- **Project Lombok**: [projectlombok.org](https://projectlombok.org/features/).
- **Git**, **GitHub** and **Visual Studio Code**: [git-scm.com](https://git-scm.com/doc), [docs.github.com](https://docs.github.com/), [code.visualstudio.com/docs](https://code.visualstudio.com/docs).
- **FRC electrical**: [frcelectrical.org](https://frcelectrical.org), robot wiring and electrical systems.

#### What the site is built with

- [Astro](https://astro.build/) with MDX content collections, [React](https://react.dev/) islands for the Java playground and the Resources catalog, [Pagefind](https://pagefind.app/) search and [Shiki](https://shiki.style/) code highlighting; deployed to GitHub Pages by GitHub Actions.
- The Java playground compiles and runs real Java in the browser with [CheerpJ](https://cheerpj.com/) and the [Eclipse Compiler for Java](https://github.com/eclipse-jdt/eclipse.jdt.core).
- Lessons are drafted with [Claude](https://claude.com/) (Anthropic) working from FRC 4451's code and the documentation above, then reviewed and edited by FRC 4451's mentors. The project includes separate checks for internal links, heading anchors, and runnable Java lesson examples.

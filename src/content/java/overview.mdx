### Part 1: Java Fundamentals

[Java Fundamentals](/java/fundamentals) starts with printing and variables, then builds through programming logic, object-oriented programming, data structures, functions, programming math, algorithms, design patterns, and concurrency.

Supported lesson examples run in the browser while online; partial snippets name the context they need. Change them, run them again, and complete each lesson's short exercises before moving forward.

### Part 2: Practice Assignments

[Practice Assignments](/java/assignments) starts with setting up one student-owned GitHub repository. Each assignment then gives you a scenario, requirements, checks, hints, and a self-grading rubric without providing the completed program.

The Practice Assignments are grouped into three tracks:

1. **Foundations:** input and output, arithmetic, strings, conditionals, loops, methods, and arrays.
2. **Objects:** classes, composition, inheritance, interfaces, records, exceptions, files, and lambdas.
3. **Collections:** generics, lists, maps, streams, recursion, and complexity.

### Remember that this is for Practice

You do not need to finish every Fundamentals lesson before opening an assignment. 
Complete the assignments that match the concepts you just learned, then return to Fundamentals for the next group.
The point of this is to help give you active examples that can be used to help further your Java skills.

Practice assignments can run in the page, but your completed programs need to belong in the GitHub repository created by [A00: Practice Repository Setup](/java/assignments/a00-practice-repository-setup). Commit and push each checkpoint so mentors can review the code and its commit history.

Java is one curriculum with two parts. **Fundamentals** explains the language with runnable examples. **Practice Assignments** asks you to build programs from a written requirement and keep the completed work in a GitHub repository.

### Part 1: Java Fundamentals

[Java Fundamentals](/java/fundamentals) starts with printing and variables, then builds through programming logic, object-oriented programming, data structures, programming math, algorithms, functions, design patterns, and concurrency.

The lesson examples run in the browser. Change them, run them again, and complete each lesson's short exercises before moving forward.

### Part 2: Practice Assignments

[Practice Assignments](/java/assignments) begins with setting up one student-owned GitHub repository. Each assignment then gives you a scenario, requirements, checks, hints, and a self-grading rubric without providing the completed program.

The assignments are grouped into three tracks:

1. **Foundations:** input and output, arithmetic, strings, conditionals, loops, methods, and arrays.
2. **Objects:** classes, composition, inheritance, interfaces, records, exceptions, files, and lambdas.
3. **Collections:** generics, lists, maps, streams, recursion, and complexity.

### Use the two parts together

Practice appears second in the navigation because it applies the Java material. You do not need to finish every Fundamentals lesson before opening an assignment. Complete the assignments that match the concepts you just learned, then return to Fundamentals for the next group.

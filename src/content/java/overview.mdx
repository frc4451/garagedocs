This track teaches Java from the first program to the structures robot code is built from. It assumes no programming experience. If you have written Java before, skim the Basics group and start where the material becomes new.

<RulesBox title="Why Java">

FRC and FTC robot code is written in Java (FRC also supports C++ and Python; FRC 4451 uses Java). Everything in this track transfers directly to robot code: a WPILib subsystem is a class, a command is an object, and a joystick reading is a method call. Java also checks types at compile time, so many mistakes are reported before the program runs.

</RulesBox>

### How the track is organised

Nine groups, in order. Each builds on the one before.

- **Java Basics:** Installing Java, printing, variables, calculations, the `Math` class, arrays, and how files are organised into packages.
- **Programming Logic:** Conditionals, methods, and handling errors with try/catch.
- **Loops and Iteration:** While and for loops, break and continue, and how to structure a program around a loop.
- **Object-Oriented Programming:** Classes, objects, references, and method overloading, then inheritance in depth: abstract classes and methods, interfaces, and runtime polymorphism.
- **Data Structures:** Choose the right way to store your data (arrays, ArrayLists, linked lists, stacks, queues, deques, trees, and graphs) and understand what each one is fast and slow at.
- **Common Algorithms:** Recursion, searching and sorting, tree traversals, depth-first and breadth-first search, backtracking, and dynamic programming: the techniques that operate on those structures.
- **Functions as Data:** Treat behaviour as a value you can store and pass around, using lambda expressions, method references, and Java's standard functional interfaces.
- **Design Patterns:** Factory methods, dependency injection, and the command pattern, the structures behind testable, reusable robot code.
- **Concurrency and Multithreading:** Running work on more than one thread, the race conditions that follow, thread pools, and the collections that are safe to share.

### How to work through it

- Take the lessons in order; each assumes the ones before it.
- Run every example. The code in these lessons runs in the browser: press *Run*, change something, and run it again.
- Do the exercises at the end of each lesson before moving on. Answers are provided, but reading one is not the same as writing it.
- After each group, the matching [Practice Assignments](/assignments) give you a program to write from scratch, with checks that tell you whether it works.
- Use search (top of the page) to find a topic again later.

<RulesBox title="Prerequisites">

No programming experience is assumed. You need a computer with a web browser; the lesson examples run in the browser, so nothing has to be installed for the lessons themselves. [Setting Up Java](/java/java-setup) covers the local install the Practice Assignments use, with an online fallback for machines where you cannot install software.

</RulesBox>

Java is a programming language: a way to write instructions that a computer can carry out. This section teaches you to write programs, check their results, and explain how they work. You can begin without programming experience or a robot.

## Start Here

Start with [Java Overview](/java/fundamentals/overview), the first lesson. Continue to [Java Setup](/java/fundamentals/setup), then [Printing](/java/fundamentals/printing). Printing means displaying text from your program so you can read its result.

If opening an editor or using a terminal is new to you, use the [Tools references](#computer-help) below as you reach those steps. You don't need to learn every tool before beginning Java.

<span id="part-1-java-fundamentals"></span>

## Learn Java

[Java Fundamentals](/java/fundamentals) explains one topic at a time, with examples and short practice tasks. You'll begin by displaying messages and storing values, then learn to make decisions, repeat actions, and organize larger programs.

Use [Java Code Style](/java/fundamentals/code-style) as a reference once you begin writing programs. It defines the AdvantageKit Spotless Profile used by GarageDocs and Cobra2026, explains how to run the formatter, and covers naming, comments, and code-review habits that an automatic formatter cannot check.

Where an example has a **Run** button, you can try it in the browser while online. Predict the result before running it, change one part, and explain what changed. Some examples show only part of a program or need tools installed on your computer; follow the instructions beside each example.

<span id="part-2-practice-assignments"></span>

## Practice Java

[Practice Assignments](/java/assignments) gives you programs to build from written requirements. Each programming assignment explains what the program should do and provides a **rubric**, a checklist with points for reviewing your work.

The assignments progress through three tracks:

- **Foundations:** display messages, read values, calculate results, and repeat actions.
- **Objects:** organize a program into parts with separate responsibilities.
- **Collections:** work with groups of values and compare ways to process them.

<span id="remember-that-this-is-for-practice"></span>

## Learn and Practice

Alternate between lessons and assignments. Read an assignment's preparation links before starting it, and return to Fundamentals when it introduces a topic you haven't learned yet. You don't need to finish every Java lesson first.

For example, after Java Setup and Printing, follow [A00: Practice Repository Setup](/java/assignments/a00-practice-repository-setup), then write the message program in [A01: Hello Team](/java/assignments/a01-hello-team). The [practice roadmap](/java/assignments#practice-tracks) explains the later tracks.

Keep completed assignments in the GitHub **repository** created in A00. A repository holds your project files and their recorded history. A00 walks you through saving a checkpoint, called a **commit**, and sending it to GitHub, called a **push**, so your mentor can review it. Running code in a lesson does not submit it.

## Computer Help

The [Tools section](/tools) explains the computer tasks used throughout these lessons:

- [Command Line Basics](/tools/command-line-basics#the-prompt) explains where to type commands and how to read the result.
- [VS Code: Tour](/tools/vscode-tour#the-window) introduces the editor where you'll write and save local programs.
- [Introduction to Version Control](/tools/introduction-to-version-control) explains Git, GitHub, and saved project history before A00 asks you to use them.

For robot examples, the [Hardware section](/hardware) explains the physical devices. Start with [Robot Control System](/hardware/hardware-control-system) when you need to identify a robot part. Hardware work isn't required to run these Java exercises.

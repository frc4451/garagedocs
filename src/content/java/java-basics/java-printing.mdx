### Basic printing

`System.out.println()` prints a line of text to the console. Most of the programs in this track use it to show their results.

### Basic print example

```java
System.out.println("Hello world!");
System.out.println("Welcome to Java programming!");

// Output:
// Hello world!
// Welcome to Java programming!
```

### Program structure

Every Java program has the same outer structure: a class, and inside it a `main` method where execution starts.

### Complete Java program

```java
public class MyProgram {
    public static void main(String[] args) {
        // Your code goes here
        System.out.println("Hello from Java!");
        System.out.println("This is my first program");
    }
}
```

### Key concepts

- **Parameters:** Text inside parentheses that gets printed
- **Semicolon:** Every command must end with `;`
- **Quotation marks:** Text must be enclosed in double quotes `""`
- **Case sensitivity:** `System` must be capitalized exactly

### Multiple lines and comments

```java
public class Example {
    public static void main(String[] args) {
        // Single-line comment
        System.out.println("First line");
        System.out.println("Second line");
        
        /* Multi-line comment
           for longer explanations */
        System.out.println("Third line");
    }
}
```

<RulesBox title="Printing best practices">

**Good Practices:**

- Use meaningful text in your print statements
- Add comments to explain your code
- Use VS Code suggestions to complete method names instead of guessing their spelling
- One command per line for readability

**Avoid:**

- Forgetting semicolons at the end of statements
- Misspelling `println` as `printin`
- Missing quotation marks around text
- Writing everything on one line

</RulesBox>

### Applications in FRC

In robot code, printing to the console is the quickest way to see a value while testing: no dashboard has to be configured first. The output appears in the Driver Station console and in the log.

### FRC console printing example

```java norun
System.out.println("********** Drive FF Characterization Results **********");
System.out.println("\tkS: " + formatter.format(kS));
System.out.println("\tkV: " + formatter.format(kV));
```

### Explanation

The example prints feedforward characterization results (`kS` and `kV`) with a label on each so they can be read from the console. For values you want to watch continuously, or plot, a dashboard or AdvantageScope is the better tool; printing is for one-off checks.

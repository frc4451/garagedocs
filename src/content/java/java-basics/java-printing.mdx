## Print Your First Lines

Printing lets a program show a result. Java sends that result to a **console**, the text area where you read program output. In [Java Setup](/java/fundamentals/setup#compiling-and-running), the console was VS Code's terminal.

The example below is a complete `Main.java` file. Replace the contents of your Setup file with it, save, compile, and run it using the same commands:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
        System.out.println("I am learning to print.");
    }
}
```

The console displays two lines in the same order as the two `println` statements:

```text
Hello, Java!
I am learning to print.
```

The Java code includes punctuation such as braces, parentheses, quotation marks, and semicolons. The output includes only the text between the quotation marks.

## Program Structure

The outer structure tells Java where the program starts. Keep this pattern for the local Java 25 lessons and the Java 17 browser runner:

```java
public class Main {
    public static void main(String[] args) {
        // Statements go here.
    }
}
```

You do not need to memorize the entire `main` line yet. For now, understand the job of each part and copy the pattern carefully.

### The Class Line

`public class Main {` starts a class declaration:

- `public` makes the class accessible to code outside the source file.
- `class` declares a class. A class is a named type that can contain code and data. Later lessons develop that idea; here it holds the program's starting method.
- `Main` is the class name. Because this class is public, save it in a file named `Main.java`.
- `{` opens the class body. The matching final `}` closes it.

Java names are case-sensitive. `Main`, `main`, and `MAIN` are three different names.

### The Main Line

`public static void main(String[] args) {` declares the method where this program begins:

- `public` lets the Java launcher call the method.
- `static` lets the launcher call it without first creating a `Main` object. An object is a value created from a class; later lessons explain how objects work.
- `void` says the method returns no value.
- `main` is the method name the launcher looks for.
- `String[] args` names the parameter that can receive command-line text. Later lessons explain strings and arrays; these first programs leave the parameter unchanged and unused.
- `{` opens the method body. Its matching `}` closes the body.

The method body is the place for the print statements you want Java to run.

### Match the File and Class

Setup used `Main.java` and `public class Main`. When an assignment gives you a different class name, change the filename and the name after `class` together.

For A01, save the file as `HelloTeam.java` and change `Main` after `class` to `HelloTeam`. Keep `public static void main(String[] args)` unchanged. The print statements required by A01 belong inside that `main` method.

## Read a Print Statement

This line is one **statement**, an instruction Java carries out:

```java
System.out.println("Hello, Java!");
```

- `System` is a class supplied by Java.
- `out` is Java's standard output destination. In these lessons, you see it in the console.
- `println` prints a value and then ends the line. The next `println` starts on the next line.
- The parentheses contain the **argument**, the value given to `println`.
- `"Hello, Java!"` is text written as a string literal. Double quotation marks mark where the text begins and ends.
- The semicolon ends the statement.

Change only the text inside the quotation marks, then save, compile, and run again. The console should show the new text while the program structure stays the same.

## Use Comments

A **comment** is a note for a person reading the source file. The compiler ignores it, so comment text does not appear in the console.

```java
public class Main {
    public static void main(String[] args) {
        // This whole line is a comment.
        System.out.println("First line");

        /* A block comment can
           continue across lines. */
        System.out.println("Second line");
    }
}
```

This program prints:

```text
First line
Second line
```

Use comments to explain information the code does not already make clear. A comment such as `// Print first line` only repeats the next statement and does not help the reader.

## Fix a First Error

The compiler cannot compile a file that breaks Java's syntax rules. If you remove the closing quotation mark below, the compiler reports an error near that line:

```java norun
System.out.println("Hello, Java!);
```

Compare the reported line with the working statement. Restore the closing `"`, save the file, and compile it again.

For a print statement that does not compile, check these marks first:

- One opening and one closing double quote around the text
- An opening `(` and a closing `)`
- A semicolon after the closing parenthesis
- Exact capitalization and spelling: `System.out.println`

An error message points you toward a place to inspect. The cause can be earlier on the same line or on the line above it, so compare nearby punctuation too.

## Printing in Robot Code

Printing also provides a quick one-time check in robot code. This partial snippet could appear inside a robot method:

```java norun
System.out.println("Drive test started");
System.out.println("Requested output: 0.25");
```

The snippet is original illustrative code, not a complete program. A deployed robot program's print output appears in the Driver Station Console Viewer and WPILib's RioLog view. Later FRC lessons teach better tools for values you need to watch continuously or plot.

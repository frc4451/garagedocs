Variables give names to values so a program can use those values again. In this lesson, you will store several values, print them, and change one value to see how reassignment affects later output.

The examples build on the complete `Main.java` structure from [Printing](/java/fundamentals/java-printing#program-structure). When you work locally, replace the statements inside `main` with one example at a time. This prevents two examples from declaring the same variable name in one block.

## Declare And Initialize A Variable

This statement both **declares** and **initializes** a variable:

```java
int wheelCount = 4;
```

- `int` is the **type**. It tells Java that this variable stores a whole number.
- `wheelCount` is the variable's name.
- `=` assigns the value on its right to the variable on its left.
- `4` is the variable's first value. Giving a variable its first value is **initialization**.

The semicolon ends the declaration statement. Later statements can read the stored value by using the name:

```java
int wheelCount = 4;
System.out.println(wheelCount);
System.out.println("Wheels: " + wheelCount);
```

The first `println` displays `4`. The second displays `Wheels: 4`. When either side of `+` is a `String`, Java joins the values as text. The Strings lesson develops that operation next.

## Choose A Type

A variable's type limits which values it can store. These four types cover the values used in the first Practice Assignments:

| Type | Stores | Example |
| --- | --- | --- |
| `int` | Whole numbers | `int wheelCount = 4;` |
| `double` | Numbers that can have a fractional part | `double voltage = 12.6;` |
| `boolean` | One of the values `true` or `false` | `boolean enabled = true;` |
| `String` | Text between double quotation marks | `String teamName = "Lightning Bolts";` |

`int`, `double`, and `boolean` are **primitive types** built into the Java language. `String` is a class and therefore a **reference type**. You do not need Java's reference model yet. For now, remember the visible distinction: numbers and Boolean values are written without quotes, while a String literal uses double quotes.

```java
int teamNumber = 4451;
String teamText = "4451";
```

These variables hold different kinds of values. `teamNumber` can take part in arithmetic. `teamText` is text made from the four digit characters.

## Reassign A Value

After initialization, an assignment statement can replace a variable's current value:

```java
int gamePieces = 2;
System.out.println("Before: " + gamePieces);

gamePieces = 5;
System.out.println("After: " + gamePieces);
```

This prints `Before: 2` and then `After: 5`. The second assignment does not repeat `int` because `gamePieces` has already been declared.

The new value must match the declared type. This line does not compile because quoted text is a `String`, not an `int`:

```java norun
int gamePieces = "five";
```

If the compiler reports an incompatible-types error, compare the variable's declared type with the value on the right side of `=`.

## Keep A Value Fixed

Place `final` before a local variable's type when the variable may be assigned only once. This complete program shows the declaration inside `main`:

```java
public class Main {
    public static void main(String[] args) {
        final double HEALTHY_VOLTAGE = 9.0;
        System.out.println("Healthy threshold: " + HEALTHY_VOLTAGE);
    }
}
```

A later assignment to `HEALTHY_VOLTAGE` would be a compile-time error. A fixed, named value prevents the meaning of `9.0` from being lost among other numbers. A02 uses two local `final double` thresholds for this reason.

Java naming conventions use `UPPER_CASE_WITH_UNDERSCORES` for constants such as `HEALTHY_VOLTAGE`. Use lower camel case for ordinary local variables, such as `wheelCount` and `teamName`.

## Follow Rules And Conventions

Java enforces identifier rules. Naming conventions are choices that make code easier to read.

| Kind | Guidance |
| --- | --- |
| Java rule | A name cannot start with a digit, contain a space or hyphen, or be a Java keyword such as `class` or `public`. |
| Project convention | Start an ordinary local-variable name with a lowercase letter and use lower camel case for additional words. |
| Project convention | Give the value a descriptive name such as `motorOutput` instead of an unexplained name such as `m`. |
| Constant convention | Use `UPPER_CASE_WITH_UNDERSCORES` for a fixed constant declared with `final`. |

Java also permits `$` and `_` in many identifier positions, although `_` cannot be a name by itself. This curriculum starts names with a letter, avoids `$`, and uses underscores in constant names.

## Use A Variable Inside Its Scope

A local variable's **scope** is the part of the block where its name can be used. A block is code enclosed by matching braces. The `main` method body is one block.

```java
int checksPassed = 2;

{
    String status = "Ready";
    System.out.println(status);
    System.out.println(checksPassed);
}

System.out.println(checksPassed);
// status cannot be used here because its block has ended.
```

`checksPassed` remains available through the rest of the `main` block. `status` is available only from its declaration to the closing brace of the smaller block. Later lessons introduce fields, which use different scope rules.

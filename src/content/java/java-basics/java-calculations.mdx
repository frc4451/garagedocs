Java can calculate a value before storing or printing it. This lesson uses arithmetic you already know and focuses on how Java reads each expression.

The examples are statements that belong inside the `main` method from [Printing](/java/fundamentals/java-printing#the-main-line). Replace the statements inside `main` with one example at a time. Predict each result, then run the example and compare the output with your prediction.

## Use Arithmetic Operators

An **operator** is a symbol that tells Java which calculation to perform. Each value an operator works on is an **operand**. These five operators work with `int` and `double` values:

| Operator | Operation | Example | Result |
| --- | --- | --- | --- |
| `+` | Addition | `7 + 2` | `9` |
| `-` | Subtraction | `7 - 2` | `5` |
| `*` | Multiplication | `7 * 2` | `14` |
| `/` | Division | `7.0 / 2.0` | `3.5` |
| `%` | Remainder after division | `7 % 2` | `1` |

Java uses `*` for multiplication. The letter `x` can be a variable name, so it does not mean multiplication in Java code. Use names that include the unit when the unit matters:

```java
double lengthMeters = 4.5;
double widthMeters = 2.0;
double areaSquareMeters = lengthMeters * widthMeters;

System.out.println("Area: " + areaSquareMeters + " square meters");
```

This prints:

```text
Area: 9.0 square meters
```

The expression `lengthMeters * widthMeters` produces a value. The complete line ending in a semicolon is a statement that stores that value in `areaSquareMeters`.

The remainder operator helps when one amount must be divided into equal groups:

```java
int parts = 23;
int partsPerBin = 5;
int fullBins = parts / partsPerBin;
int partsLeft = parts % partsPerBin;

System.out.println("Full bins: " + fullBins);
System.out.println("Parts left: " + partsLeft);
```

This prints `Full bins: 4` and `Parts left: 3`. Four full bins use 20 parts, leaving 3.

## Control The Order

Java applies these arithmetic operators in this order:

1. Expressions inside parentheses
2. Multiplication `*`, division `/`, and remainder `%`, from left to right
3. Addition `+` and subtraction `-`, from left to right

This order is called **operator precedence**. Parentheses make the grouping explicit and can change a result:

```java
int usualOrder = 2 + 3 * 4;
int groupedOrder = (2 + 3) * 4;
int sameLevel = 20 / 5 * 2;

System.out.println(usualOrder); // 14
System.out.println(groupedOrder); // 20
System.out.println(sameLevel); // 8
```

For `usualOrder`, Java multiplies `3 * 4` before adding `2`. For `sameLevel`, division and multiplication have the same precedence, so Java works from left to right: `(20 / 5) * 2` gives `8`.

Use parentheses when they express the calculation you intend. Extra parentheses can also help a reader see the grouping, even when they do not change the result.

## Compare Integer And Decimal Division

When both operands are integers, `/` performs **integer division**. The result is an integer, so Java discards the fractional part by rounding toward zero:

```java
System.out.println(7 / 2);   // 3
System.out.println(-7 / 2);  // -3
System.out.println(-7 % 2);  // -1
```

The negative example matters because rounding toward zero gives `-3`, rather than rounding down to `-4`. The quotient and remainder still fit the original number: `(-3 * 2) + -1` equals `-7`.

If either operand is a `double`, Java performs floating-point division and can keep a fractional result:

```java
System.out.println(7.0 / 2);  // 3.5
System.out.println(7 / 2.0);  // 3.5
```

The operand types choose the kind of division. The variable that receives the result does not change a calculation that has already happened:

```java
double stillIntegerDivision = 7 / 2;
System.out.println(stillIntegerDivision); // 3.0
```

Both operands are integers, so `7 / 2` produces `3`. Java then stores that result as the `double` value `3.0`.

A **cast** asks Java to convert a value to another type for an expression. Cast an operand before division when two `int` variables need a fractional quotient:

```java
int completedTasks = 7;
int totalGroups = 2;

double convertedBefore = (double) completedTasks / totalGroups;
double convertedAfter = (double) (completedTasks / totalGroups);

System.out.println(convertedBefore); // 3.5
System.out.println(convertedAfter);  // 3.0
```

`(double) completedTasks` becomes `7.0` before Java divides, so the first expression uses floating-point division. In the second expression, `completedTasks / totalGroups` produces the integer `3` first. Converting that completed result to `double` produces `3.0`; the discarded fraction cannot return.

The `double` type has limited precision, so some decimal results are approximations. It is still the appropriate type here when the calculation needs a fractional result.

<RulesBox title="Division Checks">

- Check the types of both operands when a fraction disappears.
- Use a decimal literal such as `7.0`, a `double` variable, or a cast before division when you need a fractional result.
- Parenthesize the numerator when several values must be combined before division.
- When both operands are integers, using zero as the right operand of `/` or `%` stops the calculation with a runtime error named `ArithmeticException`. Later lessons explain how programs respond to exceptions.

</RulesBox>

## Calculate Before Joining Text

The `+` operator adds numbers and joins strings. Java groups consecutive `+` operations from left to right. Once a string is one of the two values, that operation joins text:

```java
System.out.println("Result: " + 2 + 3);
System.out.println("Result: " + (2 + 3));
System.out.println(2 + 3 + " total");
```

This prints:

```text
Result: 23
Result: 5
5 total
```

The first line joins `"Result: "` with `2`, producing the text `"Result: 2"`, and then joins `3`. The second line calculates inside the parentheses first. The third line adds `2 + 3` before Java reaches the string.

## Copy Primitive Values

For the primitive numeric values in this lesson, assignment copies the current value. Reassigning the first variable later does not update the copy:

```java
int availableParts = 5;
int recordedParts = availableParts;

availableParts = 10;

System.out.println("Available: " + availableParts);
System.out.println("Recorded: " + recordedParts);
```

This prints:

```text
Available: 10
Recorded: 5
```

The assignment `recordedParts = availableParts` reads the value `5` and stores it in `recordedParts`. Later lessons explain how assignment behaves for variables that refer to objects.

An array stores a fixed number of values of one type. Its **length** is the number of slots, and each slot has an **index**, starting at zero.

### Creating arrays - basic types

```java
int[] readings = {4, 8, 15};
System.out.println(readings.length);
System.out.println(readings[0]);
readings[1] = 10;
System.out.println(readings[1]);
```

This prints `3`, `4`, and `10` on separate lines. Square brackets select one element. For length 3, the valid indices are 0, 1, and 2.

You can also create slots before you know their values:

```java
double[] distances = new double[3];
distances[0] = 1.5;
System.out.println(distances[1]);
```

Numeric slots start at zero, so this prints `0.0`. Boolean slots start at `false`.

### Walk an array with a loop

```java
int[] readings = {4, 8, 15};
int total = 0;
for (int i = 0; i < readings.length; i++) {
    System.out.println(readings[i]);
    total += readings[i];
}
System.out.println("Total: " + total);
```

The three readings print before `Total: 27`. Use `i < readings.length`: the length itself is not a valid index.

A **for-each loop** reads each value when you do not need its index:

```java
String[] names = {"drive", "intake", "launcher"};
for (String name : names) {
    System.out.println(name);
}
```

Read the header as “for each String named name in names.”

### Rows and columns

A two-dimensional array is an array of arrays. In this example each row holds a distance in meters and a speed in RPM:

```java
double[][] samples = {{1.0, 2200.0}, {2.0, 2800.0}};
System.out.println(samples[1][0]);
System.out.println(samples[1][1]);
```

This prints `2.0` and `2800.0`. The first index chooses a row; the second chooses an element in that row. Rows can have different lengths, so use `samples[row].length` for a row's size.

### Arrays of objects

String is an object type. `new String[3]` starts with three `null` references, not three empty strings. Assign a String before calling one of its methods.

The worked examples for your own classes are in [Object arrays](/java/fundamentals/java-arrays-and-their-trade-offs#object-arrays). They use the Classes and Objects lessons.

### String arrays example

```java
String[] names = "Avery Lee".split(" ");
System.out.println(names[0]);
System.out.println(names[1]);
```

This prints `Avery` and `Lee`. A string uses `length()`; an array uses the field `length` without parentheses.

### Array length and stored values

The length stays fixed. Assigning `readings[0]` replaces one value; it does not add a slot. If the program needs a different length, create another array.

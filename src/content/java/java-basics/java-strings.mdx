A `String` stores text, such as a student name or a status message. Write a string literal between double quotes. A `char` holds one UTF-16 code unit and uses single quotes; the letters in the examples each fit in one `char`.

### Read and combine text

```java
String name = "Avery";
System.out.println("Hello, " + name);
System.out.println(name.length());
System.out.println(name.charAt(0));
```

The output is `Hello, Avery`, then `5`, then `A`. The `+` joins text. The first character is at index `0`; the last is at `length() - 1`. Reading an index outside that range throws an exception.

### Useful String methods

| Call | What it does | Result |
|---|---|---|
| `"Robot".length()` | Counts UTF-16 code units | `5` |
| `"Robot".charAt(1)` | Reads the character at index 1 | `'o'` |
| `"Robot".substring(1, 4)` | Takes indices 1 through 3; excludes index 4 | `"obo"` |
| `"robot".indexOf("bot")` | Finds the first matching index | `2` |
| `"robot".indexOf("z")` | Reports no match | `-1` |
| `" drive ".trim()` | Removes leading and trailing basic whitespace | `"drive"` |
| `"Robot".toLowerCase()` | Produces lowercase text | `"robot"` |
| `"sc-rock".replace("-", "")` | Replaces literal text | `"scrock"` |
| `"robot".equals("Robot")` | Compares text, including case | `false` |
| `"robot".equalsIgnoreCase("Robot")` | Compares text without case differences | `true` |

These examples use English text. Case conversion can depend on the computer's locale. For machine identifiers such as event keys, use `toUpperCase(java.util.Locale.ROOT)` or `toLowerCase(java.util.Locale.ROOT)` to make that choice explicit.

### Strings do not change in place

A String is **immutable**: its text cannot be changed after creation. Methods that transform text return a result for you to use. They do not replace your variable automatically.

```java
String raw = "  Avery  ";
String cleaned = raw.trim();
System.out.println("[" + raw + "]");
System.out.println("[" + cleaned + "]");
```

The first line still contains the spaces. To keep the cleaned text in `raw`, assign it: `raw = raw.trim();`.

Use `equals` to compare String content. `==` asks whether references identify the same object; equal text does not guarantee that.

### Splitting and replacing patterns

`split` and `replaceAll` accept a **regular expression**, a pattern describing text. You only need one pattern for A03: `"\\s+"` means one or more whitespace characters. The Java string uses two backslashes to represent one backslash in the pattern.

```java
String cleaned = "Avery   Lee".replaceAll("\\s+", " ");
System.out.println(cleaned);
```

This prints `Avery Lee`. After [Arrays](/java/fundamentals/java-arrays), use `cleaned.split(" ")` to get one array element per word. Use `replace` when you mean literal text rather than a pattern.

2. Predict `"drive".substring(1, 4)`, then run it.
3. Remove surrounding spaces from `"  Intake  "` and convert it to lowercase.
4. Compare `"Java"` with `"java"` using both equality methods in the table.
5. Store the result of a transformation in another variable. Show that the original text stayed unchanged.

Check each result before continuing. If a character index fails, compare it with the string's length.

A `String` stores text, such as a student name, an event code, or a status message. This lesson shows how to write text in Java source, inspect its positions, compare it, and save transformed results.

The shorter examples belong inside the `main` method from [Printing's complete program structure](/java/fundamentals/java-printing#program-structure). Replace the statements inside `main` with one example at a time so repeated names such as `name` do not collide.

## Write String Literals

A **String literal** is text enclosed by double quotation marks:

```java
String robotName = "Riptide";
String empty = "";
```

The quotation marks are Java syntax and are not part of the stored text. `empty` holds a String with no characters.

An **escape sequence** starts with a backslash and represents text that would otherwise be difficult to put inside a literal:

```java
System.out.println("Drive \"ready\"");
System.out.println("First line\nSecond line");
System.out.println("Folder: C:\\robot-code");
```

The output is:

```text
Drive "ready"
First line
Second line
Folder: C:\robot-code
```

Use `\"` for a double quote, `\n` for a new line, and `\\` for one backslash in the stored text.

## Call A String Method

A **method call** runs a named operation. Printing introduced `System.out.println(...)`; String calls use the same parentheses pattern.

```java
String name = "Avery";
int count = name.length();
char first = name.charAt(0);
```

In `name.length()`, the value before the dot is the String to inspect, `length` is the method name, and the empty parentheses mean this call takes no argument. The call returns the result `5`, which the code stores in `count`.

`name.charAt(0)` gives the method one argument: the index `0`. It returns the `char` value `'A'`. A `char` uses single quotation marks and holds one text unit. An ordinary letter such as `A` fits in one `char`.

The later Methods lesson teaches how to write your own methods. Here, you only need to recognize a call, its arguments, and its returned result.

## Read Positions And Ranges

String indexes begin at `0`, so the five positions in `"Avery"` are:

| Index | `0` | `1` | `2` | `3` | `4` |
| --- | --- | --- | --- | --- | --- |
| `char` value | `'A'` | `'v'` | `'e'` | `'r'` | `'y'` |

For a nonempty String, the last valid index is `length() - 1`. `charAt` requires an index from `0` through `length() - 1`:

```java
String name = "Avery";
System.out.println(name.charAt(0));
System.out.println(name.charAt(name.length() - 1));
```

This prints `A` and `y`. The empty String has length `0`, so it has no valid index for `charAt`.

`substring(start, end)` returns text from the start index up to, but excluding, the end index:

```java
String word = "drive";
System.out.println(word.substring(1, 4));
System.out.println(word.substring(0, word.length()));
```

This prints `riv` and then `drive`. A substring may use `length()` as its end index. The start must be from `0` through `length()`, the end must be from the start through `length()`, and the start cannot be greater than the end.

An index outside these bounds causes an `IndexOutOfBoundsException`. An **exception** is an error reported while the program runs. If this exception occurs, print or calculate the String's length and compare it with the attempted indexes.

<RulesBox title="Optional Unicode Detail">

Java represents String text using **UTF-16 code units**. Each code unit occupies one numbered position used by `length`, indexes, and `charAt`. The letters in these examples use one code unit each, while some symbols, including many emoji, use two. The number returned by `length()` therefore does not always match the number of symbols you see.

</RulesBox>

## Use Common Operations

These calls cover the text operations used in the next beginner lessons:

| Call | Result | Meaning |
| --- | --- | --- |
| `"Robot".length()` | `5` | Return the number of UTF-16 code units. |
| `"Robot".charAt(1)` | `'o'` | Return the `char` at index 1. |
| `"Robot".substring(1, 4)` | `"obo"` | Return indexes 1 through 3. |
| `"robot".indexOf("bot")` | `2` | Return the first matching index. |
| `"robot".indexOf("z")` | `-1` | Report that no match exists. |
| `" drive ".trim()` | `"drive"` | Remove surrounding ordinary spaces, tabs, and line breaks. It does not remove every Unicode whitespace character. |
| `"Robot".toLowerCase()` | `"robot"` | Return a lowercase result. |
| `"robot".toUpperCase()` | `"ROBOT"` | Return an uppercase result. |
| `"sc-rock".replace("-", "")` | `"scrock"` | Replace literal text. |

Use `+` to concatenate, or join, text:

```java
String teamName = "ROBOTZ Garage";
int teamNumber = 4451;
String label = teamNumber + " " + teamName;
System.out.println(label);
```

This prints `4451 ROBOTZ Garage`.

## Keep Transformation Results

A String is **immutable**: its text cannot change after the String is created. Methods such as `trim` and `toLowerCase` return a String containing the result. They do not replace the value in your variable automatically.

```java
String raw = "  Intake  ";
String cleaned = raw.trim().toLowerCase();

System.out.println("[" + raw + "]");
System.out.println("[" + cleaned + "]");
```

The first line still shows the surrounding spaces. The second shows `[intake]`. The code calls `trim()`, then calls `toLowerCase()` on the returned text. This is a **method chain**.

To make `raw` refer to the transformed result, reassign it with `raw = raw.trim();` after its declaration. The variable changes which String it refers to. The original String itself does not change.

## Compare Text Content

Use `equals` when capitalization matters and `equalsIgnoreCase` when it does not:

```java
String entered = "ready";
System.out.println(entered.equals("ready"));
System.out.println(entered.equals("Ready"));
System.out.println(entered.equalsIgnoreCase("Ready"));
```

This prints `true`, `false`, and `true`. For text comparison, do not use `==`. The `==` operator checks whether two variables refer to the same object. Java can reuse literal Strings, so a `==` test may appear to work for literals and fail when equivalent text comes from input.

<RulesBox title="Optional Locale Detail">

The no-argument case methods use the computer's default locale. For software identifiers such as event keys, make the choice independent of the computer with `text.toUpperCase(java.util.Locale.ROOT)` or `text.toLowerCase(java.util.Locale.ROOT)`. Names written for people can require language-specific rules beyond these beginner examples.

</RulesBox>

## Preview Patterns And Splitting

The next example is reference material for A03. A **regular expression** is a pattern that describes text. `replaceAll` treats its first argument as a regular expression:

```java
String cleaned = "Avery   Lee".replaceAll("\\s+", " ");
System.out.println(cleaned);
```

This prints `Avery Lee`. The regular-expression pattern `\s+` means one or more whitespace characters. In Java source, the literal uses `"\\s+"` because `\\` places one backslash into the pattern. Use `replace` instead when the target is literal text rather than a pattern.

`split` also accepts a regular expression and returns a String array. Arrays are taught later, so treat `cleaned.split(" ")` as a preview until you complete [Arrays](/java/fundamentals/java-arrays). A03 also requires [Methods](/java/fundamentals/java-methods), loops, `null` handling, and `Character` helper calls. Finish those prerequisites before treating A03 as required practice.

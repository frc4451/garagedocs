A **program** is a set of instructions a computer can carry out. **Java** is one language we can use to write those instructions. In this lesson, you'll trace a small task in ordinary words before you begin writing Java.

You don't need programming experience. Bring a computer with a browser and be ready to try an example, explain a result, and ask for help when a step is unclear.

## Instructions and Results

Suppose you want to count the wheels needed for three carts, with four wheels on each cart. The task has three parts:

| Part | In This Example |
| --- | --- |
| **Input:** information the program receives. | The number of carts: 3. |
| **Instructions:** what to do with that information. | Multiply the number of carts by 4. |
| **Output:** the result the program produces. | Display the number of wheels: 12. |

We can describe those instructions in ordinary words: read the number of carts, multiply it by four, and display the result. Later lessons teach the Java notation for each step. For now, follow the calculation and distinguish the information going in from the result coming out.

If we accidentally tell the computer to add four instead, it would calculate seven. A program can run and still produce the wrong result. Checking the result against the task is part of writing the program.

## Try It

Use the same wheel-counting instructions with five carts. Before reading on, identify the input, the calculation, and the output. You can work on paper; this check doesn't require Java code.

The input is five carts. Multiplying five by four gives an output of twenty wheels. Explain why changing the number of carts changed the result while the instruction stayed the same.

## How Java Runs

The instructions you write in Java are called **source code**. A **compiler** checks the source code against Java's rules and translates it into a form the Java runtime can execute. The **runtime** is the software that carries out the translated instructions.

These are two different checks: the compiler checks whether the code follows the language's rules, and you check whether the running program does the task you intended. The wrong calculation in our cart example could pass the first check and fail the second.

When a lesson provides a **Run** button, the browser exercise handles compiling and running for you. It needs internet and uses Java 17. Some examples show only part of a program or require tools installed on your computer, so follow each example's instructions before trying it.

For a longer explanation, the official [Getting Started with Java](https://dev.java/learn/getting-started/) guide describes the compilation and execution process. This is optional reading. Its examples may use a newer Java version; follow GarageDocs' setup instructions for this curriculum.

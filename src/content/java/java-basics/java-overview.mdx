This track teaches Java from the first program to the structures robot code is built from. It assumes no programming experience. If you have written Java before, skim the Basics group and start where the material becomes new.

### Why Java

FRC teams can write robot code in Java, C++, or Python. FRC 4451 uses Java.

Everything here transfers directly to robot code: a WPILib subsystem is a class, a command is an object, and a joystick reading is a method call.

### How the track is organized

Ten groups, in sidebar order. Each builds on the one before.

- **Java Basics:** installing Java, printing, variables, calculations, the `Math` class, arrays, and packages.
- **Programming Logic:** conditionals, methods, and try/catch.
- **Loops and Iteration:** while and for loops, break and continue, and structuring a program around a loop.
- **Object-Oriented Programming:** classes, objects, references, overloading, inheritance, abstract classes, interfaces, generics, and runtime polymorphism.
- **Data Structures:** arrays, ArrayLists, linked lists, stacks, queues, deques, sets and maps, trees, and graphs.
- **Programming Math:** Boolean logic, discrete math, vectors, and matrices.
- **Common Algorithms:** Big-O, recursion, searching, sorting, tree traversals, depth-first and breadth-first search, shortest paths, backtracking, and memoization.
- **Functions as Data:** lambdas, method references, suppliers, and streams.
- **Design Patterns:** factory methods, dependency injection, and the command pattern.
- **Concurrency and Multithreading:** threads, race conditions, executors, and concurrent collections.

### How to work through it

- Take the lessons in order; each assumes the ones before it.
- Run every example. The code in these lessons runs in the browser: press *Run*, change something, and run it again.
- Do the exercises at the end of each lesson before moving on. Answers are provided, but reading one is not the same as writing it.
- After each group, the matching [Practice Assignments](/java/assignments) give you a program to write from scratch, with checks that tell you whether it works.
- Use search (top of the page) to find a topic again later.

### What you need

A computer with a web browser. The lesson examples run in the browser, so nothing has to be installed for the lessons themselves. The next lesson, [Setting Up Java](/java/fundamentals/java-setup), covers the local install the Practice Assignments use, with an online fallback for machines where you cannot install software.

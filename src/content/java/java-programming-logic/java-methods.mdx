## What a Method Does

A method gives a name to a block of code. A **method call** runs that block, then the program continues after the call. You have already called methods such as `System.out.println()` and `Integer.parseInt()`.

Methods keep related work together. A clear name tells the reader what the block does, and several parts of a program can call the same method instead of repeating its statements.

## Declare and Call a Method

Replace the contents of `Main.java` with this complete program. It declares `greet` inside the class and outside `main`. Run it with the local compile-and-run steps from [Java Setup](/java/fundamentals/java-setup).

```java
public class Main {
    public static void main(String[] args) {
        greet();
        greet();
    }

    public static void greet() {
        System.out.println("Robot ready!");
    }
}
```

The output is:

```text
Robot ready!
Robot ready!
```

The declaration starts with `public static void greet()`. The braces contain the method body. The statement `greet();` is a call. Each call runs the same body once.

<RulesBox title="Method Declaration">

- **`public`:** Code in other classes can call the method.
- **`static`:** The method belongs to the class, so these console programs can call it without creating an object.
- **Return type:** `void` means the method does not send a value back. A type such as `int`, `double`, or `String` says what type of value the method returns.
- **Method name:** Use a descriptive verb or verb phrase in camel case, such as `readSensor` or `calculateArea`.
- **Parameters:** Inputs appear between the parentheses. Empty parentheses mean the method has no parameters.
- **Method body:** The statements between the braces run when the method is called.

</RulesBox>

For now, keep the `public static` scaffold on every method you write. Instance methods are introduced after the lessons on classes and objects.

## Parameters and Arguments

A **parameter** is a named input in a method declaration. An **argument** is the value supplied by a particular call. Java copies each argument's value into the matching parameter.

Replace `Main.java` with this complete program. It passes two different arguments to the `name` parameter:

```java
public class Main {
    public static void main(String[] args) {
        greet("Pit crew");
        String group = "Drive team";
        greet(group);
    }

    public static void greet(String name) {
        System.out.println("Hello, " + name + "!");
    }
}
```

The first call copies the argument `"Pit crew"` into `name`. The second copies the current value of `group`. The parameter `name` is local to `greet`, so code in `main` cannot use that local name.

The program prints:

```text
Hello, Pit crew!
Hello, Drive team!
```

Methods can have several parameters. List each parameter as a type and a name, separated by commas. Calls supply arguments in the same order. Replace `Main.java` with this complete program:

```java
public class Main {
    public static void main(String[] args) {
        printDriveCommand(0.8, 0.2);
    }

    public static void printDriveCommand(double forward, double turn) {
        System.out.println("Forward: " + forward);
        System.out.println("Turn: " + turn);
    }
}
```

Here, `0.8` matches `forward` and `0.2` matches `turn`.

The program prints:

```text
Forward: 0.8
Turn: 0.2
```

## Return a Value

A returning method computes a value and sends it to the caller with `return`. The declared return type must be compatible with that value. For example, a method that returns an `int` value can declare a `double` return type because Java can widen an `int` to a `double`.

A `return` statement immediately ends the current method call. The returned value becomes the result of the call. Printing displays text in the console and does not send a value back to the caller.

Replace `Main.java` with this complete program:

```java
public class Main {
    public static void main(String[] args) {
        double panelArea = area(4.5, 2.0);
        System.out.println("Area: " + panelArea);
    }

    public static double area(double length, double width) {
        return length * width;
    }
}
```

The call `area(4.5, 2.0)` evaluates to `9.0`. `main` stores that returned value in `panelArea`, then prints it. The `area` method does not decide how the caller will use the result. Another caller could compare it, include it in a calculation, or print it with different text.

Use a `void` method when the method performs an action and the caller does not need a result. Use a returning method when the caller needs the computed value.

```java norun
public static void printArea(double area) {
    System.out.println("Area: " + area);
}

public static double area(double length, double width) {
    return length * width;
}
```

This is a partial snippet containing two methods. Both belong inside a class and outside every other method. `printArea` prints and returns no value. `area` returns a `double` and prints nothing. Keeping those jobs separate lets the caller choose what to do with the calculation.

## Return from Every Path

A method with a non-`void` return type must return a value on every path that can reach the end of the method. An `if`/`else` can return one value from each branch. Replace `Main.java` with this complete program:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(labelMeasurement(12.4));
        System.out.println(labelMeasurement(11.7));
    }

    public static String labelMeasurement(double value) {
        if (value >= 12.0) {
            return "UPPER";
        } else {
            return "LOWER";
        }
    }
}
```

The program prints `UPPER` and then `LOWER`. Both possible branches return a `String`. If the `else` branch were removed, a value below `12.0` could reach the closing brace without a return value, so the compiler would report a missing return statement.

You now have the method syntax needed for [Return After Methods](/java/fundamentals/java-control-structures#return-after-methods), the deferred `zone(int)` playground in Control Structures. Use the branch ordering from [Conditionals](/java/fundamentals/java-conditionals) and make sure every possible distance returns a `String`.

## Methods Can Call Methods

A method can call another method. Replace `Main.java` with this complete program, which separates a calculation from the message that uses it. This example requires a positive speed:

```java
public class Main {
    public static void main(String[] args) {
        reportTravelTime(6.0, 2.0);
    }

    public static void reportTravelTime(double distanceMeters, double speedMetersPerSecond) {
        double seconds = travelTime(distanceMeters, speedMetersPerSecond);
        System.out.println("Travel time: " + seconds + " seconds");
    }

    public static double travelTime(double distanceMeters, double speedMetersPerSecond) {
        return distanceMeters / speedMetersPerSecond;
    }
}
```

The calls run in this order: `main` calls `reportTravelTime`, and `reportTravelTime` calls `travelTime`. When `travelTime` returns `3.0`, `reportTravelTime` stores the value and prints `Travel time: 3.0 seconds`.

Each active call has its own local variables and parameters. Java tracks those calls on the **call stack**. When a method returns, its call ends and execution continues in the caller. You can usually debug a short program by tracing the calls in order before studying the call stack in more depth.

## Method Names

By convention, Java method names start with a lowercase letter and capitalize each later word. This style is called camel case. The compiler accepts other valid identifiers, but following the convention makes code familiar to other Java programmers. Use a verb or verb phrase that describes the method's job:

```java norun
public static void printSensorStatus() {
    System.out.println("Sensors available");
}

public static double calculateMotorOutput(double request) {
    return request * 0.5;
}
```

This is a partial snippet. Both methods belong inside a class and outside every other method. Names such as `doStuff` and `x` hide the method's purpose. Clear names make a sequence of calls easier to read.

## The Main Method

For these console programs, Java starts with `main`. Calls from `main` lead to the other `public static` methods you write. Keep every method declaration inside the class braces and outside the braces of `main` or any other method.

## Choose a Path

A conditional statement lets a program choose which statements to run. The choice comes from a **condition**, an expression whose value is either `true` or `false`.

This lesson builds complete programs with `if`, `else if`, and `else`. You will compare numbers and strings, combine conditions, and check the values on either side of a boundary.

## Write an If Statement

An `if` statement evaluates the condition inside its parentheses. When the condition is `true`, Java runs the block after it. When the condition is `false`, Java skips that block.

Comparison operators build conditions from values you already know. Read `count >= 3` as “count is greater than or equal to 3.” One equal sign, `=`, assigns a value to a variable. Two equal signs, `==`, compare two values. An accidental number or string assignment in an `if` condition causes a compiler error, but a boolean assignment can compile and change the variable. For a numeric equality comparison, use `==`. A boolean variable can be the condition itself. The sections below explain String comparisons and logical operators.

This complete program checks whether a game piece count has reached a target. To run it locally, replace the entire contents of `Main.java` with this program and use the steps from [Java Setup](/java/fundamentals/setup).

```java
public class Main {
    public static void main(String[] args) {
        int gamePieceCount = 3;

        if (gamePieceCount >= 3) {
            System.out.println("Target reached");
        }

        System.out.println("Count checked");
    }
}
```

The condition is `true`, so the program prints both lines. Change `gamePieceCount` to `2`. Java skips `Target reached` and still prints `Count checked` because that statement is below the conditional.

## Mark Each Block

The braces after an `if` enclose a **code block**. Indent the statements inside a block by four spaces so readers can see which statements the condition controls. Java uses the braces to determine the block, so misleading indentation can hide a mistake.

This partial snippet belongs inside `main`. Replace the other statements inside `main` while you try it. Both statements run only when the condition is `true`.

```java
int requestedOutputPercent = 75;

if (requestedOutputPercent > 50) {
    System.out.println("Requested output is above 50 percent");
    requestedOutputPercent = 50;
}
```

Keep the opening and closing braces even when a block contains one statement. The braces make later edits safer because every added statement has an explicit block.

## Check a Boundary

The boundary value determines which operator to use. If `positionMeters >= 2.0` marks the far zone, exactly `2.0` belongs in that zone. With `>`, it would not.

This partial snippet belongs inside `main`. Try it by itself inside that method:

```java
double positionMeters = 2.0;

System.out.println(positionMeters < 2.0);   // false
System.out.println(positionMeters == 2.0);  // true
System.out.println(positionMeters >= 2.0);  // true
```

Before writing a condition, state what happens below the boundary, at the boundary, and above the boundary. Then choose the operator that matches those three cases.

## Choose between Two Paths

Add `else` when exactly one of two paths should run. Java runs the `if` block when its condition is `true`; otherwise, it runs the `else` block.

This complete program divides a practice field at `5.0` meters. To run it locally, replace the entire contents of `Main.java`.

```java
public class Main {
    public static void main(String[] args) {
        double positionMeters = 5.0;

        if (positionMeters >= 5.0) {
            System.out.println("Far zone");
        } else {
            System.out.println("Near zone");
        }

        System.out.println("Position classified");
    }
}
```

At `5.0`, the program prints `Far zone` and then `Position classified`. Test `4.9` and `5.1` as well. These three values check the boundary and the values immediately on each side.

Two separate `if` statements make two independent decisions, so both blocks can run when both conditions are `true`. An `if`/`else if`/`else` chain makes one decision: Java runs the first true branch's block and skips the other branches.

## Choose between Several Paths

Use `else if` when one value can belong to three or more groups. Java checks conditions from top to bottom and runs the first true branch's block. If no condition is true, Java runs the final `else` block.

This complete program uses two boundaries to create three zones:

```java
public class Main {
    public static void main(String[] args) {
        double distanceMeters = 7.0;

        if (distanceMeters < 5.0) {
            System.out.println("Near zone");
        } else if (distanceMeters < 10.0) {
            System.out.println("Middle zone");
        } else {
            System.out.println("Far zone");
        }
    }
}
```

The middle condition means “at least `5.0` and less than `10.0`” because Java reaches it only after `distanceMeters < 5.0` is false. Test `4.9`, `5.0`, `9.9`, and `10.0` to check both boundaries.

<RulesBox title="Order of Execution" subtitle="Important Rules">

- Conditions are checked from **top to bottom**.
- Java runs the block for the **first branch whose condition is true**.
- Once a condition is true, Java skips the remaining branches.
- Order the conditions so that each value reaches the intended branch.

</RulesBox>

## Order the Branches

This partial snippet belongs by itself inside `main`. The most specific score range comes first.

```java
int score = 100;

if (score == 100) {
    System.out.println("Perfect score");
} else if (score >= 80) {
    System.out.println("Target reached");
} else if (score >= 50) {
    System.out.println("Near target");
} else {
    System.out.println("Below target");
}
```

The equality check must come before `score >= 80`. If the broader condition came first, a score of `100` would reach that branch and Java would skip `Perfect score`.

## Comparing Strings

Use `.equals()` to compare the characters stored in two strings. The `==` operator compares whether the variables refer to the same object, so it does not answer the content question reliably.

This complete program compares a command entered with different capitalization:

```java
public class Main {
    public static void main(String[] args) {
        String expectedCommand = "start";
        String enteredCommand = "START";

        if (enteredCommand.equals(expectedCommand)) {
            System.out.println("Exact match");
        } else if (enteredCommand.equalsIgnoreCase(expectedCommand)) {
            System.out.println("Same letters, different capitalization");
        } else {
            System.out.println("Different command");
        }
    }
}
```

The program prints `Same letters, different capitalization`. Change `enteredCommand` to `"start"`, then to `"stop"`, to reach the other branches.

## Combine Conditions

Logical operators build one condition from boolean expressions. `&&` means both expressions must be `true`. `||` means at least one must be `true`. `!` reverses one boolean value.

Java evaluates `&&` from left to right and stops as soon as one operand is `false`. It evaluates `||` from left to right and stops as soon as one operand is `true`. This **short-circuit evaluation** means Java might not evaluate the right operand.

### AND, OR, and NOT

This complete program demonstrates all three operators with bounded, observable inputs:

```java
public class Main {
    public static void main(String[] args) {
        boolean enabled = true;
        boolean connected = false;
        boolean buttonA = false;
        boolean buttonB = true;

        if (enabled && connected) {
            System.out.println("Enabled and connected");
        }

        if (buttonA || buttonB) {
            System.out.println("At least one button is pressed");
        }

        if (!connected) {
            System.out.println("Connection is absent");
        }
    }
}
```

The program prints the second and third messages. Change one boolean at a time and predict the output before you run it.

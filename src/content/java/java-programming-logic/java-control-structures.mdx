## Follow The Program

Java normally runs statements from top to bottom. A **control structure** changes that path. A decision selects a block of statements, while a loop repeats a block.

This page is a preview. Trace the examples to see the path through each program. The next lessons teach you how to write these structures yourself.

Each example below is a complete program. To run one locally, replace all the code in `Main.java` with that example. Save, compile, and run one example at a time by following [Java Setup](/java/fundamentals/java-setup). Do not paste several `public class Main` programs into the same file. Review [Printing](/java/fundamentals/java-printing) if you need a reminder about the program wrapper or console output.

## If/Else Statements

An `if` statement tests a condition that is either `true` or `false`. In this preview, `>` means “greater than.” Java runs the first branch whose condition is `true` and skips the other branches. This complete program uses an invented numeric level so you can focus on the Java logic:

```java
public class Main {
    public static void main(String[] args) {
        int level = 75;

        if (level > 80) {
            System.out.println("HIGH");
        } else if (level > 50) {
            System.out.println("MIDDLE");
        } else {
            System.out.println("LOW");
        }
    }
}
```

Trace the conditions from top to bottom:

1. `level > 80` is `false` because 75 is not greater than 80.
2. `level > 50` is `true` because 75 is greater than 50.
3. Java prints `MIDDLE` and skips the final `else` branch.

Change `level` to `50` and trace the program again. Both conditions are `false`, so the program prints `LOW`. The [Conditionals lesson](/java/fundamentals/java-conditionals) teaches comparisons, branch order, and logical operators in detail.

## For Loops

A loop repeats a block while its condition remains `true`. A `for` loop places its starting value, condition, and update in one line. In this preview, `<=` means “less than or equal to.” This complete program counts from 1 through 5:

```java
public class Main {
    public static void main(String[] args) {
        for (int count = 1; count <= 5; count++) {
            System.out.println("Count: " + count);
        }
    }
}
```

The loop starts with `count` equal to 1. After each print, `count++` adds 1. The values printed are 1, 2, 3, 4, and 5. After printing 5, the update changes `count` to 6. The condition `count <= 5` is then `false`, so the loop ends.

The [For Loops lesson](/java/fundamentals/java-for-loops) explains each part of the loop header and shows how changing a boundary affects the result.

## While Loops

A `while` loop tests its condition before every repetition. In an intentionally terminating counter loop, the statements inside the loop need to make progress toward a `false` condition. Here, `<` means “less than,” and `attempts++` increases the value that the condition tests:

```java
public class Main {
    public static void main(String[] args) {
        int attempts = 0;

        while (attempts < 3) {
            attempts++;
            System.out.println("Attempt: " + attempts);
        }
    }
}
```

The loop prints 1, 2, and 3. After the third repetition, `attempts` is 3. The condition `attempts < 3` becomes `false`, so the program continues after the loop and ends. Without the update, `attempts` would remain 0 and the condition would stay `true`.

The [While Loops lesson](/java/fundamentals/java-while-loops) teaches condition-controlled repetition and how to recognize a loop that cannot reach its stopping condition.

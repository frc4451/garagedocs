Enums and records are Java types for two common jobs: choosing from a fixed set and keeping related values together.

### An enum names the allowed choices

An `enum` defines a fixed set of constants. It avoids spelling variations such as `"teleop"` and `"TeleOp"`.

```java
public class Main {
    public enum Mode {
        DISABLED, AUTONOMOUS, TELEOP
    }

    public static void main(String[] args) {
        Mode selected = Mode.TELEOP;
        if (selected == Mode.TELEOP) {
            System.out.println("Read the driver controller.");
        }
    }
}
```

Enum constants can be compared with `==`. A `Mode` variable cannot hold an arbitrary string. Write enum constants in uppercase. The constants do not take individual access modifiers; the enum declaration above is explicitly `public`.

### A record groups values

A `record` declares its data components in parentheses. Java supplies the constructor, accessors, `equals`, `hashCode`, and `toString`.

```java
public class Main {
    public record Reading(String sensorName, double distanceMeters) {}

    public static void main(String[] args) {
        Reading first = new Reading("front", 2.5);
        Reading second = new Reading("front", 2.5);
        System.out.println(first.sensorName());
        System.out.println(first.distanceMeters());
        System.out.println(first.equals(second));
    }
}
```

The output is `front`, `2.5`, and `true` on separate lines. Accessors have the component names, such as `distanceMeters()`. Record components do not take `public` or `private`; their generated fields are private and final, and accessors are public.

### What a record protects

You cannot assign a different distance to `first`'s field. Create another Reading for another measurement. However, a record containing a list or array still refers to a potentially changeable object. A record does not make that object's contents immutable.

Records suit data such as a scouting result or coordinate pair. A normal class suits an object whose state changes through methods, such as a subsystem.

| Need | Type |
|---|---|
| One choice from a fixed named set | Enum |
| A group of values with generated accessors and equality | Record |
| An object that manages changing state or an inheritance hierarchy | Class |

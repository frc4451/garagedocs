### Sets

A **set** is a collection of distinct values. Order does not affect membership, and duplicates do not create new elements.

Let `A = {1, 2, 3}` and `B = {3, 4}`.

```java norun

union.addAll(b);

intersection.retainAll(b);

Set<Integer> difference = new HashSet<>(a);
difference.removeAll(b);
```

### Cartesian products and relations

The **Cartesian product** `A × B` contains every ordered pair whose first value comes from `A` and second value comes from `B`.

If `A = {left, right}` and `B = {forward, reverse}`, then:

`A × B = {(left, forward), (left, reverse), (right, forward), (right, reverse)}`

A **relation** is any set of ordered pairs. A drivetrain's leader-follower configuration is a relation between motor controllers. A graph's edges are a relation between nodes.

### Counting choices

Counting tells us how many cases a program may need to handle. It also warns us when an algorithm will grow too large to run.

<ContentTable
  title="Counting rules"
  headers={["Rule", "Use when", "Formula", "Example"]}
  rows={[
    ["Sum rule", "Choose one option from separate groups", "<code>m + n</code>", "3 autonomous routines or 2 test routines gives 5 choices"],
    ["Product rule", "Make one choice, then another", "<code>m × n</code>", "3 speeds and 4 directions gives 12 combinations"],
    ["Permutation", "Choose and order <code>r</code> items from <code>n</code>", "<code>n! / (n-r)!</code>", "Assign gold, silver, and bronze among 8 teams"],
    ["Combination", "Choose <code>r</code> items without order", "<code>n! / (r!(n-r)!)</code>", "Choose 3 scouts from 8 students"],
    ["Power set", "Each of <code>n</code> items is included or excluded", "<code>2^n</code>", "Every subset of available sensors"]
  ]}
/>

Order is the difference between a permutation and a combination. `(A, B, C)` and `(C, B, A)` are different match orders, but they describe the same three-person committee.

### Inclusion-exclusion and the pigeonhole principle

Two counting tools prevent common mistakes.

<ContentTable
  headers={["Tool", "Rule", "Use"]}
  rows={[
    ["Inclusion-exclusion", "<code>|A ∪ B| = |A| + |B| - |A ∩ B|</code>", "Count two groups without counting shared members twice"],
    ["Pigeonhole principle", "Putting more than <code>k</code> items into <code>k</code> groups forces at least one group to hold more than one item", "Prove that a duplicate or collision must exist"]
  ]}
/>

If 18 students choose among 5 work groups, at least one group has at least `ceil(18 / 5) = 4` students. The principle proves that such a group exists without identifying which group it is.

```java
public class Main {
    public static void main(String[] args) {
        int students = 8;
        int selected = 3;

        long orderedAssignments = permutation(students, selected);
        long committees = combination(students, selected);

        System.out.println(orderedAssignments); // 336
        System.out.println(committees);          // 56
    }

    private static long permutation(int n, int r) {
        long result = 1;
        for (int value = n; value > n - r; value--) {
            result *= value;
        }
        return result;
    }

    private static long combination(int n, int r) {
        int smallerSide = Math.min(r, n - r);
        long result = 1;
        for (int i = 1; i <= smallerSide; i++) {
            result = result * (n - smallerSide + i) / i;
        }
        return result;
    }
}
```

The methods build the products directly instead of calculating three full factorials. Factorials grow quickly, so even `long` overflows for modest inputs.

### Probability and expected value

Probability assigns a number from 0 to 1 to an event. For equally likely outcomes, divide the number of favorable outcomes by the number of possible outcomes.

<ContentTable
  title="Basic probability rules"

    ["Complement", "<code>P(not E) = 1 - P(E)</code>", "Convert success probability to failure probability"],
    ["Expected value", "<code>E[X] = Σ(value × probability)</code>", "Compare average outcomes across repeated trials"],
    ["Independent events", "<code>P(A and B) = P(A) × P(B)</code>", "Combine events only when one does not change the other"]
  ]}
/>

Measured frequency from a Java simulation may approach the theoretical probability as the number of trials grows, but a short run can differ. Keep the calculated probability separate from the observed test result.

### Sequences, recurrence, and induction

A **sequence** assigns a value to each integer position. An array is a finite sequence indexed from zero.

A **recurrence relation** defines a value using earlier values. Fibonacci numbers are one example:

`F(n) = F(n - 1) + F(n - 2)`

Mathematical induction proves a claim for every integer from a starting point:

<ContentTable
  title="Induction and recursive code"
  headers={["Proof step", "Question", "Programming parallel"]}
  rows={[
    ["Base case", "Does the claim hold at the starting value?", "Can the method answer the smallest input directly?"],
    ["Inductive assumption", "Assume the claim holds for one smaller value", "Trust the recursive call to solve the smaller input"],
    ["Inductive step", "Show that the smaller case leads to the next case", "Use the smaller result to build the current result"]
  ]}
/>

Induction is a proof method, while recursion is a programming technique. They share the same shape, but a recursive method still needs correct code and a path that reaches its base case.

### Graphs are discrete structures

A graph contains a set of **vertices** and a relation of **edges** connecting them. Robot waypoints, command dependencies, electrical connections, and state transitions can all form graphs. The [Graphs](/java/fundamentals/graphs) lesson covers their Java representations, and the algorithm lessons apply depth-first search, breadth-first search, and shortest-path methods.

### Practice

1. Find the union, intersection, and both differences of `{1, 2, 4}` and `{2, 3, 4}`.
2. List the Cartesian product of `{left, right}` and `{slow, fast}`.
3. Decide whether assigning three drive-team roles to five people uses a permutation or combination.
4. Count the possible on/off configurations for six independent sensors.
5. Use inclusion-exclusion when 12 students know Java, 9 know CAD, and 4 know both.
6. Find the probability of rolling at least one six in two rolls of a fair six-sided die.
7. Identify the base case and smaller subproblem in a recursive method that sums an array.

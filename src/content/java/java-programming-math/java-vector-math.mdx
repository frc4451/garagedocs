A vector stores a magnitude and direction. Robot code uses vectors for position changes, velocity, acceleration, forces, and directions on the field.

This lesson uses two-dimensional vectors written as `(x, y)`. The same operations extend to three or more components.

### Scalars and vectors

The ordered pair matters. `(3, 1)` and `(1, 3)` have different directions even though they contain the same two numbers.

### Coordinate convention

Every vector needs a coordinate frame and units. In the examples below, positive X points forward, positive Y points left, and both components use metres. Changing the frame or units changes what the numbers mean.

<RulesBox title="Name the frame and units">

`robotRelativeVelocity` and `fieldRelativeVelocity` may contain the same Java type while describing different directions. Use names that identify the frame, and convert units at the boundary where data enters the calculation.

</RulesBox>

Let `u = (uX, uY)` and `v = (vX, vY)`.

Addition and subtraction operate component by component. The dot product multiplies matching components and adds the results.

### Magnitude and normalization

For `v = (3, 4)`:

- Magnitude: `sqrt(3² + 4²) = 5`
- Normalized vector: `(3 / 5, 4 / 5) = (0.6, 0.8)`

A zero vector has no direction, so it cannot be normalized. Code must choose how to handle that case instead of dividing by zero.

### Dot products

The sign of a dot product describes how two vectors point relative to each other.

<ContentTable
  title="Reading a dot product"
  headers={["Result", "Relationship", "Example"]}
  rows={[
    ["Positive", "Mostly the same direction", "Forward velocity and a forward target direction"],
    ["Zero", "Perpendicular", "Forward and left"],
    ["Negative", "Mostly opposite directions", "Forward velocity and a target behind the robot"]

The exact value also depends on both magnitudes. Normalize both vectors first when you want a pure alignment value from `-1` to `1`.

### A small Java vector type

This complete program keeps the formulas inside a record so each operation returns another `Vector2`.

```java
public class Main {
    private static record Vector2(double x, double y) {
        public Vector2 plus(Vector2 other) {
            return new Vector2(x + other.x, y + other.y);
        }

        public Vector2 minus(Vector2 other) {
            return new Vector2(x - other.x, y - other.y);
        }

        public Vector2 times(double scalar) {
            return new Vector2(x * scalar, y * scalar);
        }

        public double magnitude() {
            return Math.hypot(x, y);
        }

        public Vector2 normalized() {
            double length = magnitude();
            if (length == 0.0) {
                throw new IllegalStateException("A zero vector has no direction");
            }
            return times(1.0 / length);
        }

        public double dot(Vector2 other) {
            return x * other.x + y * other.y;
        }
    }

    public static void main(String[] args) {
        Vector2 robotToTarget = new Vector2(3.0, 4.0);
        Vector2 robotVelocity = new Vector2(2.0, 0.0);

        System.out.println(robotToTarget.magnitude());
        System.out.println(robotToTarget.normalized());
        System.out.println(robotVelocity.dot(robotToTarget));
    }
}
```

Expected output:

```text
5.0
Vector2[x=0.6, y=0.8]
6.0
```

The record is a learning example. FRC code should use WPILib geometry types such as `Translation2d` when those types match the problem, because they already provide tested operations and work with the rest of WPILib.

### Points and displacement vectors

A point says where something is. A displacement vector says how to move from one point to another. Both can be stored as `(x, y)`, so the variable names carry the distinction.

```java norun
Vector2 fieldToRobot = new Vector2(2.0, 3.0);
Vector2 fieldToTarget = new Vector2(5.0, 7.0);

Vector2 robotToTarget = fieldToTarget.minus(fieldToRobot); // (3, 4)
```

Subtract destination minus start. Reversing the order produces the same magnitude with the opposite direction.

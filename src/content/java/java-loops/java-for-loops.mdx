A `for` loop keeps a counter's starting value, condition, and update together. It is useful when you can describe the repetition with a counter. This lesson builds on the condition, update, and trace steps from [While Loops](/java/fundamentals/while-loops).

<span id="for-loop-structure"></span>

## Put the Counter in the Header

This complete `Main.java` program prints the integers 0 through 4. To run it locally, replace the entire contents of `Main.java`, save the file, and use the [Compile And Run](/java/fundamentals/setup#compile-and-run) steps from Java Setup.

```java
public class Main {
    public static void main(String[] args) {
        for (int count = 0; count < 5; count++) {
            System.out.println(count);
        }
    }
}
```

The **header** is the code inside the parentheses after `for`. It has three parts, separated by semicolons:

1. **Start:** `int count = 0` creates the counter once, before the first condition check.
2. **Condition:** `count < 5` decides whether the next pass starts.
3. **Update:** `count++` runs after the body finishes. It adds 1 to `count`, like `count = count + 1`.

The **body** is the block between the braces. For this loop, Java performs the steps in this order: start, check, body, update, and then check again. The start runs only once. The remaining steps repeat until the check is false.

| Check | `count < 5` | Output | Next Count |
| --- | --- | --- | --- |
| First | `0 < 5` is `true` | `0` | `1` |
| Second | `1 < 5` is `true` | `1` | `2` |
| Third | `2 < 5` is `true` | `2` | `3` |
| Fourth | `3 < 5` is `true` | `3` | `4` |
| Fifth | `4 < 5` is `true` | `4` | `5` |
| Sixth | `5 < 5` is `false` | Body is skipped | No update |

The program prints:

```text
0
1
2
3
4
```

This is the same counting process as a `while` loop with `int count = 0` before the loop and `count++` at the end of its body. The `for` form makes those parts easier to see together.

Because `count` is declared in the header, it can be used in the condition, update, and body. It cannot be used after the loop ends. Declare a variable before the loop when later code needs its value.

## Choose the Bounds

The starting value, comparison operator, and boundary determine which values reach the body. The next snippet replaces the `for` loop inside `main` in the first program:

```java
for (int count = 1; count <= 5; count++) {
    System.out.println(count);
}
```

This loop prints 1 through 5. The `<=` comparison includes 5. Changing the condition to `count < 5` would print 1 through 4 because the check becomes false when `count` reaches 5.

Like a `while` loop, a `for` loop can run zero times. In `for (int count = 5; count < 5; count++)`, the first check is false, so Java skips the body. Before running a loop, predict its first body value, last body value, and first false check. Those three values catch many boundary mistakes.

## Count by Another Step

The update can add or subtract a fixed amount. Replace the `for` loop inside `main` in the first program with this loop to count down from 6 to 0 by twos:

```java
for (int count = 6; count >= 0; count = count - 2) {
    System.out.println(count);
}
```

It prints `6`, `4`, `2`, and `0` on separate lines. After the last body pass, the update changes `count` to `-2`. The condition `-2 >= 0` is false, so the loop ends.

## Build a Running Total

A counter can control the loop while another variable stores a result. This complete program adds the integers 1 through 5:

```java
public class Main {
    public static void main(String[] args) {
        int total = 0;

        for (int number = 1; number <= 5; number++) {
            total = total + number;
            System.out.println("After adding " + number + ": " + total);
        }

        System.out.println("Final total: " + total);
    }
}
```

`total` must be declared before the loop because the program prints it after the loop. The counter `number` is needed only inside the loop, so it stays in the header. The values of `total` after each addition are 1, 3, 6, 10, and 15. The last line is `Final total: 15`.

## Trace Nested Loops

A loop can contain another loop. The **outer loop** completes one pass for each row. During each outer pass, the **inner loop** completes all of its column passes.

```java
public class Main {
    public static void main(String[] args) {
        for (int row = 1; row <= 3; row++) {
            for (int column = 1; column <= 3; column++) {
                System.out.println("Row " + row + ", column " + column);
            }
        }
    }
}
```

For row 1, the inner loop prints columns 1, 2, and 3. The inner loop then starts again at column 1 for row 2, and again for row 3. The program prints nine lines in this order:

```text
Row 1, column 1
Row 1, column 2
Row 1, column 3
Row 2, column 1
Row 2, column 2
Row 2, column 3
Row 3, column 1
Row 3, column 2
Row 3, column 3
```

The next lesson uses loops with arrays. You do not need arrays to complete the examples or practice on this page.

<RulesBox title="Plan a For Loop">

- Use a `for` loop when a counter can describe the repetition.
- Check the start, comparison operator, boundary, and update together.
- Confirm that the update moves the counter toward a false condition.
- Declare a result before the loop when code after the loop needs that result.

</RulesBox>

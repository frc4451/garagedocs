This lesson combines the loop skills from the previous lessons into programs that are easier to test and change. You will keep values in the scope where they are needed, separate repeated work from final results, trace a loop before running it, and build one working step at a time.

## Separate Scope From Resetting

A local variable's **scope** is the part of a block where its name can be used. A variable declared in a loop body is in scope from its declaration to that body's closing brace. Code after the loop cannot use its name.

There is a second issue to check: Java executes a declaration with an initializer each time it reaches that statement. If `int ones = 0;` is inside a loop body, each pass creates and initializes that pass's `ones` variable to zero. It cannot accumulate a total across passes.

The next bounded numeric example shows both problems. Read it without running it because the final `println` would be a compile error if it were uncommented.

```java norun
int[] numbers = {1, 1, 2};

for (int number : numbers) {
    int ones = 0;

    if (number == 1) {
        ones = ones + 1;
    }
}

// Compile error: ones is outside its scope here.
// System.out.println("Total ones: " + ones);
```

Moving `ones` before the loop solves both problems. Its scope now includes the loop and the final print, and its initializer runs only once.

## Count Input Safely

This complete program counts how many entered integers are `1`. It stops at the sentinel `0` or at end-of-input. Invalid lines are reported and skipped, just as in [Loop Control](/java/fundamentals/java-loop-control#skip-invalid-input).

To run it in the browser, place all input lines in **Sample input** before selecting **Run**. To run it locally, replace the contents of `Main.java`, save the file, and follow the [terminal input instructions](/java/fundamentals/java-while-loops#run-with-terminal-input).

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int ones = 0;

        System.out.println("Enter integers. Enter 0 to stop.");

        while (input.hasNextLine()) {
            String line = input.nextLine();
            int number;

            try {
                number = Integer.parseInt(line);
            } catch (NumberFormatException exception) {
                System.out.println("Skipped invalid integer: " + line);
                continue;
            }

            if (number == 0) {
                break;
            }

            if (number == 1) {
                ones = ones + 1;
            }
        }

        System.out.println("Total ones: " + ones);
        input.close();
    }
}
```

For sample input `1`, `4`, `1`, and `0`, the final line is `Total ones: 2`. With `0` first or with empty browser input, it is `Total ones: 0`. The value remains available after the loop because it was declared in the surrounding `main` block.

## Keep Final Results After The Loop

An input loop usually performs one pass for each input item. Instructions belong before that repeated work. Reading, validation, and accumulation belong inside it. A final summary belongs after it so the program prints the summary once.

This program accepts positive integers, treats malformed and negative entries as invalid, and prints one summary after input ends. The sentinel `0` is not included in either count.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        long sum = 0;
        int validNumbers = 0;
        int invalidNumbers = 0;

        System.out.println("Enter positive integers. Enter 0 to stop.");

        while (input.hasNextLine()) {
            String line = input.nextLine();
            int number;

            try {
                number = Integer.parseInt(line);
            } catch (NumberFormatException exception) {
                System.out.println("Skipped invalid integer: " + line);
                invalidNumbers = invalidNumbers + 1;
                continue;
            }

            if (number == 0) {
                break;
            }

            if (number < 0) {
                System.out.println("Skipped negative integer: " + number);
                invalidNumbers = invalidNumbers + 1;
                continue;
            }

            sum = sum + number;
            validNumbers = validNumbers + 1;
        }

        System.out.println("Sum: " + sum);
        System.out.println("Valid numbers: " + validNumbers);
        System.out.println("Invalid entries: " + invalidNumbers);

        if (validNumbers > 0) {
            double average = (double) sum / validNumbers;
            System.out.println("Average: " + average);
        } else {
            System.out.println("Average: no valid numbers");
        }

        input.close();
    }
}
```

For this browser sample input:

```text
5
-2
no
7
0
```

the exact summary is:

```text
Sum: 12
Valid numbers: 2
Invalid entries: 2
Average: 6.0
```

With `0` as the first line, or with empty browser input, the summary reports a sum of 0, zero valid numbers, zero invalid entries, and `Average: no valid numbers`.

The check `validNumbers > 0` prevents division by zero. The cast to `double` makes the division keep a fractional part. The calculation assumes the accumulated sum fits in a `long`.

<RulesBox title="Organize An Input Loop" subtitle="One job in each place">

- **Before the loop:** Initialize totals and print instructions.
- **Start of each pass:** Read one input item.
- **Validation:** Report and skip an invalid item with `continue`.
- **Exit:** Leave on the sentinel with `break`, or let the condition detect end-of-input.
- **Processing:** Update totals for an accepted item.
- **After the loop:** Print the final results and calculations once.

</RulesBox>

## Choose A Loop From The Repetition

Choose the loop form from what controls the repetition:

- Use a `for` loop when a counter describes the repetition clearly, such as five trials or every valid index in an array.
- Use a `while` loop when another condition decides whether work remains, such as whether another input line is available.
- Use `break` for an exit discovered inside the body, such as a sentinel.
- Use `continue` when the current item should skip the rest of its pass while later items still need processing.

The choice does not make a loop safe by itself. Trace every path and make sure it reaches the update, the next condition check, or an explicit exit.

## Trace Before Running

Tracing means recording the relevant values at each condition check and pass. It can reveal an incorrect starting value, boundary, or update before you run the program.

```java
public class Main {
    public static void main(String[] args) {
        int result = 0;

        for (int i = 0; i < 4; i = i + 1) {
            result = result + 3;
        }

        System.out.println("Result: " + result);
    }
}
```

| Check | `i` | Test | Action | Result |
| --- | ---: | --- | --- | ---: |
| First | 0 | `true` | Add 3 | 3 |
| Second | 1 | `true` | Add 3 | 6 |
| Third | 2 | `true` | Add 3 | 9 |
| Fourth | 3 | `true` | Add 3 | 12 |
| Fifth | 4 | `false` | Leave the loop | 12 |

Predict `Result: 12`, then run the program. If your prediction differs, compare the first row where your trace and the program disagree.

## Build In Small Working Steps

Incremental development means adding one small behavior to a working program, then running it again. When a new run fails, the most recent change gives you a focused place to inspect.

Suppose five practice readings must be checked against an allowed range of 0 through 100. Fixed values make the example repeatable: every run can be compared with the same prediction.

Start with a loop that prints each reading:

```java
public class Main {
    public static void main(String[] args) {
        double[] readings = {82.5, 101.0, 79.5, -2.0, 88.0};

        for (int index = 0; index < readings.length; index = index + 1) {
            System.out.println("Reading " + (index + 1) + ": " + readings[index]);
        }
    }
}
```

Run that step and confirm that all five values print in order. Then add the range check, accepted count, and average:

```java
public class Main {
    public static void main(String[] args) {
        double[] readings = {82.5, 101.0, 79.5, -2.0, 88.0};
        int validReadings = 0;
        double sum = 0.0;

        for (int index = 0; index < readings.length; index = index + 1) {
            double reading = readings[index];
            System.out.println("Reading " + (index + 1) + ": " + reading);

            if (reading < 0.0 || reading > 100.0) {
                System.out.println("Skipped: outside 0 through 100");
                continue;
            }

            validReadings = validReadings + 1;
            sum = sum + reading;
            System.out.println("Accepted");
        }

        System.out.println("Total readings: " + readings.length);
        System.out.println("Valid readings: " + validReadings);

        if (validReadings > 0) {
            double average = sum / validReadings;
            System.out.println("Average: " + average);
        } else {
            System.out.println("Average: no valid readings");
        }
    }
}
```

The practice readings `101.0` and `-2.0` are outside the allowed range, so the program accepts three readings. Their sum is `250.0`, and the final average is `83.33333333333333`.

Change one thing at a time to test the boundaries: replace `101.0` with `100.0`, then replace every value with an invalid value. Predict the accepted count and whether an average prints before each run.

Java Fundamentals teaches you to write and understand Java programs. It assumes no programming experience. Begin with [Java Overview](/java/fundamentals/java-overview), then follow the lesson order. This page is a map you can return to as you learn.

<span id="where-to-start"></span>

## First Lessons

1. [Java Overview](/java/fundamentals/java-overview): understand what a program does.
2. [Java Setup](/java/fundamentals/java-setup): prepare a place to write and run Java.
3. [Printing](/java/fundamentals/java-printing): display messages from a program.
4. [Variables](/java/fundamentals/java-variables): give values names so you can use them later.
5. [Strings](/java/fundamentals/java-strings): work with text.
6. [Calculations](/java/fundamentals/java-calculations): calculate and display results.
7. [Console Input](/java/fundamentals/java-console-input): read values someone types into a program.

Use [Command Line Basics](/tools/command-line-basics) and [VS Code: Tour](/tools/vscode-tour) from Tools when setup asks you to use an unfamiliar window or command. If you can't install software, ask your mentor for an approved computer when a task requires local tools.

<span id="how-to-work-through-it"></span>

## How to Practice

1. Read the explanation and predict what the example will display. Text or other results produced by a program are its **output**.
2. If the example has a **Run** button, select it and compare the output with your prediction. Follow the lesson's local instructions for examples that need installed tools.
3. Change one value or instruction and run the example again. Explain why the result changed.
4. Complete the lesson's practice task. If you're stuck, show your mentor what you expected, what happened, and what you tried. Practice the missed step together, then repeat it on your own.
5. Choose a matching program from the [practice roadmap](/java/assignments#practice-tracks). Each assignment links to the lessons it needs. Save completed assignments using [A00: Practice Repository Setup](/java/assignments/a00-practice-repository-setup).

The browser runner uses **Java 17** and needs internet. The local setup uses **Java 25** in VS Code. Follow the version and setup instructions on each lesson; some examples are partial, and tasks involving several files or a debugger need local tools. A debugger lets you pause a program and inspect what it is doing.

A successful run is one checkpoint. Before moving on, explain the result and show what happens after a small change. You can ask for help while you are learning those steps.

## Learning Path

The ten groups below match the sidebar order. Their names describe topics you'll learn later; you don't need to understand all of them now. Each row gives you something to demonstrate after that group.

| Group | What You'll Learn to Do |
| --- | --- |
| 1. [Java Basics](/java/fundamentals/java-overview) | Write and run a program that reads values, calculates a result, and displays it. |
| 2. [Programming Logic](/java/fundamentals/java-control-structures) | Make decisions, reuse a set of instructions, and respond to invalid input. |
| 3. [Loops and Iteration](/java/fundamentals/java-while-loops) | Repeat actions, process several values, and explain when the repetition stops. |
| 4. [Object-Oriented Programming](/java/fundamentals/java-classes) | Organize related information and actions into parts with clear responsibilities. |
| 5. [Data Structures](/java/fundamentals/java-arrays-and-their-trade-offs) | Choose ways to store values so you can find, add, or remove them. |
| 6. [Functions as Data](/java/fundamentals/java-functions-as-data) | Give one part of a program behavior for it to use later. |
| 7. [Programming Math](/java/fundamentals/java-boolean-logic) | Reason about conditions, relationships, directions, and coordinates. |
| 8. [Common Algorithms](/java/fundamentals/java-recursion) | Follow steps for finding or arranging values, and compare how much work those steps require. |
| 9. [Design Patterns](/java/fundamentals/java-factory-methods) | Recognize reusable ways to organize parts of a program. |
| 10. [Concurrency and Multithreading](/java/fundamentals/java-threads-and-concurrency) | Coordinate tasks that can make progress during overlapping periods. |

Some assignments point ahead to a specific lesson. Read that preparation when the assignment asks for it; you don't need every advanced group before starting practice. [Boolean Logic](/java/fundamentals/java-boolean-logic) can also be studied before Java when your badge or mentor assigns it.

## Robot Programming

FRC 4451 uses Java for robot programming. These lessons build the language skills you'll apply in [Kit Bot](/kit-bot), where you'll work with the software used to control a robot.

When an example names unfamiliar equipment, use [Hardware](/hardware) to find the device and [Robot Control System](/hardware/hardware-control-system) to see how the parts connect. Follow your badge or mentor's assigned route for starting robot work.

This track teaches Java from the first program to the structures robot code is built from. It assumes no programming experience. If you have written Java before, skim the Basics group and start where the material becomes new.

<RulesBox title="Why Java">

FRC teams can write robot code in Java, C++, or Python. FRC 4451 uses Java.

Everything in this track transfers directly to robot code: a WPILib subsystem is a class, a command is an object, and a joystick reading is a method call. Java also checks types at compile time, so many mistakes are reported before the program runs.

</RulesBox>

### How the track is organized

The sidebar follows this sequence. Programming Math also works as a reference branch: Boolean Logic needs no Java experience; vectors and matrices prepare you for geometry.

1. **Java Basics**
   - **Topics:** Setup, printing, variables, strings, calculations, and console input.
   - **Check your understanding:** Write and run a small program that reads values and prints results.
2. **Programming Logic**
   - **Topics:** Control flow, conditionals, methods, Math helpers, and try/catch.
   - **Check your understanding:** Make decisions, reuse a calculation, and report invalid input.
3. **Loops and Iteration**
   - **Topics:** While and for loops, arrays, break, and continue.
   - **Check your understanding:** Process several values and explain when a loop stops.
4. **Object-Oriented Programming**
   - **Topics:** Classes, objects, references, static and final, inheritance, interfaces, enums, records, and packages.
   - **Check your understanding:** Create types with clear responsibilities and organize their files.
5. **Data Structures**
   - **Topics:** Arrays, ArrayLists, generics, linked lists, stacks, queues, deques, sets, and maps.
   - **Check your understanding:** Choose how to store and retrieve values.
6. **Functions as Data**
   - **Topics:** Callbacks, lambdas, functional interfaces, method references, and streams.
   - **Check your understanding:** Pass behavior to another method and query collections.
7. **Programming Math**
   - **Topics:** Boolean logic, discrete math, vectors, and matrices.
   - **Check your understanding:** Reason about conditions, relationships, and coordinates.
8. **Common Algorithms**
   - **Topics:** Recursion, Big-O, searching, sorting, trees, graphs, traversals, and dynamic programming.
   - **Check your understanding:** Trace algorithms and explain how their work grows.
9. **Design Patterns**
   - **Topics:** Factories, dependency injection, and the command pattern.
   - **Check your understanding:** Separate creation, dependencies, and actions.
10. **Concurrency and Multithreading**
   - **Topics:** Threads, shared state, executors, and concurrent collections.
   - **Check your understanding:** Identify when tasks share state and coordinate access.

### How to work through it

1. Read the explanation and predict the example's output.
2. Run a supported example, change one value, and explain the result. A partial snippet may need the surrounding code named in the lesson.
3. Complete the practice task. If you get stuck, follow its refresher links and try a smaller input.
4. Use the [assignment roadmap](/java/assignments#the-three-tracks) to choose a matching program. You do not need to finish every Fundamentals group first.
5. Keep completed assignments in the GitHub repository from A00.

The browser runner uses Java 17 and needs internet. [Setting Up Java](/java/fundamentals/java-setup) covers VS Code and local Java 25. Local tools are needed for debugger and multi-file tasks; ask a mentor about an approved computer if you cannot install them.

For mentors, use the outcome beneath each group above as a discussion checkpoint. Ask the student to explain a result and change an example, rather than treating a successful Run as evidence that every concept is understood. Advanced algorithms and concurrency are follow-on study, not prerequisites for every beginner assignment.

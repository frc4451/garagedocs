This track teaches Java from the first program to the structures robot code is built from. It assumes no programming experience. If you have written Java before, skim the Basics group and start where the material becomes new.

<RulesBox title="Why Java">

FRC teams can write robot code in Java, C++, or Python. FRC 4451 uses Java.

Everything in this track transfers directly to robot code: a WPILib subsystem is a class, a command is an object, and a joystick reading is a method call. Java also checks types at compile time, so many mistakes are reported before the program runs.

</RulesBox>

### How the track is organized

Ten groups, in order. Each builds on the one before.

1. **Java Basics**
   - **Topics:** Setup, printing, variables, calculations, the `Math` class, arrays, and packages.
   - **Goal:** Write, run, and organize your first Java programs.
2. **Programming Logic**
   - **Topics:** Conditionals, methods, and try/catch.
   - **Goal:** Make decisions, reuse code, and respond to errors.
3. **Loops and Iteration**
   - **Topics:** While loops, for loops, `break`, and `continue`.
   - **Goal:** Repeat work and organize a program around a loop.
4. **Object-Oriented Programming**
   - **Topics:** Classes, objects, references, overloading, inheritance, abstract classes, interfaces, generics, and runtime polymorphism.
   - **Goal:** Represent robot parts and their behavior with objects.
5. **Data Structures**
   - **Topics:** Arrays, ArrayLists, linked lists, stacks, queues, deques, sets, maps, trees, and graphs.
   - **Goal:** Choose a structure based on how the program stores and uses data.
6. **Programming Math**
   - **Topics:** Boolean logic, discrete math, vectors, and matrices.
   - **Goal:** Use the mathematical structures behind conditions, algorithms, geometry, and robot calculations.
7. **Common Algorithms**
   - **Topics:** Recursion, searching, sorting, tree traversals, graph searches, backtracking, memoization, and Big O analysis.
   - **Goal:** Process stored data and understand how the work grows with the input.
8. **Functions as Data**
   - **Topics:** Functional interfaces, lambdas, method references, suppliers, and streams.
   - **Goal:** Store behavior in a value and pass it to other code.
9. **Design Patterns**
   - **Topics:** Factory methods, dependency injection, and the command pattern.
   - **Goal:** Organize robot code so parts can be tested, replaced, and combined.
10. **Concurrency and Multithreading**
   - **Topics:** Threads, race conditions, executors, and concurrent collections.
   - **Goal:** Run independent work safely when more than one thread is needed.

### How to work through it

- Take the lessons in order; each assumes the ones before it.
- Run every example. The code in these lessons runs in the browser: press *Run*, change something, and run it again.
- Do the exercises at the end of each lesson before moving on. Answers are provided, but reading one is not the same as writing it.
- After each group, the matching [Practice Assignments](/java/assignments) give you a program to write from scratch, with checks that tell you whether it works.
- Use search (top of the page) to find a topic again later.

<RulesBox title="Prerequisites">

No programming experience is assumed. You need a computer with a web browser; the lesson examples run in the browser, so nothing has to be installed for the lessons themselves. [Setting Up Java](/java/fundamentals/java-setup) covers the local install the Practice Assignments use, with an online fallback for machines where you cannot install software.

</RulesBox>

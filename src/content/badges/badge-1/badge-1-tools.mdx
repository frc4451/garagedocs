Step 2 sets up the tools used for the rest of Badge 1. The rows run in order. At the check, the student shows the mentor how to open and use each tool.

### Rows

| # | Task | Instructions | Show the mentor |
|---|---|---|---|
| 2.1 | Create a GitHub account, enable two-factor authentication, accept the organization invitation | [Creating Your GitHub Account](/tools/creating-your-github-account) | The account appears in the organization member list; the mentor can check private membership |
| 2.2 | Install Git and set the commit identity | [Installing Git](/tools/installing-git) | `git config --global user.name` and `git config --global user.email` print the student's name and email |
| 2.3 | Open VS Code and find its controls | [VS Code: Tour](/tools/vscode-tour), [Keyboard Shortcuts](/tools/vscode-keyboard-shortcuts) | The student opens a folder, the terminal, and the Command Palette |
| 2.4 | Use the terminal | [Command Line Basics](/tools/command-line-basics), [Files, Pipes and PATH](/tools/files-pipes-and-path) | The student moves into a folder, lists its files, and runs a program |
| 2.5 | Install Java and WPILib | [Java Setup](/java/fundamentals/java-setup), [R00](/kit-bot/r00-wpilib-setup) | `java --version` prints a version, and the new Kit Bot project builds in WPILib VS Code |

R00 stops after the software setup and simulation check. Imaging and radio configuration are Step 7 hardware work.

### What the mentor checks

1. The student shows their Git commit name and email with the two commands above.
2. The student opens the `KitBot` project folder from R00 in WPILib VS Code, opens its terminal and Command Palette, and runs **WPILib: Build Robot Code**. The output ends in `BUILD SUCCESSFUL`.
3. The student shows that their GitHub account belongs to the organization.

The student practices any missed action with the mentor, then repeats that action alone.

<RulesBox title="Common blockers">

- **`java -version` and the WPILib build report different Java versions:** expected. The Java lessons use Java 25; WPILib builds robot projects with the JDK bundled for its release.
- **Commits have no name or email:** `user.name` and `user.email` were never set. Row 2.2 sets them; commits made before that keep the missing identity.
- **Invitation missing:** the student confirms their GitHub username with the mentor, then checks the account's email and pending invitations.

</RulesBox>

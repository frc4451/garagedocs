Set up the tools you will use for the rest of Badge 1. Follow the rows in order. At the check, you show the mentor how to open and use each tool.

### Rows

| # | Task | Instructions | Show the mentor |
|---|---|---|---|
| 2.1 | Create GitHub account, enable two-factor authentication, accept the organization invitation | [Creating Your GitHub Account](/tools/creating-your-github-account) | Your account appears in the organization member list; the mentor can check private membership |
| 2.2 | Install Git and set your commit identity | [Installing Git](/tools/installing-git) | Run `git config --global user.name` and `git config --global user.email` |
| 2.3 | Open VS Code and find its controls | [VS Code: Tour](/tools/vscode-tour), [Keyboard Shortcuts](/tools/vscode-keyboard-shortcuts) | Open a folder, the terminal, and the Command Palette |
| 2.4 | Use the terminal | [Command Line Basics](/tools/command-line-basics), [Files, Pipes and PATH](/tools/files-pipes-and-path) | Move into a folder, list its files, and run a program |
| 2.5 | Install Java and WPILib | [Java Setup](/java/fundamentals/java-setup), [R00](/kit-bot/r00-wpilib-setup) | Run `java -version` and build the new Kit Bot project in WPILib VS Code |

Stop R00 after the software setup and simulation check. Imaging and radio configuration are Step 7 hardware work.

### What the mentor checks

1. Show your Git commit name and email with the two commands above.
2. Open the Kit Bot folder in WPILib VS Code. Open its terminal and Command Palette, then run **WPILib: Build Robot Code**. Show `BUILD SUCCESSFUL`.
3. Show that your GitHub account belongs to the organization. Never show a password or recovery code.

Practice any missed action with the mentor, then try that action yourself again.

<RulesBox title="Common blockers">

- **Two Java installations:** the Java lessons use Java 25. WPILib supplies its own JDK for robot projects. A regular terminal may show Java 25 while WPILib builds with its bundled JDK.
- **Commit identity missing:** set `user.name` and `user.email` before creating commits.
- **Invitation missing:** confirm the GitHub username with the mentor, then check the account's email and pending invitations.

</RulesBox>

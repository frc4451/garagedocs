Step 2 is installs and accounts. Nothing here is graded on understanding; the check for each row is that the tool works on the student's own laptop and the student can drive it on request. Do the rows in order, since later ones depend on earlier ones.

<RulesBox title="Before you start">

A laptop the student will keep using for the season, with permission to install software on it. School-managed laptops sometimes block installers; find that out in the first meeting, not the fourth.

</RulesBox>

### Rows

| # | Step | Lesson | Done when |
|---|---|---|---|
| 2.1 | Create a GitHub account with two-factor authentication and join the team organization | [Creating Your GitHub Account](/tools/creating-your-github-account) | The mentor sees the student in the organization's member list |
| 2.2 | Install Git and set the commit name and email | [Installing Git](/tools/installing-git) | `git config --global --list` shows `user.name` and `user.email` |
| 2.3 | Install VS Code and learn its layout | [VS Code: Tour](/tools/vscode-tour), [VS Code: Keyboard Shortcuts](/tools/vscode-keyboard-shortcuts) | On request, the student opens a folder, the integrated terminal and the command palette |
| 2.4 | Learn the shell | [Command Line Basics](/tools/command-line-basics), [Files, Pipes and PATH](/tools/files-pipes-and-path) | The student navigates to a folder, lists it, and runs a program from the terminal |
| 2.5 | Install the JDK and WPILib | [Java Setup](/java/fundamentals/java-setup), [R00: WPILib Setup](/kit-bot/r00-wpilib-setup) | `java -version` reports the installed JDK; the WPILib copy of VS Code opens and builds the new project R00 creates |

### What the mentor checks

Ask for each of these and watch, without touching the keyboard:

1. Open a terminal and run `git config --global --list`.
2. Open the WPILib VS Code, open the R00 project, and run *Build Robot Code*. `BUILD SUCCESSFUL` appears in the terminal.
3. Open GitHub in the browser and show the team organization on the student's profile.

If any of the three needs help, the row is not done yet. The point of Step 2 is that the student can get themselves to a working state again on a different day.

<RulesBox title="Common blockers">

- **Two Java installs.** WPILib brings its own JDK; the Java section's JDK is for the browser-free Practice work. `java -version` in a plain terminal reports the one on `PATH`, and it is fine for that to be the Java 25 install as long as the WPILib VS Code builds.
- **Git identity never set.** Commits then show a machine name. Fix it before the first commit in Step 3 so the history does not need rewriting.
- **Organization invitation sent to the wrong email.** The invitation goes to the email on the GitHub account, which is not always the school email. Check the profile.

</RulesBox>

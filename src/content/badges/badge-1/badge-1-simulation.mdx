In Step 6, build the [Kit Bot](/kit-bot) on your laptop. A **simulation** runs your robot code against software models instead of physical motors. Complete each lesson's **Done when** check before moving on.

### Rows

| # | Work | Show the mentor |
|---|---|---|
| 6.1 | [R00](/kit-bot/r00-wpilib-setup), [R01](/kit-bot/r01-project-anatomy), [R02](/kit-bot/r02-robot-lifecycle) | Build, open simulation, identify the four files, and show the teleop print stopping when disabled |
| 6.2 | [R03](/kit-bot/r03-constants) through [R05](/kit-bot/r05-commands-and-triggers) | Constants compile; heartbeat counts while disabled; A resets and B prints while enabled |
| 6.3 | [R06](/kit-bot/r06-motor-controllers), [R07 Parts 1–2](/kit-bot/r07-drive-io), [R08 Parts 1–3](/kit-bot/r08-launcher-io) | Forward/reverse distance signs, independent launcher controls, and two distance settings |
| 6.4 | [R09 Parts 1–2](/kit-bot/r09-characterization), with a mentor | Save samples and gains; use the equations and a calculator to check one full sample set |
| 6.5 | [R10](/kit-bot/r10-joysticks-and-stick-math) through [R13 Part 2](/kit-bot/r13-pose-and-field-view) | Drive with a deadband, show `IO: sim`, graph both launcher motors, open a saved log, and show the field pose |
| 6.6 | [R14](/kit-bot/r14-time-based-autonomous) | Select each autonomous option and show its output stopping |
| 6.7 | [Capstone](/kit-bot/rc-capstone) | Demonstrate the complete project from a fresh clone |

Skip **R00 Part 2**, **R00 Part 3**, and **R12 Part 2** in this simulation step. They are physical-hardware work for Step 7. R15 is a follow-up catalog.

For row 6.3, forward increases both distance readings; reverse decreases both; a right turn increases the left reading and decreases the right. No exact two-second distance is required. For the launcher, show left-bumper intake, right-bumper launch, A-button eject, and the D-pad distance settings. Simulation shows motor readings, not actual fuel scoring.

### Badge check

A **fresh clone** is a new copy downloaded from GitHub into a different folder. It checks that your repository contains the files another student needs. Use a laptop with WPILib and REVLib prepared. The mentor may help with installation or network access before the demonstration.

<StepsBox title="Simulation badge check">

1. Clone the repository into a new folder and open it in WPILib VS Code.
2. Build and launch simulation. Show `IO: sim`.
3. Drive forward, reverse, and turn. Center the sticks and check that the deadband removes small requests.
4. Demonstrate the launcher controls and two D-pad settings. Show the launcher graphs and moving field pose.
5. Show both saved characterization runs. Use your notes and a calculator to explain one result. Demonstrate that releasing a test button ends the test.
6. In Glass, run each autonomous option. Show the outputs stopping and confirm that the sticks cannot drive during **Do nothing** autonomous.

</StepsBox>

You operate the keyboard and controller. Notes and documentation are allowed. Explain what you changed and what the result shows. If a check needs help, practice that part with the mentor and repeat it; completed phase checks remain valid.

If a fresh clone fails to build, read the first error. Possible causes include a missing committed file, a missing vendor library, a different WPILib version, or an unavailable dependency download. Do not assume every failure means code was lost.

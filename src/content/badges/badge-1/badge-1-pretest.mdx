Take this test twice: once in your first week, before any lesson, and once after the capstone. The first time, most students answer three or four questions. That is the point. The two papers next to each other show you and your mentor what Badge 1 changed.

<RulesBox title="How it works">

- Thirty minutes, ten questions, no notes and no internet. Paper or a plain text file; write the date at the top.
- Answer what you can. Leave a question blank rather than guessing; a blank tells the mentor more than a guess.
- Nothing about a robot or an FRC library is on the test. It is the shell, networking, Git and Java: the things Badge 1 teaches before the Kit Bot.
- The mentor keeps the first paper. At the end, take it again on a fresh sheet and compare.

</RulesBox>

### Questions

**1. The shell.** You open a terminal in your home folder. Write the commands, in order, that move into a folder named `robot`, list what is in it, and print the full path of the folder you are in. PowerShell or a Unix shell, your choice; say which.

**2. Networking.** A laptop has the address `192.168.1.20` and a device on the bench has `10.44.51.2`. Can they talk to each other directly, and why or why not? Then name the one command you would run to find out whether a device answers on the network.

**3. Git words.** In one sentence each, what is a *commit*, a *branch* and a *remote*?

**4. Git order.** Put these five steps in the order you would do them to get a change onto GitHub without touching `main`:

- `git push -u origin feature`
- `git add .`
- edit a file
- `git commit -m "Describe the change"`
- `git switch -c feature`

**5. Predict the output.** What does this print, one value per line?

```java
int a = 7;
int b = 2;
System.out.println(a / b);
System.out.println(a % b);
System.out.println(a / 2.0);
```

**6. Conditions and Boolean logic.** The first snippet has one problem. Say what it is.

```java
boolean enabled = false;
if (enabled = true) {
    System.out.println("running");
}
```

Then use De Morgan's law to rewrite this expression so the negation applies to each variable instead of the parentheses. The new expression must have the same result for every input.

```java
!(enabled && connected)
```

**7. Write a loop.** Write a loop that prints the numbers 10 down to 1, one per line.

**8. Write a method.** Assume the method belongs inside a class. Write a `public static` method named `clamp` that takes a `double value`, a `double min` and a `double max`, and returns `value` limited to that range: `min` if it is below, `max` if it is above, otherwise `value` unchanged.

**9. Objects.** What does this print, and why?

```java
public class Motor {
    private double speed = 0;

    public void set(double s) {
        speed = s;
    }

    public double get() {
        return speed;
    }
}

Motor m = new Motor();
Motor n = m;
n.set(0.5);
System.out.println(m.get());
```

**10. Interfaces.** A program declares an interface with two implementations: one that talks to real hardware and one that pretends to, for testing on a laptop. The rest of the program only uses the interface. In two or three sentences, what does that arrangement make possible?

### Scoring

The mentor scores each question 0, 1 or 2: nothing or wrong, partly right, right. Twenty points total. There is no pass mark. The first score goes on the sign-off sheet next to *Pretest (start)*, the second next to *Pretest (end)*, and the difference is the number that matters. The mentor holds the answer key; ask for the questions you missed to be explained after the second sitting, not the first.

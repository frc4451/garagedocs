Step 5 is the Java the Kit Bot code assumes. The list is not the whole Java section. It includes the lessons the Kit Bot pages name in their *Before you start* boxes and the lessons those pages build on. The Practice assignments exercise the same ideas in code.

<RulesBox title="Before you start">

[Step 4](/badges/badge-1-boolean-logic) complete, and the `garagedocs-practice` repository from Step 3 exists. Every assignment below ends with a commit and push to it; the README table is how the mentor sees progress.

</RulesBox>

### Badge check

The mentor opens `garagedocs-practice` and confirms:

1. Every assignment above passes its checks. The README table marks all 14 complete with a self-score.
2. Each assignment has its checkpoint commit, so the history shows the work arriving over time and not in one paste.
3. In a short conversation, the student walks through A11, A17 and A22 and explains one design choice in each: why the field is private, why the interface has two implementations, why the binding takes a lambda.

The mentor signs after the conversation. A student who passes the automated checks but cannot explain A17 is not ready for R07, and the sign-off waits.

Step 5 teaches the Java used by Kit Bot. Complete the 31 lessons and 14 assignments listed here; you do not need the entire Java catalog for Badge 1.

### Lessons

Work through the groups below in order. For each lesson, read one example, predict what it will do, then run it and compare. Java execution in the browser requires internet; use local VS Code and the installed JDK when working offline.

You may keep the lesson open while completing an assignment. Save your code in the repository even when you write it in the browser.

### Badge check

The mentor opens `garagedocs-practice` and confirms:

1. Every assignment above passes its checks. The README table marks all 14 complete with a self-score.
2. Each assignment has a checkpoint commit, so the mentor can find the saved version you demonstrated.
3. In a short conversation, the student walks through A11, A17 and A22 and explains one design choice in each: why the field is private, why the interface has two implementations, why the binding takes a lambda.

Use your code and notes during the conversation. Explain in your own words. If A11, A17, or A22 is unclear, review that example with the mentor, make a small change, and explain the result before repeating that part of the check.

Step 5 teaches the Java the Kit Bot lessons use. 

The student's primary goal is to complete the 14 assignments listed below; the rest of the Java catalog is outside Badge 1.
The lessons prepare the student for the assignments.
A student who already knows a topic still reads its lesson, because the lessons show the style the mentors expect in robot code.

### Lessons

The groups run in order. For each lesson, the student reads one example, predicts what it will do, then runs it and compares.
Java execution in the browser requires internet. When offline, the student should use their local VS Code and the installed JDK. The student may keep the lesson open while completing an assignment.
Code written in the browser needs to be saved to the repository too.

Every group listed here appears in the Kit Bot lessons, where the student recreates the 2026 Kit Bot (FRC 4864's *Scorpion*) in their own `KitBot` project.

### Recommendations
The student completes one group at a time and starts an assignment once its lessons are done:

- A01 through A08 after Java Basics, Programming Logic, and Loops. A06 also needs the enum half of [Enums and Records](/java/fundamentals/java-enums-and-records); its record half can wait until the object lessons.
- A10 after Arrays and Calculations. The assignment asks for a hand-written sort; insertion sort is enough.
- A11 and A14 after Classes and Objects.
- A16 after Inheritance.
- A17 after Interfaces and Dependency Injection.
- A22 after Lambdas and Functional Interfaces.

### Badge check

The mentor opens `<yourname>Badge01` and confirms:

1. Every assignment above passes its checks, and the README table marks all 14 complete with a self-score.
2. Each assignment has a checkpoint commit, so the mentor can find the version the student demonstrated.
3. During a regularly scheduled team meeting, the student walks through A11, A17 and A22 and explains one design choice in each: 
    1. Why the field is private
    2. Why the interface has two implementations
    3. Why the binding takes a lambda.

The student may use their code and notes during the conversation and explains in their own words. 
If A11, A17, or A22 is unclear, the student reviews that example with the mentor, makes a small change, and explains the result before repeating that part of the check.

The keys are not on the public site. The pretest key is stored locally in `mentor-only/badge-1-pretest-key.md`. The worksheet key is stored in `mentor-only/badge-1-boolean-logic-worksheet-key.md`. Both paths are excluded by `.gitignore`.

### Questions to ask at the end

The capstone's demonstration includes explaining one failure check. Add four questions that cross the steps, and expect answers in the student's own words:

1. **Git:** "A teammate pushed to `main` while your branch was open. What do you do before your pull request can merge?" (Pull or rebase onto `main`, resolve any conflict, push the branch again.)
2. **Java:** "Why does `RobotContainer` construct `new DriveIOSim()` in one branch and `new DriveIOReal()` in the other, and why does `Drive` not care which?" (Both implement the `DriveIO` interface; the subsystem depends on the interface, not the class.)
3. **Boolean logic:** "The robot may run when it is enabled and either has no fault or has a manual override. Write that condition, then explain what must be true for it to be false." (`enabled && (!fault || override)`; it is false when the robot is disabled, or when it has a fault and no override.)
4. **Robot:** "The robot turns when you command forward. What do you check first, and where is the fix?" (Compare the two sides' commanded and measured values; invert the side that is backwards in the constants or the IO implementation.)

A student who cannot answer one question has a gap in that step; sign the other rows and send them back to the step's page.

### When a student is stuck

| Symptom | Usually means | Send them to |
|---|---|---|
| Cannot get a clean `git status` after a build | Ignore rules missing or a generated folder already committed | [.gitignore](/tools/gitignore) |
| Practice checks pass but the checkpoint commits are missing | Work done in the browser and never copied to the repository | [A00](/java/assignments/a00-practice-repository-setup) |
| Kit Bot builds in the student's folder, not in a clean clone | A file, usually a vendordep JSON or a new class, was never added | [Local Git Workflow](/tools/local-git-workflow) |
| A button does nothing in simulation | Robot not enabled, wrong joystick slot, or the binding never runs | [R05](/kit-bot/r05-commands-and-triggers) |
| `IO: sim` on the robot | The `isReal()` branch is inverted or the deploy went to the simulator | [R12](/kit-bot/r12-real-vs-sim) |
| No SPARK MAX in the REV Hardware Client | Wiring, CAN termination, firmware or power | [R12 Part 2](/kit-bot/r12-first-deploy#prepare-the-spark-max-controllers) |

The Badge 1 requirements and sign-off sheet are maintained in Google Docs. The student prints the sheet and brings it to each check. A mentor signs after seeing the required evidence.

### Required Sheets

The [Badge 1 requirements and sign-off sheet in Google Docs](https://docs.google.com/document/d/1FHhinkTDgvzAyIR0UuoW-VRv7J8d-mUgtN3Slgaeesw/edit) includes every check, the required evidence, and spaces for mentor signatures and dates.

The [Boolean Logic worksheet from Step 4](/badges/badge-1-boolean-logic#boolean-logic-worksheet) is printed separately and kept with the sheet. The signed paper is the badge record

### Final Questions

The capstone's demonstration ends with the student explaining one failure from a list (a button that does nothing, a robot that turns when commanded forward, a telemetry topic stuck at zero, an autonomous command that does not stop): what they would observe, what they would check first, and what evidence would confirm the cause. The mentor adds four questions that cross the steps and expects answers in the student's own words:

1. **Git:** 
    - A teammate pushed to `main` while your branch was open. How would you bring those changes into your branch and check your work before merging?
2. **Java:** 
    - Both `DriveIOSim` and `DriveIOReal` implement `DriveIO`. Explain how that lets `Drive` use either one.
3. **Boolean logic:** 
    - A practice program accepts a submission when the name is filled in and either a file or a repository link is provided. Write that condition using Boolean variables you name. Explain one case where it is false.
4. **Robot:**
    - The robot turns when you command forward. What values and physical directions would you check while the robot is safely on blocks with a mentor?

The student may use their written notes and explains in their own words. If an answer needs work, the mentor reviews that lesson with the student and tries another example. Completed checks stand.

### Common Reasons a Student Needs Help

| Symptom | Usually means | Send them to |
|---|---|---|
| Cannot get a clean `git status` after a build | Ignore rules missing or a generated folder already committed | [.gitignore](/tools/gitignore) |
| Practice checks pass but the checkpoint commits are missing | Work done in the browser and never copied into `<yourname>Badge01` | [A00](/java/assignments/a00-practice-repository-setup) |
| Kit Bot builds in the student's folder, not in a fresh clone | The first error says which: a file never committed, a missing vendor library, a different WPILib version, or a dependency download that failed | [Step 6 badge check](/badges/badge-1-simulation#badge-check) |
| A button does nothing in simulation | Robot not enabled, wrong joystick slot, or the binding never runs | [R05](/kit-bot/r05-commands-and-triggers) |
| `IO: sim` on the robot | The `isReal()` branch is inverted, or **Simulate Robot Code** ran instead of **Deploy Robot Code** | [R12](/kit-bot/r12-real-vs-sim) |
| No SPARK MAX in the REV Hardware Client | With the robot disabled, check power, USB connection, firmware and CAN wiring with a mentor | [R12 Part 2](/kit-bot/r12-first-deploy#prepare-the-spark-max-controllers) |

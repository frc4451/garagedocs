This module establishes the formal calculus requirement for Badge 3. The student connects rates and accumulated change to one mechanism's recorded motion and control error. Its evidence becomes part of the subsystem project, rather than a second robot project. C1–C5 support the B3-02.1 assessment row below; completing this module alone does not award the badge.

Start after the entry baseline and work plan. This written and simulation module may continue while physical checks are scheduled. Badge 2 or mentor-verified equivalent work supplies the Java, graph-reading, units, and mechanism-simulation prerequisites. The student needs algebra, function notation, and signed arithmetic. A school calculus course is not a prerequisite: the linked lessons teach the selected material, and the mentor helps with unfamiliar algebra before the independent review.

## Lessons and Practice

Read these lessons in order and work through their examples:

1. [Functions and Rates of Change](/java/fundamentals/functions-and-rates-of-change): inputs and outputs, average rates, signs, and units.
2. [Derivatives](/java/fundamentals/derivatives): shrinking intervals, limits, instantaneous rate, and the derivative rules used in the examples.
3. [Integrals](/java/fundamentals/integrals): signed accumulation, definite and indefinite integrals, antiderivatives, initial values, and sampled approximations.
4. [PID Control](/frc/pid-control#the-three-terms): connect the derivative and integral of error to D and I.

The mathematical sequence draws on Frank Thorne's [USC MATH 141 curriculum](https://thornef.github.io/math141/index.html). This module selects concepts needed for controls; it does not claim to cover the full university course or adopt its examination policy.

Use a personal copy or printout of the [Badge 3 Calculus Fundamentals worksheet](https://docs.google.com/document/d/1eFejNKApiOwPyziOaORg5K7GruMwVl3d9PG5KJ7cW3c/edit). Leave the shared master blank. Notes, lessons, and a calculator are allowed during practice. The mentor keeps the answer key separate and reviews missed reasoning before the student repeats that part independently.

The worksheet includes signed rates, derivatives of a position model, signed accumulation, and PID error calculations. Questions 9–10 use the complete Java examples from the derivative and integral lessons. Write predictions before running them, record observed output with units, and explain whether each result is exact for the stated model or an approximation. The mentor selects a further change for the student to predict independently.

## Apply It to a Mechanism

Use the position-controlled elevator retained from Badge 2 and its saved motion log. If equivalent entry work did not include an elevator log, the mentor supplies one and checks the student's understanding of its units and model. Reuse its controller, tests, and logging. Read [Simulation in AdvantageScope](/frc/simulation-in-advantagescope) before inspecting the recorded run. No hardware trial or custom PID implementation is required.

1. Record a simulation run with timestamps, position setpoint, measured position, and measured velocity. State the position and time units, positive direction, controller configuration, and any integral limit or reset policy used. Choose at least five consecutive samples during motion and a section where the position setpoint is constant.
2. For two adjacent intervals, calculate average measured velocity from position change divided by elapsed time. Compare those values with the logged velocity and explain why an interval average need not equal an instantaneous or filtered sensor estimate. Do not divide by zero or assume samples arrive at exactly the requested loop period.
3. Estimate displacement over the selected samples using a stated rectangle or trapezoid rule. Compare the estimate with final position minus initial position. Include the initial position only when recovering final position, and distinguish displacement from total distance if direction changes.
4. On the constant-setpoint section, calculate error as setpoint minus measured position. Estimate one error rate and accumulated error over the selected interval, with the starting accumulation explicitly set to zero for this analysis. Explain the signs of the corresponding D and I contributions for positive gains. This offline calculation does not establish the controller's actual internal I state or exact output.
5. Repeat a calculation with a wider sample spacing. Explain what changed and what the data does not establish about noise or accuracy. Use the results to propose one measurement, sampling, or tuning check. The student does not need to enable I or D to finish the module.

Keep the worksheet, Java predictions and output, saved log, sample table, calculations, and explanation with the subsystem evidence. The README links to them. A mentor can provide a recorded simulation run if the student's project is not ready; the student still performs and explains the analysis.

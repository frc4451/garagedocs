The student hands the project to another member and completes the final independent written check.
The mentor reviews technical evidence, physical demonstrations, written understanding, and
leadership separately. Completing one category does not substitute for another.

## Handoff Package

Provide the project source, pinned dependencies, setup instructions, mode selection, simulation
entry points, actual hardware setup sheets, units and conversion conventions, gain records,
reference procedures, representative logs, tests, and known limitations. The README identifies the
preserved base version and distinguishes supplied code from student additions.

Another member builds and runs the project from those instructions, reproduces the required FuelSim
scoring shot and controlled miss, and investigates a selected result. The student corrects missing
instructions, then the member repeats the affected action. Record the reproduction evidence and the
mentor's observation. Reuse matching peer reproduction and physical handoff evidence already
gathered in the badge; repeat only missing or changed actions. Maple-sim open-space and contact
reproduction is also required, using the combined world.

## Written and Practical Review

After instruction, finish the independent 100% mastery attempt attached to B3-01.1. Then use a
separate independent equivalent form of [Written Checks](/badges/badge-3-written-checks). The final
result must be 100%. If an answer is incomplete, practice the topic and attempt an equivalent
question set again. Keep the attempts and correction record. Previously completed practical rows
remain credited.

The calculus and Expo worksheets also require complete correct reasoning after feedback. Notes are
permitted during worksheet practice. The independent checks assess the student's own explanation;
the mentor may clarify wording without supplying an answer.

## Sign-Off Record

Copy the current required rows from Steps 1–14 into one dated evidence record. Each required B3
identifier needs an evidence link, student explanation, mentor signature and date. Review B3-13.2 or
B3-13.3 when it matches the prior physical route; both are extensions for a student who used FX.
Former B3-06.0 is no longer a separate required row; review the physical FX baseline within B3-13.1.
C1–C5 support B3-02.1. Record required simulation and physical demonstrations separately even when
one fixture contributes to several rows.

| Review | Evidence | Mentor Signature | Date |
| --- | --- | --- | --- |
| Technical work | All required simulation, code, experiments and failure runs. | | |
| Physical work | FX voltage baseline and roller/flywheel/pivot torque-current work, voltage comparison, selected Badge 2 controller evidence, CANrange, pivot reference and stationary camera. | | |
| Written work | Diagnostic corrections through instruction, independent 100% mastery after instruction, complete worksheets, and a separate independent 100% final. | | |
| Leadership | Diagnosis, substantive review, observed teaching and lesson feedback. | | |
| Handoff | Another member builds, reproduces and investigates. | | |

The Automation Team mentor makes the final leadership-readiness judgment and dates the badge record.
There is no event-attendance requirement. If equipment prevents a physical demonstration, record
that row as pending and retain the other completed evidence.

## Badge Check

S means simulation, H means hardware, W means written reasoning, and M means mentor-observed review.
The student records an evidence link, an explanation in the student's own words, the mentor's
signature, and the date for each row. The mentor asks the
student to explain a change and its result before signing.

| Row | Work | Done When |
| --- | --- | --- |
| B3-15.1 | Handoff | M: Supply setup, configuration, units, tuning results, representative logs, tests, limitations and troubleshooting instructions. Another member builds, reproduces the FuelSim scoring shot and controlled miss, and investigates using them; matching earlier evidence may count. |
| B3-15.2 | Final written check | W/M: Complete an independent equivalent assessment at 100%, with practice and reassessment as needed. |
| B3-15.3 | Final sign-off | M: Mentor separately approves technical evidence, physical demonstrations, written work and leadership readiness, then dates the badge record. |

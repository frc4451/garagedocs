Badge 2: Intermediate FRC prepares Automation Team students to read, build, test, and explain competition-scale robot code. Start after [Badge 1](/badges/badge-1), or after a mentor verifies equivalent work. Badge 1 supplies Java fundamentals, interface-based IO, commands, simulation, and basic logging. Badge 2 adds the Java practice, AdvantageKit logging and replay, testing, and architecture needed for its larger projects.

The student first proves a small piece, changes it independently, and then demonstrates it to a mentor. One complete mechanism comes before the full library; one path comes before an autonomous routine; one camera comes before two-camera integration.

## Required Outcomes

The student completes these outcomes in order:

- The recorded AdvantageKit templates build and simulate. A dedicated hardware lesson uses a mentor-provided bench project that matches the physical fixture; a separate software lesson develops IO, replay and configuration builders.
- Talon FX, Talon FXS and Thrifty Nova are introduced in the dedicated hardware lesson. The student implements and physically demonstrates the supplied controller on a roller.
- Four typed mechanism families run in general simulation: roller, flywheel, pivot, and elevator. The elevator includes drum diameter and radius, reduction, rigging calculations, gravity, limits, and a saved motion log.
- Required FX and FXS roller device simulations follow the general roller. A software-profiled pivot comes before one CTRE Motion Magic simulation comparison. Additional physical controller ports and linear-rail implementation are outside the required path.
- An elevator, pivot, and conveyor form one parent subsystem with measured interlocks and a measured/goal drawing. A smaller feed-and-flywheel exercise proves possession and readiness.
- A student-written driver-controller class has tested input shaping and bindings. Timed rumble and a separate pivoting intake are optional extensions.
- Pose, frames, and odometry immediately precede path following. A guided differential path prepares two complete swerve routines, one with PathPlanner and one with BLine. Each swerve routine uses at least three paths and two mechanism actions.
- Two simulated AprilTag cameras provide timestamped observations, named rejection reasons, uncertainty, and replayable estimator input.
- Shared robot facts influence commands without owning actuators. The integrated robot stops on interruption and successfully replays a saved log with a new diagnostic output.

Java practice and tests prepare the student for these outcomes. The badge does not require every remaining Java assignment. Formal calculus and advanced physical Talon FX work belong to Badge 3.

Java examples intended for the robot projects must work with their WPILib 2026 Java 17 toolchain, even when a linked general Java lesson discusses Java 25.

## Mentor Checks

A mentor signs a row after seeing its evidence. Reading a page or copying working code alone does not complete a row. The student explains the result and predicts what will happen after a small change. If more practice is needed, completed checks stand while the student and mentor agree on the next attempt.

The site uses the September 2026 revised requirements. The linked Google Docs packet has not yet been updated; record current evidence using the [site revision record](/badges/badge-2-sign-off#required-sheet). Use the [printed sign-off sheet](https://docs.google.com/document/d/19bYHl6gLpLtoIs9wSAsRVje0Jok5U5xWoD9A7rcnjWs/edit) alongside the [final review](/badges/badge-2-sign-off). The current site rows determine required practical work; an older printed row does not restore a retired requirement. Notes and documentation are allowed except during the pretest and post-test. Simulation work runs on the student's laptop. Steps 4 and 7 also require the provided physical hardware and a mentor-observed demonstration. Physical elevator and autonomous-driving demonstrations are optional.

## Assessment

Take the ten-question [pretest](/badges/badge-2-pretest) before Java Foundations. It is diagnostic and has no passing mark. After the capstone, take it again and score at least 18 of 20. The practical checks separately assess the Java, testing, and robot-building skills; a written score does not replace them.

Step 8 includes a short guided [Math Behind PID](/badges/badge-2-mechanism-library#the-math-behind-pid) exercise within the existing mechanism review. Formal derivatives, integrals, and their worksheet belong to [Badge 3](/badges/badge-3-calculus), not an additional Badge 2 completion requirement.

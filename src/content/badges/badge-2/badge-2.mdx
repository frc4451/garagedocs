Badge 2: Intermediate FRC prepares Automation Team students to read, build, test, and explain competition-scale robot code. Start after [Badge 1](/badges/badge-1), or after a mentor verifies equivalent work. Badge 1 supplies Java fundamentals, interface-based IO, commands, simulation, and basic logging. Badge 2 adds the Java practice, AdvantageKit logging and replay, testing, and architecture needed for its larger projects.

The student first proves a small piece, changes it independently, and then demonstrates it to a mentor. One complete mechanism comes before the full library; one path comes before an autonomous routine; one camera comes before two-camera integration.

## Required Outcomes

The student completes all existing robot deliverables:

- Two AdvantageKit template projects, with the chosen release recorded and builds verified from a clean clone.
- Five independent mechanism families: roller, flywheel, pivot, elevator, and linear rail. Each has Talon FX and Talon FXS implementations, both simulation counterparts, and the required tests.
- Three composed parent subsystems with the specified interlocks and defined behavior when commands finish or are interrupted.
- Three autonomous routines: PathPlanner on the differential Kit Bot, PathPlanner on swerve, and BLine on swerve. Each uses at least three paths and two mechanism actions.
- Two simulated AprilTag cameras, real and simulated IO, timestamped observations, named rejection reasons, uncertainty, and estimator integration.
- A controlled robot-state object whose derived facts influence commands without owning actuators.
- Successful replay of an integrated saved log, including a newly added diagnostic output visible in the replay result.

Java practice and tests prepare the student for those outcomes. The badge does not require completing every remaining Java assignment. Follow the selected prerequisites and checks on each step page.

## The Repository

Badge 2 work lives in one GitHub repository, `<yourname>Badge02`, such as `AlexBadge02`:

```text
AlexBadge02/
├── README.md
├── java-practice/       Java work from Step 2
├── KitBotPathPlanner/   AdvantageKit Kit Bot project
└── Badge2Robot/         AdvantageKit swerve project and mechanism library
```

Step 2 starts in a local practice folder. [Project Setup](/badges/badge-2-project-architecture) places that work in `java-practice/` when the repository is created. This folder is not a third robot project. Open either GradleRIO project in its own VS Code window when using WPILib build and simulation tasks.

The root README records the template releases and links each numbered badge requirement to its source, test, written explanation, or saved log. Java examples intended for the robot projects must work with their WPILib 2026 Java 17 toolchain, even when a linked general Java lesson discusses Java 25.

## Mentor Checks

A mentor signs a row after seeing its evidence. Reading a page or copying working code alone does not complete a row. The student explains the result and predicts what will happen after a small change. If more practice is needed, completed checks stand while the student and mentor agree on the next attempt.

Use the [printed sign-off sheet](https://docs.google.com/document/d/19bYHl6gLpLtoIs9wSAsRVje0Jok5U5xWoD9A7rcnjWs/edit) alongside the [final review](/badges/badge-2-sign-off). Notes and documentation are allowed except during the pretest and post-test. Each required outcome can be completed on the student's laptop; hardware trials happen separately with a mentor and are not required for the badge.

## Assessment

Take the ten-question [pretest](/badges/badge-2-pretest) before Java Foundations. It is diagnostic and has no passing mark. After the capstone, take it again and score at least 18 of 20. The practical checks separately assess the Java, testing, and robot-building skills; a written score does not replace them.

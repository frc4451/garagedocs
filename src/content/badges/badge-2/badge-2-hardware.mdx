The student identifies and operates a prepared motor-controller fixture with the mentor. Talon FX, Talon FXS and Thrifty Nova are all introduced here. The supplied controller determines the required physical route; access to all three physical controllers is not required.

This step uses hardware manuals and vendor configuration tools. The student records the actual arrangement, verifies its settings and observes bounded motor operation. No robot project, code reading, build or deployment is assigned in this step.

## Compare the Controllers

| Controller | Hardware Setup |
| --- | --- |
| Talon FX | Identify the integrated motor/controller assembly and use Phoenix Tuner X to inspect its identity, firmware and settings. |
| Talon FXS | Identify the separate controller, attached motor and feedback connection. Verify the motor arrangement in Phoenix Tuner X before operation. |
| Thrifty Nova | Identify the attached motor and feedback connection. Use Thrifty Config to verify the device and its motor selection. |

The student compares the three routes using the documentation and the supplied hardware. A similar setting name does not establish equivalent current limits or feedback behavior. Read the physical motor label before selecting its settings.

## Inspect the Fixture

With power disconnected, identify the motor, controller, protected power branch, CAN wiring and sensor connections. Check mounting, strain relief, exposed conductors and clearance with the mentor. Trace each cable to its destination and compare it with the selected hardware manual.

The mentor supplies the connection equipment and any already-installed diagnostic services needed by the configuration tool. The student records the connection route and identifies the output stop control and power disconnect before powering the fixture.

## Phoenix Tuner X Setup

For an FX or FXS fixture:

1. Open the mentor-approved Phoenix Tuner X release and connect to the prepared fixture using the documented connection route.
2. Match the displayed device to its physical label. Confirm its type, CAN bus and planned ID before changing settings.
3. Verify the approved firmware, unique ID and any licence required by the selected features. Label the device and record the versions.
4. Inspect the Configs tab. For FXS, verify the motor arrangement and feedback connection against the attached hardware.
5. With output disabled, apply the mentor-approved current limits, direction and neutral behavior where supported. Record the values and their units.
6. Read the settings back and save configuration evidence. Inspect available faults and a Self Test Snapshot before the first enable.

The mentor handles any missing diagnostic-server setup. This step does not use Tuner's project generators.

## Thrifty Config Setup

For a Nova fixture:

1. Open the mentor-approved Thrifty Config release and use the Nova's documented configuration connection.
2. Match the displayed controller to the physical fixture. Record its identity and approved firmware.
3. Assign or confirm its planned CAN ID and attach a physical label.
4. Verify the motor and feedback selections against the connected hardware.
5. With output disabled, apply the approved current limits and other supported fixture settings. Record the units shown by the application.
6. Follow the installed release's save procedure, reconnect or power-cycle as directed, and verify the retained settings before operation.

The mentor demonstrates the controls in the installed release. The student records an unavailable setting or measurement instead of substituting a value from another controller.

## Complete the Setup Sheet

Record actual values with the mentor before enabling each arrangement. Leave unknown values open until verified.

| Item | Record |
| --- | --- |
| Identity | Motor, controller, CAN ID and bus, firmware, configuration-tool version and any required licence. |
| Connections | Power protection, motor wiring, feedback connection and configuration connection. |
| Motion | Positive direction, feedback source and displayed units, and reduction defined as motor revolutions per mechanism revolution. |
| Reference and Travel | Any reference procedure, physical endpoints, permitted travel and clearance. Mark items that do not apply to the roller. |
| Electrical Settings | Approved supply/stator limits where supported, output bound, neutral behavior and available device status. |
| Operation | Mounting, load, enable procedure, stop control, disable operator, power disconnect and supervising mentor. |
| Evidence | Dated settings record, screenshots or available exports, expected motion and observed feedback. |

Read back the applied settings where supported. A failed or unconfirmed setup keeps output disabled. The setup sheet becomes the hardware reference for later lessons.

## First Enable

With the mentor present, inspect mounting, wiring, power protection and clearance again. Confirm device identity while output is disabled. Check changing feedback using the fixture's approved movement procedure. Gravity-loaded mechanisms need a support and disable plan before powered work; they are extensions to this roller lesson.

Use the configuration application's motor controls for a bounded positive request, stop, and bounded reverse request. The mentor selects the permitted output and duration. For FRC devices controlled through Phoenix Tuner X, Driver Station must also be enabled; station the disable operator before starting. Follow the installed Thrifty Config release's enable and stop procedure for Nova.

Check output direction and feedback direction separately. Demonstrate the tool's stop and disable procedure. Record the requested output, displayed measurements and observed motion. Removing effort may leave the roller coasting; keep the fixture clear until motion ends.

The mentor chooses one permitted change to the tool's output setting. The student predicts the result, repeats the check and compares the observations. Return to the recorded configuration and leave output disabled.

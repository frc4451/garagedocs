### How code reaches a motor

This page shows how to create CTRE Talon FX, REV SPARK MAX, REV SPARK Flex, and Thrifty Nova motor-controller objects in `Robot.java`, set their output from the robot lifecycle, reverse direction, and stop them.

The tabbed examples let you compare the vendor APIs. Choose the class and library that match the controller physically installed on the robot.

### CTRE: Talon FX

The Talon FX is a high-performance motor controller with a built-in encoder. It requires the CTRE Phoenix 6 library.

  src="/media/hardware/talonfx.png"
  alt="CTRE Talon FX integrated brushless motor controller"

### Talon FX Example

```java
package frc.robot;

import edu.wpi.first.wpilibj.TimedRobot;
import com.ctre.phoenix6.hardware.TalonFX;
import com.ctre.phoenix6.controls.DutyCycleOut;

public class Robot extends TimedRobot {
    // Create motor instance with CAN ID 1
    private final TalonFX m_motor = new TalonFX(1);
    // Create control request for duty cycle output
    private final DutyCycleOut m_output = new DutyCycleOut(0);
    
    @Override
    public void teleopPeriodic() {
        // Set motor to 50% speed forward (range: -1.0 to 1.0)
        m_motor.setControl(m_output.withOutput(0.5));
    }
}
```

### REV: SPARK MAX

The SPARK MAX supports both brushless (NEO) and brushed motors. It requires the REVLib library.

/>

### SPARK MAX Example

```java
package frc.robot;

import edu.wpi.first.wpilibj.TimedRobot;
import com.revrobotics.spark.SparkMax;
import com.revrobotics.spark.SparkLowLevel.MotorType;

public class Robot extends TimedRobot {
    // Create motor instance: CAN ID 1, Brushless motor type
    private final SparkMax m_motor = new SparkMax(1, MotorType.kBrushless);
    
    @Override
    public void teleopPeriodic() {
        // Set motor to 50% speed forward (range: -1.0 to 1.0)
        m_motor.set(0.5);
    }
}
```

### REV: SPARK Flex

The SPARK Flex is a separate brushless motor controller. It can dock directly to a NEO Vortex, and REVLib gives it its own `SparkFlex` class. Do not create a `SparkMax` object for a physical SPARK Flex.

```java
package frc.robot;

import com.revrobotics.spark.SparkFlex;
import com.revrobotics.spark.SparkLowLevel.MotorType;
import edu.wpi.first.wpilibj.TimedRobot;

public class Robot extends TimedRobot {
    private final SparkFlex m_motor =
            new SparkFlex(1, MotorType.kBrushless);

    @Override
    public void teleopPeriodic() {
        m_motor.set(0.5);
    }
}
```

### Thrifty Bot: Thrifty Nova

The Thrifty Nova is a separate brushless motor controller supported by ThriftyLib. Its percent-output method is `setPercent()`. Confirm the connected motor type in Thrifty Config before running the motor.

```java
package frc.robot;

import com.thethriftybot.devices.ThriftyNova;
import edu.wpi.first.wpilibj.TimedRobot;

public class Robot extends TimedRobot {
    private final ThriftyNova m_motor = new ThriftyNova(1);

    @Override
    public void teleopPeriodic() {
        m_motor.setPercent(0.5);
    }
}
```

### Control Basics

**Speed:** Values range from -1.0 (full reverse) to 1.0 (full forward). 0.0 stops the motor.

**Multiple Motors:** Create separate instances for each motor (e.g., left and right drive motors).

<RulesBox title="Key Points" subtitle="Remember:">

- Create motors as private fields.
- Use unique CAN IDs.
- Talon FX uses `setControl`.
- SPARK MAX and SPARK Flex use `set` for this introductory percent-output example.
- Thrifty Nova uses `setPercent`.
- Range is -1.0 to 1.0.

</RulesBox>

## About GarageDocs

GarageDocs is maintained by FRC 4451 ROBOTZ Garage. It grew from the open-source [Mantik](https://github.com/itkan-robotics/mantik) project and now combines FRC 4451's lessons, team code, simulation workflow, and selected material from other FIRST contributors.

Java lessons and Practice assignments run in the browser. Hardware covers the electrical system and vendor configuration clients. Kit Bot and FRC lessons use the WPILib development tools and teach students to test robot code in simulation before moving to hardware. Technical lessons include a Sources list with the documentation, API references, and team code used to write them.

## Contributing
[Claude](https://claude.com/) (Anthropic) and [Codex](https://openai.com/codex/) (OpenAI) are used to help draft, review, edit lessons, and site code using the team's code and cited documentation.
FRC 4451's mentors review, edit for clarity, and approve the published material before each commit. 

LLMs scrape and collect information for educational material for this effort. However, LLMs are not a replacement for human thought.
Human review is required for all content submitted to GarageDocs. Humans need to verify that the content is accurate, complete, and appropriate for the intended audience.

### Report a problem

Open a [GitHub issue](https://github.com/frc4451/garagedocs/issues/new) when you find a broken link, unclear instruction, technical error, or missing source. Include the page address, the section heading, what you expected, and what you found. Screenshots and links to official documentation help the maintainers reproduce and check the problem.

### Prepare an edit

1. [Fork the GarageDocs repository](https://github.com/frc4451/garagedocs/fork), then create a branch for one focused change.
2. Follow the writing rules in [`docs/documentation-style.md`](https://github.com/frc4451/garagedocs/blob/main/docs/documentation-style.md) and the MDX guidance in [`docs/content-authoring.md`](https://github.com/frc4451/garagedocs/blob/main/docs/content-authoring.md).
3. Cite the specific documentation page, API reference, or source file that supports each technical claim. Every lesson page ends with a `Sources` block.
4. Preview the site with `npm run dev`. Check the changed page on both a narrow mobile layout and a laptop-sized layout.
5. Run the checks that apply to the change. At minimum, run `npm run check`, `npm run build`, and `npm run links`. Run `npm run sources` after changing citations, and run the Java or Practice checks listed in the repository instructions when those sections change.

### Submit the change

Open a pull request against `main`. Explain the problem, describe the resulting behavior or lesson text, and list the checks you ran. Keep unrelated changes in separate pull requests so reviewers can verify each change on its own. A maintainer will review the technical accuracy, sources, readability, and site behavior before merging it.

## Source repositories

- **[itkan-robotics/mantik](https://github.com/itkan-robotics/mantik)** is the original project behind GarageDocs. The site's Astro foundation, original FRC lesson outline, and Resources catalog came from Mantik. The curriculum also uses its [PID practice project](https://github.com/itkan-robotics/mantik-pid-practice) and tutorial videos. Mantik's browser PID simulator was removed from this site in September 2026 because it was outside the site's scope.
- **[FRC3476/mantik-orange](https://github.com/FRC3476/mantik-orange)** is the source of the Java playground used in Java lessons and Practice assignments.
- **[FSC Open Docs](https://github.com/firstsouthcarolina/FSCOpenDocs)** from FIRST South Carolina is the source of the two FRC Networking pages. Its historical [Propositional Logic and Rules of Inference module](https://github.com/firstsouthcarolina/FSCOpenDocs/blob/efb6489ba9fe9da52b3f4bf3bd19455ffd7d4c40/docs/curriculum/java-fundamentals/07-propositional-logic/index.md) supplies the credited curriculum structure and examples adapted in [Boolean Logic](/java/fundamentals/boolean-logic). FSC contributors, including FRC 4451's mentors, wrote this material. It is used under CC BY-SA 4.0; see [NOTICE](https://github.com/frc4451/garagedocs/blob/main/NOTICE).
- **[AdvantageKit](https://github.com/Mechanical-Advantage/AdvantageKit)** is Mechanical Advantage's logging and replay framework repository. Its [template projects](https://github.com/Mechanical-Advantage/AdvantageKit/tree/main/template_projects/sources), including the 2026 KitBot project, provide reference implementations for real, simulation, and replay IO. Their Spotless configuration is the origin of the Java formatting standard GarageDocs calls the **AdvantageKit Spotless Profile**.
- **[Team 190 GompeiLib](https://github.com/Team-190/GompeiLib)** provides the component architecture used in the FRC mechanism lessons: separate flywheel, roller, elevator, and angular-position components owned by a parent subsystem. GarageDocs adapts its current WPILib 2027-alpha code to the site's 2026 APIs and extends the roller example with FRC 4451's voltage and torque-current controls.
- **[FRC 2910's 2026 Competition Robot](https://github.com/FRCTeam2910/2026CompetitionRobot-Public)** provides the wanted-state and current-state pattern used in the State-Driven Robot Design lessons. GarageDocs refers to its `SuperStructure` and `HopperSubsystem` for state transitions, mechanism commands, and logging the requested and active states.
- **[FRC 254's 2025 Robot](https://github.com/Team254/FRC-2025-Public)** provides the transition-graph example used in the State-Driven Robot Design lessons. Its superstructure defines allowed state changes and finds a safe route when coupled mechanisms cannot move directly between every pair of positions.
- **[frc4451/Ember2024](https://github.com/frc4451/Ember2024)** is FRC 4451's 2024 robot code, where the [VARC](/frc/varc) alignment pattern, the first `BobotState`, and the team's Mechanical Advantage-derived [`VirtualSubsystem`](/frc/virtual-subsystem) began. Lessons cite it for the origin of ideas Cobra still uses.
- **[frc4451/Riptide2025](https://github.com/frc4451/Riptide2025)** is FRC 4451's 2025 robot code. The [Choreo](/frc/choreo) and [QuestNav](/frc/questnav) lessons draw on its autonomous and headset code.
- **[frc4451/Scorpion2026](https://github.com/frc4451/Scorpion2026)** is FRC 4864's 2026 robot, *Scorpion*, built on the 2026 KitBot. The [Kit Bot](/kit-bot) section was written from that build and checks its finished behavior against this repository.
- **[frc4451/Cobra2026Private](https://github.com/frc4451/Cobra2026Private)** is FRC 4451's 2026 competition robot code. It provides the ROBOTZ Garage library (`org.robotzgarage.frc2026`) and reference implementations for FRC lessons. The repository is public despite its name, so every file a lesson cites can be opened and checked. Lesson examples may be simplified or use illustrative configuration values.
- **[hammerheads5000/FuelSim](https://github.com/hammerheads5000/FuelSim)** is FRC 5000 Hammerheads' single-file fuel physics simulation for the 2026 game, used in [FuelSim](/frc/fuelsim). It is published under the MIT licence and is copied into a robot project rather than added as a vendordep; a copy has to keep its licence header. GarageDocs quotes its API and does not redistribute the file.
- **[maple-sim](https://github.com/Shenzhen-Robotics-Alliance/maple-sim)** from the Shenzhen Robotics Alliance is the physics-engine field and drivetrain simulation used in [maple-sim](/frc/maple-sim), built on [dyn4j](https://dyn4j.org/). It is published under the BSD 3-Clause licence and ships as a vendordep, including a 2026 Rebuilt arena.
- **[Spectrum3847/2026-Spectrum](https://github.com/Spectrum3847/2026-Spectrum)** and **[2025-Spectrum](https://github.com/Spectrum3847/2025-Spectrum)** are FRC 3847's robot code and SpectrumLib. The [Mounts and Moving Roots](/frc/mounts-and-moving-roots) lesson is written from their simulation package, their roller indicator is the source for drawing spinners, their AdvantageScope asset folder is the worked model example in [Mechanisms in 3D](/frc/mechanisms-in-3d), and their maple-sim bridge is cited in [maple-sim](/frc/maple-sim). They also publish [their own programming docs](https://github.com/Spectrum3847/2026-Spectrum/tree/main/docs) alongside the code. **Spectrum's own code carries no published licence** (the only licence file in either repository is WPILib's), so GarageDocs describes and cites these repositories and does not quote them; the one exception is their `MapleSimSwerveDrivetrain`, which carries maple-sim's own MIT header.
- **Mechanical Advantage robot code:** Team 6328 publishes its seasonal code in [RobotCode2024Public](https://github.com/Mechanical-Advantage/RobotCode2024Public), [RobotCode2025Public](https://github.com/Mechanical-Advantage/RobotCode2025Public), and [RobotCode2026Public](https://github.com/Mechanical-Advantage/RobotCode2026Public). GarageDocs uses these repositories for working examples of `VirtualSubsystem`, simulation, IO layers, vision, and competition-robot architecture.

## Site software and review

GarageDocs uses [Astro](https://astro.build/) and MDX for lesson pages, [React](https://react.dev/) for the Java playground and Resources catalog, [Pagefind](https://pagefind.app/) for search, and [Shiki](https://shiki.style/) for code highlighting. GitHub Actions publishes the site to GitHub Pages.

The site bundles [Fira Sans](https://fonts.google.com/specimen/Fira+Sans), [Fira Code](https://fonts.google.com/specimen/Fira+Code), and [Font Awesome Free](https://fontawesome.com/license/free) so text, code, and interface icons remain available offline.

The Java playground compiles and runs real Java in the browser with [CheerpJ](https://cheerpj.com/) and the [Eclipse Compiler for Java](https://github.com/eclipse-jdt/eclipse.jdt.core).

Licensing and third-party notices are recorded in the repository's [NOTICE](https://github.com/frc4451/garagedocs/blob/main/NOTICE) file.

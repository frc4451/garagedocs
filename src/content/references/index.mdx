## Source repositories

- **[itkan-robotics/mantik](https://github.com/itkan-robotics/mantik)** is the original project behind GarageDocs. The site's Astro foundation, original FRC lesson outline, and Resources catalog came from Mantik. The curriculum also uses its [PID practice project](https://github.com/itkan-robotics/mantik-pid-practice) and tutorial videos. Mantik's FTC lessons and browser PID simulator were removed from this site in September 2026 because they were outside its scope.
- **[FRC3476/mantik-orange](https://github.com/FRC3476/mantik-orange)** is the source of the Java playground used in Java lessons and Practice assignments.
- **[FSC Open Docs](https://github.com/firstsouthcarolina/FSCOpenDocs)** from FIRST South Carolina is the source of the two FRC Networking pages. FSC contributors, including FRC 4451's mentors, wrote these pages. They are used under CC BY-SA 4.0; see [NOTICE](https://github.com/frc4451/garagedocs/blob/main/NOTICE).
- **[Cobra2026Private](https://github.com/frc4451/Cobra2026Private)** is FRC 4451's 2026 competition robot code. It provides the ROBOTZ Garage library (`org.robotzgarage.frc2026`) and reference implementations for FRC lessons. Lesson examples may be simplified or use illustrative configuration values.
- **[Riptide2025](https://github.com/frc4451/Riptide2025)** is FRC 4451's 2025 robot code. The [Choreo](/frc/choreo) and [QuestNav](/frc/questnav) lessons draw on its autonomous and headset code.

## Technical documentation

- **WPILib:** [docs.wpilib.org](https://docs.wpilib.org/) and the [Java API](https://github.wpilib.org/allwpilib/docs/release/java/) for command-based programming, simulation, unit testing, telemetry, and coordinate systems.
- **CTRE Phoenix 6:** [v6.docs.ctr-electronics.com](https://v6.docs.ctr-electronics.com/) for control requests, Motion Magic, CANcoder, simulation, unit testing, and the [manual PID tuning](https://v6.docs.ctr-electronics.com/en/latest/docs/api-reference/device-specific/talonfx/manual-pid-tuning.html) application note used in the [Manual Tuning](/frc/manual-pid-tuning) group.
- **REV:** [docs.revrobotics.com](https://docs.revrobotics.com/) and the [REVLib API](https://codedocs.revrobotics.com/java/).
- **AdvantageKit:** [docs.advantagekit.org](https://docs.advantagekit.org/) for the IO layer, logging, and replay.
- **AdvantageScope:** [docs.advantagescope.org](https://docs.advantagescope.org/) for the data sources and tabs covered in the [AdvantageScope Tour](/tools/advantagescope-tour).
- **PhotonVision:** [docs.photonvision.org](https://docs.photonvision.org/).
- **Path planning:** [PathPlanner](https://pathplanner.dev/), [Choreo](https://choreo.autos/), and [BLine](https://bline-docs.pages.dev/).
- **QuestNav:** [questnav.gg](https://questnav.gg/).
- **Project Lombok:** [projectlombok.org](https://projectlombok.org/features/).
- **Development tools:** [Git](https://git-scm.com/doc), [GitHub](https://docs.github.com/), and [Visual Studio Code](https://code.visualstudio.com/docs).
- **FRC electrical:** [frcelectrical.org](https://frcelectrical.org/) for robot wiring and electrical systems.

## Site software and review

GarageDocs uses [Astro](https://astro.build/) and MDX for lesson pages, [React](https://react.dev/) for the Java playground and Resources catalog, [Pagefind](https://pagefind.app/) for search, and [Shiki](https://shiki.style/) for code highlighting. GitHub Actions publishes the site to GitHub Pages.

The Java playground compiles and runs real Java in the browser with [CheerpJ](https://cheerpj.com/) and the [Eclipse Compiler for Java](https://github.com/eclipse-jdt/eclipse.jdt.core).

FRC 4451's mentors use [Claude](https://claude.com/) (Anthropic) and Codex (OpenAI) to help draft, review, and edit lessons and site code using the team's code and cited documentation. FRC 4451's mentors review the published material. The project has separate checks for internal links, links to headings, and runnable Java lesson examples.

Licensing and third-party notices are recorded in the repository's [NOTICE](https://github.com/frc4451/garagedocs/blob/main/NOTICE) file.

## About GarageDocs

GarageDocs is maintained by FRC 4451 ROBOTZ Garage. It grew from the open-source [Mantik](https://github.com/itkan-robotics/mantik) project and now combines FRC 4451's lessons, team code, simulation workflow, and selected material from other FIRST contributors.

Java lessons and Practice assignments run in the browser. Hardware covers the electrical system and vendor configuration clients. Kit Bot and FRC lessons use the WPILib development tools and teach students to test robot code in simulation before moving to hardware. Technical lessons include a Sources list with the documentation, API references, and team code used to write them.

## Source repositories

- **[itkan-robotics/mantik](https://github.com/itkan-robotics/mantik)** is the original project behind GarageDocs. The site's Astro foundation, original FRC lesson outline, and Resources catalog came from Mantik. The curriculum also uses its [PID practice project](https://github.com/itkan-robotics/mantik-pid-practice) and tutorial videos. Mantik's browser PID simulator was removed from this site in September 2026 because it was outside the site's scope.
- **[FRC3476/mantik-orange](https://github.com/FRC3476/mantik-orange)** is the source of the Java playground used in Java lessons and Practice assignments.
- **[FSC Open Docs](https://github.com/firstsouthcarolina/FSCOpenDocs)** from FIRST South Carolina is the source of the two FRC Networking pages and the Boolean Algebra appendix expanded in [Boolean Logic](/java/fundamentals/java-boolean-logic). FSC contributors, including FRC 4451's mentors, wrote this material. It is used under CC BY-SA 4.0; see [NOTICE](https://github.com/frc4451/garagedocs/blob/main/NOTICE).
- **[Cobra2026Private](https://github.com/frc4451/Cobra2026Private)** is FRC 4451's 2026 competition robot code. It provides the ROBOTZ Garage library (`org.robotzgarage.frc2026`) and reference implementations for FRC lessons. Lesson examples may be simplified or use illustrative configuration values.
- **[Team 190 GompeiLib](https://github.com/Team-190/GompeiLib)** provides the component architecture used in the FRC mechanism lessons: separate flywheel, roller, elevator, and angular-position components owned by a parent subsystem. GarageDocs adapts its current WPILib 2027-alpha code to the site's 2026 APIs and extends the roller example with FRC 4451's voltage and torque-current controls.
- **[Riptide2025](https://github.com/frc4451/Riptide2025)** is FRC 4451's 2025 robot code. The [Choreo](/frc/choreo) and [QuestNav](/frc/questnav) lessons draw on its autonomous and headset code.
- **[Ember2024](https://github.com/frc4451/Ember2024)** is FRC 4451's 2024 robot code, where the [VARC](/frc/varc) alignment pattern, the first `BobotState`, and the team's Mechanical Advantage-derived [`VirtualSubsystem`](/frc/virtual-subsystem) began. Lessons cite it for the origin of ideas Cobra still uses.
- **[Scorpion2026](https://github.com/frc4451/Scorpion2026)** is FRC 4864's 2026 robot, *Scorpion*, built on the 2026 KitBot. The [Kit Bot](/kit-bot) section was written from that build and checks its finished behavior against this repository.
- **Mechanical Advantage robot code:** Team 6328 publishes its seasonal code in [RobotCode2024Public](https://github.com/Mechanical-Advantage/RobotCode2024Public), [RobotCode2025Public](https://github.com/Mechanical-Advantage/RobotCode2025Public), and [RobotCode2026Public](https://github.com/Mechanical-Advantage/RobotCode2026Public). GarageDocs uses these repositories for working examples of `VirtualSubsystem`, simulation, IO layers, vision, and competition-robot architecture.
- **[AdvantageKit](https://github.com/Mechanical-Advantage/AdvantageKit)** is Mechanical Advantage's logging and replay framework repository. Its [template projects](https://github.com/Mechanical-Advantage/AdvantageKit/tree/main/template_projects/sources), including the 2026 KitBot project, provide reference implementations for real, simulation, and replay IO.

- **WPILib:** [docs.wpilib.org](https://docs.wpilib.org/) and the [Java API](https://github.wpilib.org/allwpilib/docs/release/java/) for command-based programming, simulation, unit testing, telemetry, and coordinate systems.

- **AdvantageKit:** [docs.advantagekit.org](https://docs.advantagekit.org/) for the IO layer, logging, and replay.
- **AdvantageScope:** [docs.advantagescope.org](https://docs.advantagescope.org/) for the data sources and tabs covered in the [AdvantageScope Tour](/tools/advantagescope-tour).
- **PhotonVision:** [docs.photonvision.org](https://docs.photonvision.org/).
- **Path planning:** [PathPlanner](https://pathplanner.dev/), [Choreo](https://choreo.autos/), and [BLine](https://bline-docs.pages.dev/).
- **QuestNav:** [questnav.gg](https://questnav.gg/).
- **Project Lombok:** [projectlombok.org](https://projectlombok.org/features/).
- **Development tools:** [Git](https://git-scm.com/doc), [GitHub](https://docs.github.com/), and [Visual Studio Code](https://code.visualstudio.com/docs).
- **FRC electrical:** [frcelectrical.org](https://frcelectrical.org/) for robot wiring and electrical systems.
- **FRC control-system setup:** WPILib's [Zero to Robot](https://docs.wpilib.org/en/stable/docs/zero-to-robot/introduction.html), the [Vivid-Hosting radio documentation](https://frc-radio.vivid-hosting.net/), and [REV Hardware Client 2](https://docs.revrobotics.com/rev-hardware-client-2/) for imaging, radio setup, firmware, CAN IDs, and first bring-up.
- **Hardware vendors:** [CTRE Phoenix](https://pro.docs.ctr-electronics.com/), [West Coast Products](https://docs.wcproducts.com/), [REV](https://docs.revrobotics.com/), [Thrifty Bot](https://docs.thethriftybot.com/), [AndyMark](https://andymark.com/), [Arducam](https://docs.arducam.com/), [PhotonVision](https://docs.photonvision.org/en/latest/), [QuestNav](https://questnav.gg/docs/), [Pololu](https://www.pololu.com/), and [Team 900's ZebraSwitch documentation](https://team900.org/blog/2023-ZebraSwitch-2.0/) for the devices covered in the [Hardware](/hardware) section.

## Site software and review

GarageDocs uses [Astro](https://astro.build/) and MDX for lesson pages, [React](https://react.dev/) for the Java playground and Resources catalog, [Pagefind](https://pagefind.app/) for search, and [Shiki](https://shiki.style/) for code highlighting. GitHub Actions publishes the site to GitHub Pages.

The site bundles [Source Sans 3](https://fonts.google.com/specimen/Source+Sans+3), [Source Serif 4](https://fonts.google.com/specimen/Source+Serif+4), and [Font Awesome Free](https://fontawesome.com/license/free) so text and interface icons remain available offline.

The Java playground compiles and runs real Java in the browser with [CheerpJ](https://cheerpj.com/) and the [Eclipse Compiler for Java](https://github.com/eclipse-jdt/eclipse.jdt.core).

[Claude](https://claude.com/) (Anthropic) and [Codex](https://openai.com/codex/) (OpenAI) help draft, review, and edit lessons and site code using the team's code and cited documentation. FRC 4451's mentors review the published material. The project has separate checks for internal links, links to headings, and runnable Java lesson examples.

Licensing and third-party notices are recorded in the repository's [NOTICE](https://github.com/frc4451/garagedocs/blob/main/NOTICE) file.

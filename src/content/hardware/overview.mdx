Hardware teaches the electrical and configuration work that connects robot code to a physical machine. Start with the foundations before touching robot wiring. Use the vendor pages to identify, configure, replace, and troubleshoot the hardware FRC 4451 has used.

### Start with electrical foundations

1. [Robot Control System](/hardware/hardware-control-system): trace power and data through the robot.
2. [5 V, 12 V, and Current](/hardware/electrical-basics-voltage-current): match voltage, current capacity, regulation, and protection to a load.
3. [Wire Gauge and Selection](/hardware/wire-gauge-and-selection): read AWG numbers, let the breaker set the minimum wire, and pick the gauge and connector for each circuit.
4. [Power, Wiring, and CAN](/hardware/power-wiring-and-can): build and document connections that survive robot motion.

### Connected hardware

Continue with the Vivid-Hosting radio, Pololu voltage regulators, PhotonVision coprocessors, cameras, Quest 3S with QuestNav, and the team's ZebraSwitch page. Each page starts with the power requirement and the configuration tool that matters for that device.

Finish with the [Hardware Bring-Up Checklist](/hardware/hardware-bring-up-checklist). It tests one layer at a time: unpowered inspection, power, controller, network, CAN clients, robot code, actuators, and sensors.

<RulesBox title="Safety and current information">

Use the current FRC game manual, inspection rules, manufacturer documentation, and team safety procedures when selecting or wiring hardware. A lesson explains the system, but it does not make an old part number or last season's wiring legal for the current season.

</RulesBox>

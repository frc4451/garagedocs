### Start with the exact product

Thrifty Bot sells motor controllers, encoders, distance sensors, cameras, power devices, and mechanical parts. Read the product label before choosing instructions. This page focuses on devices that use **Thrifty Config** or **ThriftyLib**, including the Thrifty Nova used by the team library.

### Thrifty Config workflow

1. Power the device from an appropriate protected branch.
2. Connect the supported configuration path described by the product manual.
3. Open Thrifty Config and confirm the expected device appears.
4. Use the identify function or disconnect other devices to match the screen entry to the physical device.
5. Update supported firmware when the team has approved the version.
6. Assign a unique CAN ID and label the device.
7. Set product-specific options, then power-cycle and verify that they persisted.
8. Match the ID and settings in the robot code.

The Thrifty Nova motor-type setting changes how the controller handles different motor phase conventions. Verify the physical motor before choosing the setting. An incorrect selection can make the observed direction disagree with the wiring and code assumptions.

### Connect the configuration to Cobra

Cobra includes ThriftyLib and defines a `ThriftyNovaConfig` in the shared motor configuration code. The client establishes device identity and firmware. The Java configuration establishes the behavior the program requests each time it starts.

<RulesBox title="Done when">

The expected Thrifty Bot device appears in Thrifty Config with the approved firmware, a unique labeled CAN ID, and the correct product-specific options. The same ID and motor type appear in the robot constants.

</RulesBox>

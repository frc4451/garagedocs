### Choose the motor before the settings

| Motor | Type setting | Sensor starting point | Team examples |
|---|---|---|---|
| NEO 1.1 | Brushless | Integrated hall sensor | Finn and Scorpion drivetrains; Scorpion superstructure option |
| NEO 550 | Brushless | Integrated hall sensor | Ember and Riptide swerve steering |
| CIM or another compatible brushed motor | Brushed | No integrated hall sensor; add the feedback device the mechanism needs | Finn coral mechanism and Scorpion superstructure option |

The SPARK MAX can control brushless and brushed motors. The selected motor type changes how the controller drives its output. A NEO or NEO 550 also needs its integrated encoder cable connected. REV warns that running those motors without that cable can damage the motor.

### Configure and verify one controller

1. Read the controller and motor labels.
2. In REV Hardware Client 2, assign a unique CAN ID.
3. Select brushless or brushed operation to match the motor.
4. Select the feedback sensor that is physically connected.
5. Set a conservative current limit for the motor and mechanism.
6. Save the required parameters and power-cycle the controller.
7. Confirm the Java constructor uses the same motor type.
8. Test at low output while watching direction, current, encoder position, and temperature.

`MotorType.kBrushed` in code is evidence that the controller expects a brushed motor. It does not identify the exact motor model. Use the robot bill of materials or the motor label to distinguish a CIM from another brushed motor.

<RulesBox title="Done when">

The SPARK MAX motor type, connected sensor, current limit, persisted parameters, Java constructor, and physical motor agree. The motor responds at low output and its expected sensor changes in the expected direction.

</RulesBox>

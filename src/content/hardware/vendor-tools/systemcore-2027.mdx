### Treat this as a transition plan

FRC 4451 plans to use SystemCore beginning in 2027. SystemCore combines the main robot computer with CAN, Ethernet, USB, I2C, configurable input and output, an onboard inertial measurement unit, and local status controls.

The 2027 software is still in alpha testing. Version pairings, images, ports, and setup steps can change. Check the current WPILib 2027 documentation and SystemcoreTesting repository before every bench session.

### What changes from a roboRIO workflow

| Area | SystemCore planning point |
|---|---|
| Power | Feed the controller as the current specification requires. Current test guidance says direct battery voltage and warns against a small regulator. |
| Operating system | Flash the SystemCore image that matches the hardware revision and WPILib alpha release. |
| CAN | Code may select one of the controller's CAN buses. Record the bus and device ID together. |
| Vendor software | Match WPILib, vendor library, firmware, and SystemCore package versions. A compatible 2026 roboRIO set is not proof of 2027 compatibility. |
| Hardware clients | Some clients can run as packages on SystemCore or connect to a service running there. Follow the vendor's current test notes. |
| I/O | Verify the pinout and electrical behavior before reusing a roboRIO cable or limit-switch circuit. |

### Team bring-up plan

1. Record the SystemCore hardware revision.
2. Choose one published compatibility set for the image, WPILib, Driver Station, and vendor libraries.
3. Flash the controller with the documented procedure for that revision.
4. Deploy a minimal WPILib project from VS Code.
5. Test Ethernet and one CAN bus with one device.
6. Add CTRE, REV, and Thrifty libraries one at a time.
7. Confirm logs, Driver Station communication, disable behavior, and code restart behavior.
8. Record every working version before adding the next device family.
9. Repeat the current-season electrical and inspection checks before installing the controller on a competition robot.

Do not copy an alpha compatibility table into a permanent team checklist. Link to the live table and record the exact set that passed the team's own bench test.

<RulesBox title="Done when">

The team record names the SystemCore revision, image, WPILib release, Driver Station release, each vendor-library version, and the tested CAN bus. A minimal program deploys, disables, restarts, and reports logs correctly. Any untested device family remains marked unverified.

</RulesBox>

### The controller and motor are separate parts

The Talon FXS uses Phoenix 6, but the motor is not built into the controller. Cobra's hood configuration pairs a Talon FXS implementation with a WCP Minion model. The shared team library also supports a Talon FXS with or without an external CANcoder.

The Talon FXS supports the Minion, NEO, NEO 550, a NEO Vortex with the required adapter, and many brushed motors. Support does not mean the same settings work for every motor.

### Set the motor arrangement first

1. Identify the exact motor and its sensor connection.
2. Wire power, CAN, phases, and the required sensor cable using the current manual.
3. Open Phoenix Tuner X and assign a unique ID and name.
4. Select the motor arrangement that matches the installed motor.
5. Set current limits before commanding output.
6. Check the status lights and Self Test Snapshot for motor or sensor faults.
7. Request a small voltage with the mechanism unloaded.
8. Confirm motor direction and sensor direction separately.

An incorrect motor arrangement can produce a fault, incorrect commutation, unexpected direction, or poor control. Do not correct a configuration mistake by swapping random wires or negating values in code.

<RulesBox title="Done when">

Phoenix Tuner X shows the correct motor arrangement, CAN identity, firmware, and no unexplained fault. The motor and sensor move in the expected direction at low voltage. Cobra's hardware record states whether the Minion pairing was installed or only modeled.

</RulesBox>

### Know the REV devices on the robot

The Kit Bot uses SPARK MAX motor controllers and NEO motors. Other team robots may use SPARK Flex controllers, the Power Distribution Hub (PDH), Pneumatic Hub, Servo Hub, or other supported REV devices.

REVLib 2026 and current ION devices use **REV Hardware Client 2 (RHC2)**. The original REV Hardware Client and RHC2 are separate applications. Follow the current device requirements before deciding which client can update older firmware.

| Client action | What it establishes |
|---|---|
| Scan for devices | Which USB and CAN devices communicate |
| Identify and assign a unique ID | Which physical device matches code |
| Update or recover firmware | Compatibility with current REV tools and REVLib |
| Inspect faults and telemetry | Evidence about power, sensors, temperature, and communication |
| Edit and persist parameters | Settings that survive a power cycle |
| Back up and restore configuration | A repeatable replacement-device workflow |
| Run a motor | Direction and sensor checks before robot code |

RHC2 requires supported current firmware. Devices on older firmware may first appear as outdated and require the documented recovery process.

### Bring up a REV CAN bus

1. Install RHC2 and close other programs that may hold the device connection.
2. Connect one supported device by USB to establish a bridge.
3. Scan and confirm the device type and firmware.
4. Update or recover firmware using the documented path.
5. Assign a unique CAN ID and label the controller.
6. Set the correct motor and sensor type.
7. Apply an appropriate current limit before a motor test.
8. Persist required parameters, power-cycle, and scan again.
9. Compare IDs and parameters with the robot constants.
10. Save a configuration backup or screenshot for the hardware record.

RHC2 will not run a motor when a roboRIO is present on the same bus. This safety behavior can look like a client failure if the robot controller remains connected. Follow the RHC2 test procedure and keep the mechanism unloaded.

<RulesBox title="Done when">

RHC2 shows every expected REV device exactly once with approved firmware and a unique labeled ID. Motor and sensor types, current limits, and persisted parameters match the hardware plan and robot code. No fault remains unexplained.

</RulesBox>

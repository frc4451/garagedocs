<RulesBox title="2026 is the roboRIO's last season">

FIRST announced in November 2024 that a new controller, Systemcore, will be used in FRC starting in the 2027 season. The roboRIO is retired from FRC after the 2026 season, so this page describes the controller FRC 4451 runs this year and the one every older robot in the shop still uses. Read it to operate and troubleshoot what is on the bench; read [SystemCore for 2027](/hardware/systemcore-2027) for what replaces it.

</RulesBox>

### The robot computer

The National Instruments roboRIO runs the deployed robot program and connects Ethernet, CAN, USB, and direct sensors. Learn the labels on the case before plugging in a cable. The power input, CAN terminals, Ethernet port, USB ports, and sensor headers serve different electrical interfaces.

### NI and WPILib tools

| Tool | Use it for | Proof to save |
|---|---|---|
| FRC Game Tools | Install the Driver Station, NI drivers, and imaging software | Driver Station opens and USB communication works |
| roboRIO Imaging Tool | Install the current image and set the team number | Current image year and correct team number |
| roboRIO web dashboard | Inspect versions, network interfaces, resources, and startup settings | Expected image, address, and startup state |
| roboRIO Log | Read program startup and runtime output | A clean startup or the first useful error |

A roboRIO 1 stores its image internally and uses **Format Target** over USB. A roboRIO 2 boots from a microSD card, so its image is written to the card before the team number is applied. Follow [R00 Part 2](/kit-bot/r00-roborio-imaging) for the complete procedure.

### Read the Driver Station status

- **No Communications:** the laptop cannot reach the roboRIO. Check power, radio or USB, team number, and addressing.
- **No Robot Code:** the roboRIO is reachable, but the program is not running. Check deploy output and the roboRIO log.
- **Joysticks missing:** robot communication may be healthy while the controller or Driver Station assignment is wrong.

Use USB at `172.22.11.2` to separate radio problems from controller problems. Once USB works, test the Ethernet path through the radio.

<RulesBox title="Done when">

Show the current image, correct team number, reachable web dashboard, and a roboRIO log. Explain whether a demonstrated failure is in communication, robot-code startup, or an attached device.

</RulesBox>

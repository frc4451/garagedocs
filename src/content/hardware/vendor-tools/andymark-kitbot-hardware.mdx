### Use the physical build as a code input

The FRC KitBot begins with the AndyMark Kit of Parts drivetrain platform and the season's official mechanism parts. Scorpion's drivetrain simulation uses the WPILib KitBot preset with two NEO motors per side, a `10.71:1` reduction, and `6 inch` wheels. Those values describe the code model. Confirm the physical robot before treating them as its bill of materials.

### Record the installed drivetrain

1. Identify the chassis generation and season-specific KitBot parts.
2. Count the motors on each side.
3. Read the gearbox reduction from the assembly documentation or installed gearing.
4. Measure or identify the wheel diameter.
5. Measure track width using the convention required by the drivetrain code.
6. Record which controller drives each motor and which motors follow.
7. Check chain or belt tension, wheel alignment, fastener retention, and free movement with power off.

The exact wheel size, reduction, track width, motor count, and mass affect simulation and odometry. A copied preset is a starting point only when the physical assembly matches it.

### Follow the official build sequence

Use FIRST's current KitBot build instructions as the controlling assembly guide. AndyMark product pages help identify replacement parts and chassis hardware. Community build threads can show useful examples, but they do not replace the official dimensions or current game manual.

<RulesBox title="Done when">

The hardware record names the chassis, wheel diameter, gearbox reduction, motor count, controller IDs, and measured track width. The drivetrain constants and simulation model use the same verified values.

</RulesBox>

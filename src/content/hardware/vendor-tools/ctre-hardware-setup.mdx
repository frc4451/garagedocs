### Know the CTRE devices on the robot

Cobra uses Phoenix 6 with Talon FX and Talon FXS motor controllers, CANcoder absolute encoders, and a Pigeon 2 gyro. Its generated swerve constants bind each physical CAN ID to a module position. A wrong ID can make code control the wrong corner even when every device is online.

| Client action | What it establishes |
|---|---|
| Select the target roboRIO or CANivore | Which CAN network you are inspecting |
| Scan the device list | Which devices currently communicate |
| Blink a device | Which physical device owns a screen entry |
| Assign a name and unique ID | Stable identity for wiring and code |
| Field-upgrade firmware | Compatibility with the installed Phoenix release |
| Self Test Snapshot | Current faults, measurements, and configuration evidence |
| Plot signals | Whether position, velocity, current, or yaw changes as expected |
| Control a device | Limited bench verification before robot code |
| Review licensing | Whether requested Phoenix Pro features are available |

Phoenix 6 base features do not require a Pro license. A license enables specific Pro features. The firmware, Phoenix API year, and license year must be compatible when the code relies on one of those features.

### Bring up a CTRE CAN bus

1. Install the current Phoenix Tuner X from CTRE's documentation.
2. Connect to the roboRIO target or directly supported CAN adapter.
3. Start with one new device when duplicate default IDs are possible.
4. Confirm the device type and serial information.
5. Blink it, assign its planned ID and name, and attach a physical label.
6. Apply the team-approved firmware.
7. Repeat until every expected device appears once.
8. Save a Self Test Snapshot for faults and bus information.
9. Compare device IDs and bus names with `TunerConstants` and mechanism constants.

Use the Tuner X swerve project generator only with measured module geometry, ratios, wheel size, IDs, and offsets. Generated constants are hardware configuration, so review them like wiring documentation.

### Test safely

Place the robot on blocks, clear the mechanism, and station one person at Driver Station **Disable** before controlling a motor. Start with a small request. Confirm direction and stop behavior before increasing output.

<RulesBox title="Done when">

Tuner X shows every expected CTRE device exactly once with the approved firmware, ID, bus, and license state. Physical labels and Java constants match. A saved Self Test Snapshot contains no unexplained faults.

</RulesBox>

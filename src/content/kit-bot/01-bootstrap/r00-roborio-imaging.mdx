<RulesBox title="Before you start">

Complete [R00: WPILib Setup](/kit-bot/r00-wpilib-setup). Work with a mentor and use a Windows computer with permission to install software. You need the roboRIO, its power connection, a data cable, and a charged robot battery. Keep the robot disabled; this lesson does not move a motor.


</RulesBox>

The roboRIO runs the robot program. **Imaging** installs the current FRC operating-system image and libraries. The image changes each season, while the team number tells development tools and the Driver Station which robot they should find.

The WPILib installer and the FRC Game Tools are separate downloads. Install the [FRC Game Tools](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/frc-game-tools.html) on the Windows computer used for this work. They provide:

- The FRC Driver Station.
- The roboRIO Imaging Tool and current images.
- The NI drivers used for USB communication.

Restart Windows if the installer asks. Open the Driver Station once after installation so you know it starts.

### Identify the controller

Read the label before choosing an imaging procedure:

| Controller | Where its operating system lives | Correct procedure |
|---|---|---|
| roboRIO 1 | Internal storage | Connect over USB and use **Format Target** in the roboRIO Imaging Tool. |
| roboRIO 2 | Removable microSD card | Write the image directly to the microSD card, reinstall it, then set the team number. |

The roboRIO 2 cannot be imaged directly with the Imaging Tool. The tool is still used after the card is installed to set startup settings.

### Image a roboRIO 1

1. Power the roboRIO from the robot power-distribution device. Check that both ends of its power connector are secure.
2. Connect the roboRIO USB device port to the Windows computer with a USB printer cable.
3. Open **roboRIO Imaging Tool** and select the controller it finds.
4. Choose **Format Target**.
5. Enter the team number. For FRC 4451, enter `4451`.
6. Select the newest image installed for the current season.
7. Start the reformat and leave the power and USB cable connected until it completes.
8. Restart the roboRIO when the tool finishes.

Firmware and the yearly image are different. Update firmware only when the Imaging Tool says the installed firmware is too old for the image.

### Image a roboRIO 2

1. Turn off robot power before removing the microSD card.
2. In the roboRIO Imaging Tool, use the **SD** button to open the folder containing the current roboRIO 2 image.
3. Insert the microSD card into the computer or a USB card reader.
4. Use a supported image writer such as [balenaEtcher](https://etcher.balena.io/) or [Raspberry Pi Imager](https://www.raspberrypi.com/software/) to write the `FRC_roboRIO2_YEAR_VERSION.img.zip` image to the card.
5. If Windows asks to format the card after writing, cancel that prompt.
6. Reinstall the card fully, then power the roboRIO.
7. Connect to the roboRIO and use **Edit Startup Settings** in the Imaging Tool to set the team number.

### Verify the result

Open the FRC Driver Station and check the status indicators. The robot should appear with the expected team number and current image year. A USB connection uses `172.22.11.2`, so it can work even before the radio is configured.

Save one screenshot that shows the team number, image version, and connected status. Do not include a radio password or other secret in the screenshot.

### Troubleshooting

- **No roboRIO appears in the Imaging Tool:** wait for the USB driver, try another data cable, and confirm robot power. A charge-only USB cable cannot carry data.
- **The image list is from an older season:** update the FRC Game Tools. The images are installed with that package.
- **A roboRIO 2 will not boot:** turn off power and confirm the microSD card is fully inserted and contains the roboRIO 2 image.
- **The Driver Station shows the wrong team:** use **Edit Startup Settings** or the Team Number Setter, then restart the controller.

<RulesBox title="Done when">

The Driver Station reaches the roboRIO over USB, shows the correct team number, and reports the current season's image. You can explain why a roboRIO 1 uses **Format Target** while a roboRIO 2 uses a separately written microSD card.

</RulesBox>

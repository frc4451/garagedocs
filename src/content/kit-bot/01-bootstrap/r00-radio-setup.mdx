## Before You Start

This mentor-supervised hardware branch is not required for R01-R05. Complete [R00 Part 2: Image the roboRIO](/kit-bot/r00-roborio-imaging). Review [Vivid-Hosting Radio](/hardware/vivid-hosting-radio), [Command Line Basics](/tools/command-line-basics), and [Network Diagnostics: Ping a Device](/tools/network-diagnostics#rung-2-test-reachability). Work with a mentor. You need the robot's VH-109, a second VH-109 and VH-117 power adapter for the recommended shop access point, Ethernet cables, and the settings approved by FRC 4451. Get credentials from the mentor. Never put keys or passwords in screenshots, notes, commits, or chat.

The robot radio connects the Driver Station computer to the roboRIO. In the recommended shop setup, one VH-109 rides on the robot and a second VH-109 acts as the access point near the Driver Station.

```text
Driver Station laptop ── Ethernet or Wi-Fi ── shop access point
                                               ))) 6 GHz (((
                                      robot VH-109 ── Ethernet ── roboRIO
```

The two radios must use matching team, suffix, and 6 GHz security settings.

## Open the Configuration Page

1. Connect the radio's **DS** port directly to the computer with Ethernet.
2. Power the radio through its robot power input or the approved PoE adapter.
3. Disconnect other networks if they interfere with discovery.
4. Open `http://radio.local/` in a browser.

If that name does not work, follow the [Vivid-Hosting connection troubleshooting](https://frc-radio.vivid-hosting.net/getting-started/usage/practicing-at-home) with a mentor instead of guessing network settings.

## Update Firmware

1. Read the firmware version shown by the configuration page.
2. Open [Vivid-Hosting Firmware Releases](https://frc-radio.vivid-hosting.net/miscellaneous/firmware-releases). Have the mentor choose the file for the installed-version branch: radios below 1.2.0 and radios on 1.2.x or newer use different update paths.
3. Copy the published SHA-256 checksum into the configuration page.
4. Select the downloaded firmware and start the upload.
5. Leave power connected until the PWR light is solid and the SYS light returns to its slow blink.

A firmware update can take several minutes. Removing power during the update can damage the radio.

## Configure the Robot Radio

1. Choose **Robot Radio Mode**.
2. Enter the team number.
3. Enter the mentor-approved suffix, if FRC 4451 uses one for this robot.
4. Enter the approved 6 GHz key and, when used, the 2.4 GHz key.
5. Save the configuration and label the radio with its role.

## Configure the Shop Access Point

Repeat the connection and firmware steps on the second radio. Choose **Access Point Mode** and enter the exact same team number, suffix, and keys as the robot radio.

At an event, the field's programming system configures the radios. Do not replace those settings manually in the queue or at the field.

## Verify the Network Path

1. Connect the laptop to the shop access point.
2. Power the robot radio and roboRIO.
3. Open the Driver Station and confirm **Communications** becomes green.
4. Open the VS Code terminal or Windows PowerShell and run the command below. Replace `TEAM` with the team number, or use the team's `10.TE.AM.2` address. FRC 4451's address is `10.44.51.2`.

```powershell
ping roborio-TEAM-frc.local
```

If the name does not resolve, run `ping 10.44.51.2` and follow [Network Diagnostics: Ping a Device](/tools/network-diagnostics#rung-2-test-reachability).
5. Open the [robot network lesson](/frc/robot-network) and point to each device in the path you just tested.

<RulesBox title="Done When">

Both radios report the approved current firmware and complementary robot/access-point modes. The laptop joins the shop network, the Driver Station reports communications, and `ping` reaches the roboRIO. You can identify which radio is on the robot and which radio is the access point.

</RulesBox>

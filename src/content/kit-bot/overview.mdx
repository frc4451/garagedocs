Kit Bot is the bridge from small Java programs to a complete FRC robot project. You will build a drivetrain and a combined launcher and intake, control them with commands, test them in simulation, and add a short autonomous routine.

This course is for high-school students learning to program a robot. Use the refresher links when a word or pattern is unfamiliar. A mentor can help you work through an example before you try it yourself.

The lessons build two subsystems, drawing on the Scorpion project described in the Origin box:

- **Drive:** controls the left and right wheels.
- **Launcher:** controls a feeder and a separate roller that both intakes and launches fuel.

First test simulated motors on your laptop. Then add driver controls, measurements, a field display, and timed autonomous movement. **Autonomous** means the program chooses the actions without joystick input. AdvantageKit is a separate follow-up topic; it is not required here.

## Before You Start

Use the [Java fundamentals](/java/fundamentals) lessons to prepare for writing classes, methods, and interfaces. The refresher table below points to the specific ideas used in robot code. If a linked concept is new, work through that lesson before using it here.

You need a computer for the simulation path. [R00: WPILib Setup](/kit-bot/r00-wpilib-setup) explains the software and installation steps. Physical robot work begins later with a mentor; the [Hardware section](/hardware) supplies the equipment and electrical preparation.

## Follow the Simulation Route

1. Start with R00: WPILib Setup.
2. Continue through R01 to R14 in order, including each numbered part.
3. During this first pass, skip **R00 Part 2**, **R00 Part 3**, and **R12 Part 2**. Those three pages need a physical robot and a mentor.
4. Complete the simulation capstone. Return to the three hardware pages with a mentor when a robot is available.

The **Before You Start** section identifies prerequisites, including hardware or mentor requirements when they apply. Java refresher links explain concepts used by the steps.

<RulesBox title="Use the Code Listings">

A **complete file** starts with its `package` line and replaces the named file. A **partial snippet** belongs inside the named class or method. Put `import` lines after the package declaration, above the class.

Keep one `RobotContainer` and one `configureBindings()` method throughout the course. Add or replace only the lines a step names. Build with **WPILib: Build Robot Code** after each checkpoint. Fix the first reported error before adding more code.

</RulesBox>

## What You Will Build

```text
2026 KitBot
├── Drivetrain     four SPARK MAX controllers and four NEO motors in this course configuration
└── Launcher       separate feeder and intake-launcher motors; also intakes fuel
```

The course configuration is a programming example. Before using it on hardware, confirm the installed motors, controllers, gearing, and wiring with a mentor.

The same subsystem code works with two kinds of input/output code:

- A **simulation implementation** talks to WPILib's physics models.
- A **real implementation** talks to the motor controllers on the robot.

You will prove each required result in simulation. Real hardware is a later confirmation with a mentor and a robot that is safe to operate. R00 Parts 2 and 3 cover roboRIO imaging and radio setup for that hardware stage; they do not block the simulation lessons that begin at R01.

| 3. Motors, IO, and measured response | [R06](/kit-bot/r06-motor-controllers) to [R09 Part 2](/kit-bot/r09-characterization-part-2) | The drivetrain moves first, the two simulated launcher motors respond independently, and steady-state samples produce calculated `kS` and `kV` values. |

| 5. Autonomous | [R14](/kit-bot/r14-time-based-autonomous) and [the capstone](/kit-bot/rc-capstone) | A selected timed autonomous routine runs, stops, and can be demonstrated with the rest of the project. |

## Tools

- [WPILib 2026](/kit-bot/r00-wpilib-setup) supplies the robot libraries, simulator, GradleRIO, and a separate copy of Visual Studio Code (VS Code).
- [REVLib](/kit-bot/r00-wpilib-setup#step-3-add-revlib) lets Java code communicate with SPARK MAX motor controllers.
- [AdvantageScope](/tools/advantagescope-tour) graphs live values and displays saved log files.
- [Glass](/kit-bot/r14-time-based-autonomous) displays the autonomous chooser used in R14.

## Check Your Progress

Each required lesson ends with a **Done When** box. It names an observable result, such as a changing counter, a spinning simulated launcher, or a graph in AdvantageScope. Save the evidence named by the lesson. The [capstone](/kit-bot/rc-capstone) brings those results together. The [Badge 1 path](/badges) explains the separate mentor sign-off process.

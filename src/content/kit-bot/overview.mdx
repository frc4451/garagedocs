Kit Bot is the bridge from small Java programs to a complete FRC robot project. You will build a drivetrain and a combined launcher and intake, control them with commands, test them in simulation, and add a short autonomous routine.

Scorpion is the reference for the finished behavior, not a file-for-file template. This track keeps the parts a new programmer can build and explain: differential drive, real and simulation IO, intake and launcher controls, characterization, telemetry, drivetrain pose, and an autonomous chooser. Autonomous movement uses timed commands, and field position comes only from drivetrain sensors. The project stays focused on two subsystems: the drivetrain and a launcher subsystem that coordinates an independent feeder with the shared intake and launcher roller. AdvantageKit remains a follow-up topic; the Kit Bot uses the same IO separation without requiring the logging framework.

You can start with little programming experience. Follow the lessons in order, and use their Java links when a term or code pattern is new. Practice assignments give you another chance to use an idea in a smaller program. A **Before you start** box appears only when a lesson requires physical hardware or mentor supervision.

<RulesBox title="How to use the code listings">

Every listing says which file it belongs in. A **complete file** replaces that file. A **partial snippet** is added to the named class or method. Build after each small checkpoint instead of copying a full lesson and debugging everything at once.

</RulesBox>

### What you will build

```text
2026 KitBot
├── Drivetrain     four SparkMax controllers and four NEO motors
└── Launcher       separate feeder and intake-launcher motors; also intakes fuel
```

The same subsystem code works with two kinds of input/output code:

- A **simulation implementation** talks to WPILib's physics models.
- A **real implementation** talks to the motor controllers on the robot.

You will prove each required result in simulation. Real hardware is a later confirmation with a mentor and a robot that is safe to operate. R00 Parts 2 and 3 cover roboRIO imaging and radio setup for that hardware stage; they do not block the simulation lessons that begin at R01.

### Tools

- **WPILib 2026** supplies the robot libraries, simulator, GradleRIO, and a separate copy of Visual Studio Code (VS Code).
- **REVLib** lets Java code communicate with SparkMax motor controllers.
- **AdvantageScope** graphs live values and replays log files.
- **Glass** displays the autonomous chooser used in R14.

### How completion is checked

Each required lesson ends with a **Done when** box. It names an observable result, such as a changing counter, a spinning simulated launcher, or a graph in AdvantageScope. Save the evidence named by the lesson. The capstone uses the same results in one short demonstration.

Tools explains the computer skills used throughout GarageDocs: opening a project, running a command, saving work with Git, checking a connection, and inspecting robot data. These pages are written for people who may have little experience using computers. You can take one action at a time and compare your screen with the expected result.

## Where to Start

You do not need to read every reference page before beginning a lesson. Use the page that matches your task, then follow its prerequisite links when a term or action is new.

| I Need To | Start Here | What I Will Practice |
|---|---|---|
| Open an editor and save a file | [VS Code Tour](/tools/vscode-tour) | Recognize the editor, open a project folder, and find a saved file. |
| Type a command from a lesson | [Command Line Basics](/tools/command-line-basics) | Open a terminal, find the current folder, and distinguish a command from its output. |
| Keep a history of my changes | [Introduction to Version Control](/tools/introduction-to-version-control), then [Installing Git](/tools/installing-git) and [Local Git Workflow](/tools/local-git-workflow) | Record local changes. Check [ignore rules](/tools/gitignore) before staging files so generated output stays out of commits. |
| Share code with other people | [Create a GitHub Account](/tools/creating-your-github-account), then [GitHub Remotes](/tools/github-remotes) | Connect local work to a shared repository after learning the local Git workflow. |
| Understand a connection problem | [How a Network Works](/tools/how-a-network-works), then [Network Diagnostics](/tools/network-diagnostics) | Inspect the connection before changing settings. Use [Setting a Static IP](/tools/setting-a-static-ip) only when the network plan calls for one. |
| Look at robot measurements | [AdvantageScope Tour](/tools/advantagescope-tour) | Open a known log or simulation source, find a named value, and graph it. |
| Understand an error or ask for help | [Reading Docs and Errors](/tools/reading-docs-and-errors) | Collect the relevant message, locate its source, and explain what happened. |

## Where This Fits

These are references with no required session lengths. Use them alongside [Java](/java), [Hardware](/hardware), or a lesson that sends you here. Tools explains the computer action; Hardware provides the physical-device and connection context.

- [The Robot Network](/frc/robot-network) and [Robot Network Troubleshooting](/frc/robot-network-troubleshooting) apply network concepts to FRC radios and the roboRIO.
- [Kit Bot Setup](/kit-bot/r00-wpilib-setup) uses WPILib's editor and build tools. Keep its robot environment separate from the standalone Java course setup.
- [Kit Bot Telemetry](/kit-bot/r13-telemetry-with-advantagescope) produces the data used in the AdvantageScope examples.
- [Cobra Repository Tour](/frc/cobra-repository-tour) applies repository navigation to FRC 4451's competition project.

## Follow the Examples

Read the operating-system label before copying a command. Type the command itself, not the prompt or example output. Replace placeholders only after reading what belongs there. If a result differs from the page, stop at that step and use its troubleshooting guidance before continuing.

Shell examples use **PowerShell** tabs for Windows and **Terminal** tabs for macOS/Linux. Git commands are often identical because both shells run the same Git program. Operating-system configuration steps have separate labels when the procedures differ. Workflow YAML and program code retain their own language labels.

Tools covers the command line, networking, Git and GitHub, Visual Studio Code, AdvantageScope, and reading documentation. Use these pages while working through the curriculum or return to them for a specific task.

### Where this fits

These pages are reference material, with no durations or required sessions. Use them before or alongside [Java](/java):

- Start with the command line to run tools and read their output.
- Read the first three Git pages before making commits. Read the remote-repository page before cloning or sharing FRC 4451's code.
- Visual Studio Code (VS Code) is Microsoft's code editor. Start with its tour and shortcuts, then use the Java and Source Control pages as needed.
- Use Networking when configuring a connection or diagnosing a connection failure.
- Read the AdvantageScope pages when you have simulation data or a robot log to inspect. [Kit Bot R13](/kit-bot/r13-telemetry-with-advantagescope) introduces that workflow.

Later sections use these skills:

- [The Robot Network](/frc/robot-network) and [Troubleshooting a Robot Connection](/frc/network-troubleshooting) apply the networking concepts to FRC addresses, radios, and connections.
- [Kit Bot](/kit-bot/r00-wpilib-setup#step-4-build-the-project) uses Gradle to build robot code and Git to record changes.
- [Reading Our Robot Code](/frc/team-robot-code) applies repository navigation to FRC 4451's competition project.

### Conventions

Shell examples use **PowerShell** tabs for Windows and **Terminal** tabs for macOS/Linux. Git commands are often identical because both shells run the same Git program. Operating-system configuration steps have separate labels when the procedures differ. Workflow YAML and program code retain their own language labels.

### Getting Git on your system

Open PowerShell on Windows or Terminal on macOS/Linux and check whether Git is installed:

<CodeTabs>
<CodeTab label="PowerShell">

```powershell
git --version
```

</CodeTab>
<CodeTab label="Terminal">

```bash
git --version
```

</CodeTab>
</CodeTabs>

If the command prints a version, Git is available in that shell. Otherwise, follow the [Git installation guide](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git) for your operating system. Reopen the shell after installation and check again.

GitHub Desktop is an optional graphical client. The command-line examples in these pages require Git to be available in your shell.

### Initial Git configuration

Set the name and email address that Git will attach to your commits. Replace the example values with your own. These settings identify the author; they do not sign you in to GitHub.

<CodeTabs>
<CodeTab label="PowerShell">

```powershell
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
git config --global --get user.name
git config --global --get user.email
```

</CodeTab>
<CodeTab label="Terminal">

```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
git config --global --get user.name
git config --global --get user.email
```

</CodeTab>
</CodeTabs>

The last two commands print the values you set. Use an email associated with your GitHub account, or the private commit email provided in your GitHub email settings if you want to keep your personal address out of commits.

### Git configuration explained

`--global` applies the setting to your account on this computer. To use a different identity in one repository, run the configuration command inside it without `--global`. The repository setting takes precedence there.

On a shared computer, check the configured identity before committing. Each student should use their own account and identity. Authentication for remote access is covered in [GitHub and remote repositories](/tools/github-remotes#authentication-methods).

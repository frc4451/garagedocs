## Before You Start

Your personal GitHub account identifies you when you work on repositories. The account belongs to you. An organization can give your account access to shared repositories without knowing your password or owning your account.

You need an email address you can open now. An address you expect to keep after graduation is a good choice. You can add a school address later if your school or team needs it.

This lesson changes an online account. If a parent, guardian, school, or team has rules about student accounts, follow those rules before continuing.

## Create The Account

<StepsBox title="Sign Up For GitHub">

1. Open a web browser, such as Chrome, Edge, Firefox, or Safari.
2. Click the address bar at the top of the browser window, type `https://github.com/signup`, and press **Enter**.
3. Follow GitHub's prompts to create a free personal account. Use a strong, unique password and save it in your password manager.
4. Choose a username you are comfortable showing on repository pages, pull requests, and your public profile.
5. When GitHub asks you to verify your email address, open your email in a separate browser tab or email application. Open the message from GitHub and follow its verification link.
6. Return to GitHub and sign in if prompted. Select your profile picture in the upper-right corner, then select **Your profile**. Your exact username appears on the profile page.

</StepsBox>

Without a verified email address, GitHub blocks some basic tasks, including creating a repository. If the verification message does not arrive, check the spam or junk folder, confirm that the signup address is spelled correctly, and use GitHub's email-verification troubleshooting page.

Do not create one shared account for the Automation Team. Separate accounts keep commits, reviews, and permissions connected to the person who performed each action.

## Enable Two-Factor Authentication

Two-factor authentication (2FA) asks for another proof of identity when you sign in. GitHub requires contributors on GitHub.com to use one or more forms of 2FA.

1. While signed in, select your profile picture in the upper-right corner.
2. Select **Settings**.
3. In the left sidebar, select **Password and authentication**.
4. In the **Two-factor authentication** section, select **Enable two-factor authentication** and follow GitHub's current setup instructions.
5. Save the recovery codes when GitHub displays them. Confirm the saved file or printed copy is readable before you continue.

Store the recovery codes somewhere secure that you can reach if you lose your phone or computer. Do not keep the only copy on the device used for authentication. GitHub marks setup complete after you save the codes and confirm that you saved them. GitHub then begins a 28-day checkup period during which you can reconfigure 2FA if a setup mistake would otherwise lock you out.

<RulesBox title="Keep Credentials Private">

Never send anyone your password, authentication code, recovery code, personal access token, or private SSH key. A mentor needs your GitHub **username** to invite you, not your credentials.

</RulesBox>

## Accept An Organization Invitation

1. Copy your exact GitHub username from your profile and send it to the mentor or organization owner responsible for access.
2. Watch your email and GitHub notifications for the organization invitation.
3. Open the invitation while signed in to the account that should join, then select the option to join the organization.
4. Select your profile picture, then select **Organizations**. Confirm that the organization appears.
5. Open the repository your mentor names. Seeing an organization on your account does not by itself prove that you can open a particular private repository.

Organization invitations expire after seven days. If the invitation has expired, ask the organization owner to send it again. If the organization requires 2FA, you must enable 2FA before accepting its invitation.

Your organization membership may be private on your public profile. That visibility setting does not remove your membership or determine whether you can open a repository.

## Connect Commits To Your Account

Your GitHub username and your Git commit identity are configured separately. The next lesson sets the name and email stored in commits.

Use an email address connected to your GitHub account so GitHub can attribute pushed commits to you. If you do not want a personal address stored in commits, GitHub provides a private `noreply` address under **Settings → Emails**. Copy the complete address GitHub shows rather than typing it from memory.

## Check Your Setup

Before continuing, confirm that:

- You can sign in to your own GitHub account.
- GitHub shows your email address as verified.
- 2FA is enabled and your recovery codes are stored safely.
- You know your exact username.
- If your mentor sent an organization invitation, you accepted it and can open the assigned repository.

If one check fails, return to that section before installing and configuring Git. Keep the exact error message when asking a mentor for help, but remove any code or secret before sharing a screenshot or copied text.

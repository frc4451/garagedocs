## Before You Start

This lesson uses a **terminal**, an application where you type commands after a prompt. Read [The Prompt](/tools/command-line-basics#the-prompt) first if you have not used one. In the command boxes below, type only the command. Do not type the prompt text or copy the output examples back into the terminal.

Ask the computer's owner or administrator before installing software. An installation may ask for an administrator password that a student account does not have.

## Check For Git

Open the terminal for your operating system:

- **Windows:** Open the **Start** menu, type `PowerShell`, and select **Windows PowerShell** or **PowerShell**.
- **macOS:** Open **Finder**, select **Applications → Utilities**, and double-click **Terminal**.
- **Linux:** Open the distribution's application menu and select **Terminal**. The exact label varies by distribution.

Click in the terminal window, type the following command, and press **Enter**:

<CodeTabs>
<CodeTab label="PowerShell">

```powershell
git --version
```

</CodeTab>
<CodeTab label="Terminal">

```bash
git --version
```

</CodeTab>
</CodeTabs>

A working installation prints a line beginning with `git version`, followed by a version number. If you see that line, continue to [Choose The Commit Identity](#choose-the-commit-identity).

If PowerShell says that `git` is not recognized, or Terminal says `git: command not found`, install Git for your operating system. On macOS, the first version check may instead open a prompt to install Apple's command-line developer tools.

## Install On Windows

1. In a web browser, open the official [Git for Windows download page](https://git-scm.com/download/win). The download normally starts automatically.
2. Open the browser's downloads list and select the downloaded Git installer. If Windows asks whether the installer may make changes, confirm with the computer's owner or administrator.
3. Follow the installer. Keep the default choices unless your school or Automation Team has supplied different settings.
4. Close every open PowerShell window after the installer finishes. Open a new PowerShell window so it can find the newly installed program.
5. Run `git --version` again. Continue only when the output begins with `git version`.

If the download or installer is blocked, stop and show the message to the computer's administrator. Do not download an installer from an unrelated website.

## Install On macOS

1. In Terminal, run `git --version`.
2. If macOS offers to install command-line developer tools, follow that prompt. An administrator may need to approve the installation.
3. If no prompt appears, use the official [Git for macOS download page](https://git-scm.com/download/mac) and follow the current installer instructions.
4. Close Terminal after installation, open it again, and run `git --version`. Continue only when the output begins with `git version`.

## Install On Linux

Linux installation commands depend on the distribution. Open the official [Git for Linux instructions](https://git-scm.com/download/linux), find your distribution, and ask a mentor or administrator if you do not recognize its name or package manager. Installation often needs administrator permission.

After installation, close Terminal, open it again, and run `git --version`. Continue only when the output begins with `git version`.

## Choose The Commit Identity

Every commit stores an author name and email address. These values do not sign you in to GitHub.

The commands below use `--global`, which sets the identity for your user account across repositories on this computer. Do not use a global identity on a shared user account where several students create commits. Ask a mentor to help set a repository-specific identity instead.

Choose the name you want attached to your work. For the email address, use an address connected to your GitHub account or the private `noreply` address shown under **GitHub Settings → Emails**.

## Configure And Check Git

Replace `Your Name` and `your.email@example.com` inside the quotation marks. Keep the quotation marks around the name, especially when the name contains a space. Do not type angle brackets around either value.

Run one line at a time. Successful `git config` commands normally print no output. The two `--get` commands then print the saved values.

<CodeTabs>
<CodeTab label="PowerShell">

```powershell
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
git config --global --get user.name
git config --global --get user.email
```

</CodeTab>
<CodeTab label="Terminal">

```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
git config --global --get user.name
git config --global --get user.email
```

</CodeTab>
</CodeTabs>

Read the final two output lines. They should exactly match the name and email you intended to use. If either value is wrong, run its setting command again with the correct text, then repeat both checks.

## Local And Global Settings

`--global` applies a setting to your user account on this computer. A setting stored inside one repository takes precedence while you work in that repository.

On a shared computer, a mentor can open the intended repository folder and run the same configuration commands without `--global`. Check the result inside that repository before committing. [GitHub Remotes: Authentication Methods](/tools/github-remotes#authentication-methods) separately explains how Git proves your identity when it connects to GitHub.

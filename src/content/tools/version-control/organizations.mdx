### Organizing team repositories

A GitHub organization holds repositories and manages access for a group. It helps the team retain code and documentation when individual members leave.

### Creating GitHub organizations

1. Create an organization from your GitHub account and choose its name and plan.
2. Assign owners who will maintain access across seasons.
3. Create or transfer the team's repositories.
4. Choose visibility for each repository and invite members.

An organization is managed through members' individual accounts. Do not share one login among students. Repository visibility and organization membership visibility are separate settings. See [About organizations](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/about-organizations).

### Managing team access

Group members into teams, such as programmers or mentors, and grant repository access to those teams. Give contributors the access their work requires. Keep administrative access limited to people responsible for repository settings and membership.

Review access when students join, graduate, or change roles. Keep more than one responsible owner so one unavailable person does not prevent the organization from being managed.

### GitHub Education benefits

GitHub Free already supports private repositories; student status is not required for that. GitHub Education offers additional benefits for eligible users and organizations. Check the current [Student Developer Pack](https://education.github.com/pack) and [GitHub Classroom](https://classroom.github.com/) documentation before planning around a particular benefit.

### Security and access control

Choose public or private visibility according to what the team intends to share. Private visibility restricts repository access but does not make it a suitable place to store credentials.

Use two-factor authentication and review owners, teams, and repository permissions regularly. Record who maintains the organization and how the next season's mentors will take over those responsibilities.

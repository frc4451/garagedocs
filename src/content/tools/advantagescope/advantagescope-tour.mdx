**AdvantageScope** is a data visualization application from Team 6328, Mechanical Advantage. It is included with WPILib and can display live NetworkTables data and several log formats. FRC 4451 uses it for graphs, field views, controller inputs, and console messages.

This page introduces the application. [Poses on the field](/tools/advantagescope-field) covers the 2D and 3D views, and [Controllers and the console](/tools/advantagescope-controllers-and-console) covers those two tabs. The [official documentation](https://docs.advantagescope.org/) is the reference for current controls and supported formats.

### Where the data comes from

AdvantageScope displays fields available through the selected live source or log. If a value is missing, first check whether the program publishes or records it under the expected key.

[Kit Bot R13](/kit-bot/r13-telemetry-with-advantagescope) configures NetworkTables publishing and WPILib data logging. Cobra uses [AdvantageKit](/frc/advantagekit), which records logged inputs and values passed to `Logger.recordOutput`. Check the active source and exact key path before comparing the two projects.

AdvantageScope supports additional formats, including Driver Station logs and selected vendor formats. Consult [Log Files](https://docs.advantagescope.org/overview/log-files/) for the version you installed.

### Installing

Use the AdvantageScope version included with WPILib unless the team has chosen a separate release:

- **The WPILib installer** already put AdvantageScope on your machine when you did [Kit Bot R00](/kit-bot/r00-wpilib-setup). In WPILib VS Code the palette command *WPILib: Start Tool* → *AdvantageScope* launches it; so does the shortcut in the `wpilib/2026/tools` folder.
- **Direct from 6328.** The [releases page](https://github.com/Mechanical-Advantage/AdvantageScope/releases/latest) is often newer than the WPILib copy and alerts you when a new version ships. A new major version arrives every January with the year in its number (v26 for the 2026 season); the [installation page](https://docs.advantagescope.org/overview/installation/) explains the choice.

Record which version the team uses for shared layouts and troubleshooting. If two installations are present, confirm which executable you opened.

The window title shows *Searching* while a live connection is pending. Configure the robot address in preferences. For NetworkTables connections, **Low Bandwidth** requests active fields; **Logging** requests all fields so they can be viewed retroactively. Use Logging only when the available bandwidth supports it. See [Live Sources](https://docs.advantagescope.org/overview/live-sources/).

If the tree remains empty, confirm the selected source, configured address, robot or simulator state, network path, firewall, and whether data is being published. [Troubleshooting a Robot Connection](/frc/network-troubleshooting) covers the network checks.

The **timeline** controls the selected time across supported tabs. Mode colors depend on the data and current AdvantageScope version. Click or scrub to align graphs, field views, and messages. During a live connection, use the red arrow control to lock or unlock the current time.

### The Line Graph

Use a Line Graph to compare numeric fields over time. Put fields with different units on separate axes, and use the discrete area for booleans, enums, or strings.

For a mechanism, compare the commanded value, measured value, and control output. This can reveal lag, overshoot, steady-state error, or saturation, but the graph alone does not establish the cause. [Watching Simulation in AdvantageScope](/frc/advantagescope-sim#the-line-graph-commanded-versus-measured) explains how to investigate.

### Layouts

A layout stores tabs, selected fields, and view settings. Export shared layouts to JSON and keep them with the project when the team wants a reproducible review setup.

<RulesBox title="Common mistakes">

- **Wrong live source or address.** Confirm Robot versus Simulator and the selected protocol.
- **Missing publication or log entry.** Verify the key in the code and source tree.
- **Bandwidth mode does not retain an unused field.** Use Logging mode only when bandwidth permits.
- **Layout not saved.** Export a shared layout after checking its fields and labels.
- **Version mismatch.** Record the AdvantageScope version used to create a layout or reproduce a problem.

</RulesBox>

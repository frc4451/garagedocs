## Read a Shortcut

A shortcut is one or more keys pressed together. `Ctrl+S` means hold **Ctrl**, press **S**, then release both. On a Mac keyboard, `Cmd` means the **Command (⌘)** key and `Option` means the **Option (⌥)** key. `↑`, `↓`, `←`, and `→` mean the arrow keys.

A sequence such as `Ctrl+K Ctrl+S` is a **chord**. Press and release the first combination, then press the second. The tables show VS Code's defaults. Your operating system, keyboard layout, keymap extension, or personal settings may change them.

You can perform every listed action without memorizing its shortcut: open the Command Palette through **View → Command Palette...**, type the action name, and select it.

## Edit and Save

| Action | Windows / Linux | macOS |
|---|---|---|
| Save | `Ctrl+S` | `Cmd+S` |
| Undo / redo | `Ctrl+Z` / `Ctrl+Y` | `Cmd+Z` / `Cmd+Shift+Z` |
| Toggle line comment | `Ctrl+/` | `Cmd+/` |
| Move line up / down | `Alt+↑` / `Alt+↓` | `Option+↑` / `Option+↓` |
| Delete line | `Ctrl+Shift+K` | `Cmd+Shift+K` |
| Insert line below | `Ctrl+Enter` | `Cmd+Enter` |
| Find in file | `Ctrl+F` | `Cmd+F` |
| Replace in file | `Ctrl+H` | `Cmd+Option+F` |
| Select next occurrence | `Ctrl+D` | `Cmd+D` |
| Select all occurrences | `Ctrl+Shift+L` | `Cmd+Shift+L` |
| Add cursor with mouse | `Alt+Click` | `Option+Click` |
| Return to one cursor | `Escape` | `Escape` |

Multiple cursors apply the same typing at every selected position. Check all selections before typing. For a Java class, field, or method rename, use `F2` because the Java tools can follow symbol references.

The find box also offers **Match Case**, **Match Whole Word**, and **Use Regular Expression** controls. Use Match Whole Word when a search for `speed` should not also select `speedLimit`. Regular expressions describe text patterns; leave that control off unless the task supplies or explains a pattern.

## Debugging

| Action | Default Key | Expected Result |
|---|---|---|
| Start or continue | `F5` | The program starts, or runs to the next breakpoint |
| Start without debugger | `Ctrl+F5` | The program starts without debug controls |
| Toggle breakpoint | `F9` | A breakpoint marker appears or disappears beside the line |
| Step over | `F10` | The highlighted statement runs; the debugger stops at the next statement |
| Step into | `F11` | The debugger enters a method call when source is available |
| Step out | `Shift+F11` | The current method finishes and the caller becomes active |
| Stop | `Shift+F5` | The debug session ends |

Laptop function keys may control brightness or volume. If `F5` does not reach VS Code, hold the keyboard's **Fn** key too, or use the named button in the Debug toolbar.

## When a Shortcut Does Not Work

<StepsBox title="Check a Shortcut">

1. Choose **File → Preferences → Keyboard Shortcuts** on Windows/Linux or **Code → Settings → Keyboard Shortcuts** on macOS. The shortcut above opens the same editor.
2. Type the action name, such as `Toggle Integrated Terminal`, in the search box.
3. Read the **Keybinding** column. A blank row means that action has no key assigned in the current context.
4. To inspect a key combination, select the **Record Keys** button in the search box, then press the keys. The results show every command that uses them.
5. If two active commands use the same keys, read their **When** conditions. Different conditions can make the same shortcut valid in different views.
6. To change a binding, right-click its row, choose **Change Keybinding...**, press the new keys, and press Enter. Test the action once before continuing.

</StepsBox>

If the recorded key never appears, the operating system or another application may be intercepting it. Use the menu or Command Palette for the task, then choose a different VS Code binding rather than changing system settings you do not understand.

## Practice Safely

Open a scratch copy of a Java file. Do not use unfinished robot work for shortcut practice.

1. Save once and confirm the tab's unsaved dot disappears.
2. Use Quick Open to reopen the file by part of its name.
3. Move one line up, move it back down, then undo. Confirm the original text returns.
4. Select a repeated word with the next-occurrence shortcut, type a replacement, press Escape, then undo.
5. Open the terminal. Before typing a command, confirm its current folder as described in [Command Line Basics](/tools/command-line-basics#your-current-folder).
6. If the scratch folder is a Git repository, run `git status` and compare the output with [Reading Git Status](/tools/local-git-workflow#the-three-areas). Otherwise, skip that command.

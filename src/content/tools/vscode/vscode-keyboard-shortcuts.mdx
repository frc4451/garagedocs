### How to use this page

Use these tables as a reference. The ten entries marked **★** are suggested starting points. Practice a few that match your current work, then add others as needed.

The tables list default Windows/Linux and macOS bindings, with platform exceptions noted. A sequence such as `Ctrl+K Ctrl+S` is a **chord**: press and release the first combination, then press the second. Your keymap or keyboard layout may change these bindings.

If a shortcut does not work, check its binding, the active editor context, and any operating-system conflict. The [last section](#when-a-shortcut-does-not-work) explains where to look.

### Getting to things

| Action | Windows / Linux | macOS |
|---|---|---|
| ★ Command Palette: every command by name | `Ctrl+Shift+P` | `Cmd+Shift+P` |
| ★ Quick Open: any file by fuzzy name | `Ctrl+P` | `Cmd+P` |
| Go to symbol in file (methods, fields) | `Ctrl+Shift+O` | `Cmd+Shift+O` |
| Go to symbol in project (any class or method) | `Ctrl+T` | `Cmd+T` |
| Go to line | `Ctrl+G` | `Ctrl+G` |
| Cycle through open editors | `Ctrl+Tab` | `Ctrl+Tab` |
| Go back / forward (where the cursor was) | `Alt+←` / `Alt+→` | `Ctrl+-` / `Ctrl+Shift+-` |
| Open recent folder | `Ctrl+R` | `Ctrl+R` |
| Settings | `Ctrl+,` | `Cmd+,` |
| Keyboard Shortcuts editor | `Ctrl+K Ctrl+S` | `Cmd+K Cmd+S` |

After following a definition with `F12`, use **Go Back** to return to the previous location. The history can follow several nested jumps.

### Multiple cursors

Multiple cursors apply the same edit at several selected positions. Check the selections before typing.

| Action | Windows / Linux | macOS |
|---|---|---|
| ★ Add the next occurrence of the selection to the selection | `Ctrl+D` | `Cmd+D` |
| Select every occurrence of the selection | `Ctrl+Shift+L` | `Cmd+Shift+L` |
| Skip this occurrence, take the next | `Ctrl+K Ctrl+D` | `Cmd+K Cmd+D` |
| Add a cursor with the mouse | `Alt+Click` | `Option+Click` |
| Add a cursor on the line above / below | `Ctrl+Alt+↑` / `Ctrl+Alt+↓` ² | `Cmd+Option+↑` / `Cmd+Option+↓` |
| Add cursors to the ends of selected lines | `Shift+Alt+I` | `Shift+Option+I` |
| Back to one cursor | `Escape` | `Escape` |

² On Linux, `Shift+Alt+↑` / `↓`. On Windows, some graphics drivers intercept `Ctrl+Alt+Arrow` to rotate the screen; disable that hotkey in the driver's settings.

Use multiple cursors for repeated text edits. For a Java symbol rename, prefer `F2`, which uses language information to find references. Review the resulting changes in either case.

### Find and replace

| Action | Windows / Linux | macOS |
|---|---|---|
| ★ Find in file | `Ctrl+F` | `Cmd+F` |
| Replace in file | `Ctrl+H` | `Cmd+Option+F` |
| Find in all files | `Ctrl+Shift+F` | `Cmd+Shift+F` |
| Replace in all files | `Ctrl+Shift+H` | `Cmd+Shift+H` |
| Next / previous match | `F3` / `Shift+F3` | `Cmd+G` / `Cmd+Shift+G` |
| Find with the current selection | `Ctrl+F3` | `Cmd+E` then `Cmd+G` |

The find box has three toggles at its right end: match case, whole word, and regular expression. *Whole word* is the one to reach for when searching `speed` keeps finding `speedLimit`.

### When a shortcut does not work

Open the Keyboard Shortcuts editor (`Ctrl+K Ctrl+S` / `Cmd+K Cmd+S`) and type the *action* in its search box. For example, search for "toggle terminal". The row shows which keys are bound. Click the record-keys icon at the top right of the search box and press the *keys* instead, and it shows every action bound to that combination. This tells you whether an extension has taken it.

To change one, right-click the row → *Change Keybinding*, press the new keys, Enter. Your changes live in a `keybindings.json` you can open from the same screen, and Settings Sync carries them to your other machines.

If the binding is correct, check whether focus is in the expected view and whether another application or the operating system intercepts it. You can change the VS Code binding instead of disabling a system shortcut.

<ExerciseBox title="Shortcut practice">

Use a scratch copy of a Java lesson file. Follow the platform-specific bindings above; the exercise shorthand uses Windows keys.

1. Open the robot project or your Java lessons folder. Use `Ctrl+P` to open a file whose name you only half remember.
2. `Ctrl+Shift+P`, type `wrap`, and toggle word wrap on and off. Note the shortcut the palette shows.
3. Select a repeated comment word with `Ctrl+D`, edit the selected occurrences, then press `Escape`. Undo the practice edit.
4. `F12` on a method call, read the definition, `Alt+←` (`Ctrl+-` on macOS) back.
5. `Alt+↑` a line three times, then `Alt+↓` three times.
6. `Ctrl+/` a block of lines, then again to uncomment.
7. `` Ctrl+` `` to open the terminal, run `git status`, `` Ctrl+` `` again to hide it.
8. Introduce a typo in a method name. Press `F8` to jump to the error, `Ctrl+.` to see what VS Code offers.
9. `F2` on a method name and rename it; check the callers changed too. Undo with `Ctrl+Z`.
10. `Ctrl+K Ctrl+S`, search "format document", and confirm what it is bound to on your machine.

</ExerciseBox>
